# Front Office — 단장의 시간

가상 프로야구 리그의 단장(GM)이 되어 구단을 운영하는 한국어 브라우저 게임입니다. 경기는 감독과 선수가 치르고, 단장은 드래프트·트레이드·FA·외국인 선수·연봉·예산·코치진을 맡습니다.

- 창단 구단으로 시작해 창단 드래프트로 선수단을 꾸립니다.
- 샐러리캡, FA 등급과 보상, 외국인 선수 한도(용병 3명 총액 400만 달러, 아시아쿼터 1명) 등 KBO식 제도를 게임에 맞게 단순화해 넣었습니다.
- 경기는 카드 중계, 문자 중계, 박스스코어로 확인합니다.
- 모바일 우선, 설치 없이 한 개의 HTML 파일로 실행됩니다. 진행 상황은 브라우저에 자동 저장됩니다.

구단, 선수, 단장, 감독은 모두 가상입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 글꼴은 Google Fonts에서 불러오므로, 인터넷이 없으면 기본 글꼴로 표시됩니다.

## 구조

소스는 기능별 조각 파일로 나뉘어 있고, `build.sh`가 파일 이름 앞 숫자 순서대로 이어 붙여 `index.html` 한 파일을 만듭니다. 모든 조각은 한 스크립트 안에서 실행되므로 함수는 어느 파일에 있어도 서로 부를 수 있습니다. 다만 맨 위에서 바로 실행되는 상수·표(`const`)는 쓰는 곳보다 앞 번호 파일에 있어야 합니다.

| 경로 | 내용 |
| --- | --- |
| `src/html/` | 문서 머리말(`head.html`)과 본문 틀(`body.html`) |
| `src/css/` | 화면 스타일. 뒤 번호 파일이 앞 규칙을 덮습니다 |
| `src/engine/` | 게임 규칙과 시뮬레이션: 규정, 기록, 경기, 하루 진행, 스토브리그, 드래프트, 외국인, 연봉, 트레이드, 재정, 병역, 코치·감독, 구장 등 41개 |
| `src/ui/` | 화면과 동작: 홈, 소식함, 선수단, 트레이드, 영입·계약, 훈련, 스태프, 리그, 구단·재정, 중계, 선수 정보, 동작(`40_actions.js`), 결재(`41_guard_boot.js`) 등 42개 |
| `vendor/` | 외부 라이브러리(faces.js, lz-string) |
| `build.sh` | 위 파일을 묶어 `index.html`과 검사용 `dist/engine.js`를 만듭니다 |
| `index.html` | 빌드 결과물. 이 파일 하나로 실행됩니다 |

## 빌드

```bash
./build.sh
```

`src/` 또는 `vendor/`를 고친 뒤 실행하면 `index.html`이 다시 만들어집니다.
