# 세리머니·더그아웃·함성 에셋 조사 (2026-11-13)

대상: 끝내기·우승 세리머니, 빠던, 더그아웃 인물, 큰 함성. 웹 조사만 했고 내려받거나 들어 본 파일은 없다.
표기: **확인** = 해당 페이지를 열어 라이선스 문구를 읽음. **검색 요약** = 검색 결과 요약만 봄. **차단** = 사이트가 403/404를 돌려줘 확인하지 못함(우회하지 않음).

## 결론

- 동작: 빠던·몰려들기·포옹·하이파이브·더그아웃에서 뛰어나오기는 깨끗한 라이선스로 쓸 수 있는 클립이 없다. 쓸 수 있는 CC0 자료는 일반 환호·앉기·박수·점프뿐이고, 모두 지금 뼈대(`mixamorig*`)로 옮겨야 한다.
- 더그아웃 인물: CC0 후보는 있지만 "앉은 자세, 삼각형 수백 개"로 확인된 것은 없다. 우리 모델을 `bench_sit` 자세로 굳혀 단순화한 메시를 만드는 쪽이 안전하다.
- 함성: Freesound에 CC0 후보가 여럿 있다(파일별 확인). 들어 보고 잘라 써야 한다.
- 한국어 심판 콜·장내 음성: 여전히 CC0 자료 없음.

- 동작: 야구 전용 동작(빠던, 몰려들어 뛰기, 하이파이브, 포옹, 더그아웃에서 뛰어나오기)은 지금 뼈대에 직접 키를 잡는다. 앉기·환호 변형은 Quaternius 무료판을 내려받아 클립 목록을 확인한 뒤 옮긴다.
