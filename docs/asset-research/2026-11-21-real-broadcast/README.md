# 실중계 기준 중계 보완 조사

2026-11-21. **영상 후보 수집·코드 대조 단계**이며, 실제 재생 구간 검증은 완료하지 못했습니다. 현재 Cloud Browser는 `Browser Use could not read requirements`로 탭을 열지 못했고, 공개 MLB 페이지·Stats API 파일 접근은 이 환경의 프록시에서 `Tunnel connection failed: 403 Forbidden`을 반환했습니다. 이를 YouTube/MLB 자체의 봇 차단으로 판단하지 않습니다. 직접 보지 않은 영상의 동작·시간을 관찰한 것처럼 적지 않습니다.

사용자 기준: 실제 중계에서 부족한 부분을 찾아 채웁니다. 준비→동작→후동작→다음 플레이를 연속 구간으로 비교합니다. 기존 스윙 자세가 더 낫다는 피드백을 반영해 자동 복귀는 원복했고 사운드 정리는 유지했습니다.

## 기존 에셋에서 확인한 것

실제 `player.glb`의 애니메이션 목록에는 `throw_casual`, `throw`, `catch_throw`, `catch_throw_low`, `catcher_crouch`, `field_ready_infield`, `field_ready_outfield`가 있습니다. `athletic-motion.mjs`에는 포수 송구 연결 클립 `catcherThrow()`도 있습니다. 반환 송구는 새 외부 모델보다 기존 클립의 연결 여부를 먼저 검토할 수 있습니다. 이 목록은 에셋 존재 확인이며 실제 중계와 동작이 맞는다는 판정은 아닙니다.

## 구현 진입 기준

1. 접근 가능한 실제 영상의 출처와 직접 확인한 시작/끝 타임스탬프 기록.
2. 같은 상황의 현재 게임 연속 재생과 나란히 비교. 정지 화면만으로 후동작 개선 판정 금지.
3. 차이를 관찰 사실·추정·기존 의도적 생략으로 구분.
4. 빠진 연결 한두 개만 좁혀 시안 및 회귀 검사 작성. 화면·공·소리와 기록이 일치하는지 확인.
5. 사용자 비교 확인과 필요한 검사 완료 후에만 병합·배포.

현재는 위 영상 재생 검증이 막혀 있어 신규 동작·카메라·사운드를 더 구현하지 않았습니다. 코드 후보를 확인했다는 사실과 실중계 대조 완료를 구분합니다.
