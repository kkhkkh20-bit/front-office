## 공통 처리와 호환성

- `rainGames(day)`를 우천, 사전 검사, 경기 진행, 달력, 예약, 관중 전망이 공유한다. 재처리 우선·대진별 순번·최초 우천일·초과 경기 표시를 전달한다.
- 예약의 `gk={d,h,a,i}`는 특정 경기 한 건에 연결된다. 새 재처리가 앞에 끼면 기존 키를 보정하며 목적지 날짜별 표식으로 중복 보정을 막는다.
- 구형 DH 예약에서 차전을 식별할 수 없으면 임의로 먼저 실행하지 않고 취소 안내 후 다시 예약할 수 있게 한다. 단일 대진은 기존 상대 정보로 호환한다.
- `gameDone`·`playedDh`, 퓨처스 `playedDays`는 재진입 중복 반영을 막는다. 완료 표식이 없던 구형 DH는 실제 로그로 계산한다.
- 롤백은 경기 반영이 수정하는 가지만 보관하고 공유 객체 참조를 유지한다. 시즌 전체 G 복제는 사용하지 않는다. 시즌 로그가 쌓인 상태의 스냅샷 비용도 별도 검토했다.
- 반복 우천에서는 새 순연 표시에 최근 취소일을 기록하고 앞선 취소 이력은 따로 유지한다. 처리 오류 재시도는 그 우천 날짜를 그대로 전달한다. 기존 #166과 새 #536을 함께 검증했다.
- 기존 DH `11-09k` 시나리오는 두 경기가 열린 날의 기록 검증이므로 날씨를 끄고, 추가 상대의 공용 구장이 다른 홈경기와 겹치지 않도록 준비 과정만 고쳤다. 재처리도 우천 취소되도록 바뀐 #526 동작은 새 별도 시나리오에서 검사한다.
- 기존 `11-09zt` 시나리오는 이미 끝난 날을 다시 실행하는 설정이었다. 앞으로 열릴 날에서 오류를 주입하도록 준비 과정만 고쳤다. 좌우·타구 기록·선발 순번 롤백, DH 첫 경기 캠프 구종 검사는 그대로 유지했다.
