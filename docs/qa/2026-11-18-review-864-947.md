## 검증·예전 저장·한계

최종 공유 빌드 검사·화면·이전 저장 근거·겹치는 파일과 배포는 아래 통합 실행 기록에 확정한다. 각 담당의 원래 재현·정상 대조·추가 경계·구형 저장 검사는 /workspace/work/qa-followup-*.md 및 관련 상세 보고서에 보관했다. 기존 게임 검사와 단정은 유지하며, actor ID가 없는 연락 준비 한 곳만 실제 같은 인물을 나타내도록 person/contactOwner를 보완했다.

이번 선택 범위의 기존 GE765 oracle은 수정 전 main6068에서도 실패했다. 기준과 현재의 실제 세 경기/RNG fingerprint는 모두 [879007581,1626131393,501139324]로 같으며, 초기 세계 JSON hash는 새 메타데이터 때문에 달라진다. 기존 단정은 바꾸거나 끄지 않았고, 기준/현재 비교 로그를 별도로 보관했다.


## 통합 구현과 난수

결산의 pre/core/post(업적·레거시 포함)를 공통 transaction 안에서 실행한다. 실패하면 원래 객체 참조·배열·Map·Set까지 되돌린다. 이미 소비한 main RNG prefix를 다음 같은 결산 재시도에서 재생하고 나머지는 원래 stream을 잇는다. 정상 결산은 기존 난수원과 호출 순서를 유지한다. 실제 정상과 후반 오류→재시도의 전체 G·급여/성과급 명세·구단 현금·개인 지갑·난수 상태/소비 횟수를 대조했다. 정상 50회·상태1384912476을 보존하고 실제 processDay 재시도도 검사한다.

G 바깥 계정 업적은 결산 중 메모리 overlay에서 계산하고 성공 뒤 기존 병합 저장을 사용한다. 실패한 결산의 업적·우승이 계정에 먼저 남지 않으며, 저장소를 과거 값으로 통째로 되돌리지 않으므로 다른 탭의 새 칭호·업적·우승도 보존한다. 같은 성공 결산 재호출은 추가 지급·계정 갱신을 하지 않는다.

퓨처스는 편성 전 상태부터 실제 경기 결과·양쪽 선수 기록·순위·로테이션을 한 번에 확정한다. 오류가 난 경기만 미완료로 남겨 같은 날짜에 재시도한다. 이미 성공한 경기는 다시 반영하지 않는다. 구형 날짜 처리표는 실제 저장된 경기의 날짜·라운드·대진 증거로만 복구하고, 존재하지 않는 과거 경기를 생성하지 않는다. 시즌 중 처음 퓨처스를 생성해도 실제 달력 라운드와 관전 예약 상대가 일치한다.

퓨처스 일반 구단 홈·원정은 홀수 맞대결 잔여 그래프의 Euler 방향과 pair 교대로 전체·각 맞대결 편차를 1경기 이하로 맞춘다. 상대·날짜·순서·bye와 상무 항상 원정 정책은 유지한다. 기존 완료 라운드와 경기 기록은 보존하고 다음 미처리 경계부터 적용한다. 초기 상무 보충의 기존 main RNG는 유지하며 새 시즌 중 충원과 새 야인 후보 경로의 난수는 별도 salt로 격리한다.

감독의 직접 건의·메일·회의가 공통 인원/자격 검사를 사용한다. 실패한 안건은 관계·강요·말소일을 바꾸지 않고, 비포수 콜업은 건강한 포수 2명을 보존한다. 승인한 투수 휴식은 실제 일반/비상/포스트시즌 선발·불펜 자격에서 제외한다. 요청 완료는 원본 메일·중요 표시·진행 정지를 함께 닫고, 실제 영입의 순번·기한·구단/역할 영수증을 남겨 당일 선행 영입·기한 이후 영입·후속 이적을 구분한다.

대체 계약은 원선수·대체 선수·해당 계약의 연결을 확인하며 구형 일방 연결 때문에 건강한 원선수를 방출하지 않는다. 전환에는 실행 직전 명단·교체권·실제 해당 구단의 잔여 경기(DH 각 경기 포함)를 사용한다. 임시 입단일과 정식 전환일/영입 순번은 각각 보존한다.

스폰서는 이미 끝난 시즌의 AI 후원 발생 몫과 시즌 급여 담당자를 실제 종료 시점에 동결한다. 늦은 부임·왕복 이직으로 기존 수입·우승 단장·전임 연봉이 바뀌지 않는다. 계약별 정수 지급액과 합계·이력/화면이 같은 helper를 사용한다. 영업 중 정기 제안으로 자리가 차면 기존 미사용 기간 비례 환급을 즉시 사용하며 새 환급률을 만들지 않는다.
