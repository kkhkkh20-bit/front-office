## 검사 준비 변경·겹치는 파일

기존 검사를 삭제하거나 단정을 줄이지 않았습니다. 기존 11-09zo의 AI 구단 시설 검사는 조회할 AI 구단의 시설을 최고 단계로 준비하도록 한 줄을 정정했습니다. 기존 11-09zz의 합성 1월 한국시리즈 박스에는 검사 의도인 `season:G.year`만 명시했습니다. 두 검사의 원래 단정은 모두 유지했습니다. 래더 정상 경기 대조는 다른 검사 실행 순서에 따라 기준 세계 캐시가 냉·온 상태로 달랐습니다. 기준 main에서도 같은 차이를 재현했고, 두 실행 전에 기존 기준 세계를 같은 상태로 준비하도록 검사 준비만 보완했습니다. 이 준비가 경력 G 전체 JSON과 주 난수를 바꾸지 않는 단정도 넣었으며, 전체 경기 박스 해시 및 난수 단정은 유지했습니다. 수비 교체의 정상 대조도 첫 생성과 JSON 복원의 준비 난수를 같게 고정했습니다. 타석 결과를 강제한 검사 대역은 실제 outcome처럼 이전 타구 정보 LBIP도 매 타석 초기화합니다. 초기화 전에는 이전 GB/FB에 따라 세 기준 엔진 모두 같은 차이가 났고, 초기화 후에는 4df4·9fc·통합 엔진의 전체 점수·이닝·판정·양 팀 박스·교체 순서 해시 2994195025와 난수 658856370가 모두 같습니다. 경기·난수 단정은 줄이지 않았습니다.

## 기존 실패와 검증 범위

`[검수 11-18 자책 난수 호환] 실책 없는 정상 경기의 기존 결과·박스·로그와 주 난수 흐름을 유지한다`는 수정 전 main `4df4acd7` 보존 엔진에서도 실패했습니다. 기존 단정은 그대로 남겼습니다. 기준과 최종 통합 빌드의 네 해시는 모두 동일합니다: 세계 메타데이터 `1793794006`, 실제 세 경기 난수 결과 `879007581, 1626131393, 501139324`. 전체 JSON의 오래된 고정값과 새 메타데이터 차이를 실제 경기 난수 대조와 구분해 기록합니다.

실제 GUI는 로컬 최종 생성물에서 Chromium으로 조작했습니다. 운영 중인 이용자 저장 및 실제 발생 빈도는 검증하지 않았습니다. 배포 확인은 공식 배포 작업 로그가 읽은 release.json의 commit으로 확인합니다.

Git fetch RPC가 지연되어 최신 main은 연결된 GitHub 도구와 공식 raw 파일로도 확인했습니다. 원래 서명 커밋 7개·변경 blob 30개·전체 Git 트리 106c7908ecde39fd22e69b606ecc0332430001b1의 해시가 모두 일치하고 필요한 객체가 전부 있는 것을 검증한 뒤 origin/main을 최신 확인 커밋으로 갱신하여 git merge를 실행했습니다. 프록시·TLS·자격 증명 정책은 변경하지 않았습니다. Push는 원래 origin의 Git 전송을 사용합니다.
