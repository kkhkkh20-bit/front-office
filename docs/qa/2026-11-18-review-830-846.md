## 예전 저장과 공통 처리

`migrateDraft`의 기존 `fanOpsFix`가 사진과 경기 예약을 정리한다. 구형 예약에 대진·차전이 하나로 확인될 때만 기존 경기 키를 보완한다. 여러 차전이 가능하면 임의 배정 대신 안내와 환불로 종료한다. 사진은 단원 번호의 구단 소속이 유일할 때만 옮기며 모호하거나 새 사진과 충돌하면 옛 사진·자르기 원본을 보존한다. main에서 추가한 v22 사진 배정도 함께 유지한다.

`fanLedgerFix`는 **현재 미결 회계연도**의 원장에서 팬 비용 항목이 명시적으로 0이고 `net`이 수입−비용보다 큰 구형 clip 형태만 복원한다. 모든 수치가 유한한지 확인하며 이미 현금에 반영된 차액을 음수 팬 비용으로 돌려 놓는다. 현금과 `net`을 다시 지급하지 않는다. 과거 결산 장부·팬 비용 근거 없는 장부·정상 균형 장부는 그대로다. 실제 불러오기 두 번과 최종 결산에서 중복 환급·현금 불일치가 없음을 검사했다.

`facDealsMigrate`는 로드 말미에 한 번 실행한다. 실제 연간 처리 완료 증거 `G.ceco.yr`가 있을 때만 후원 계약의 처리 연도를 보완한다. 근거 없는 과거 지급액은 추정하지 않는다. 계약의 마지막 해까지 지역 채용 비용을 적용하고 다음 회계연도 전망에서는 제외한다. 정상 이행의 마지막 명명권 지급만 반올림 잔액을 포함하고, 조건을 어긴 해의 미지급액은 보충하지 않는다.

응원단 새 계약은 실제 계약 시작일·청구 기준일을 보관한다. 날짜가 없는 옛 계약은 기존 월 청구 정책을 유지한다. 새 단원 배정에 필요한 난수는 거절 전에 소비하지 않는다. 독립구단은 기존 단원 실제 요금과 새로 배정할 단원의 수학적 최대 월 요금에 대한 운영 여유를 먼저 확보해야 하며, 실제 배정 뒤 실제 수수료만 청구한다. 최대 요금을 예산으로 확보해야 한다는 안내를 계약 화면과 거절 문구에 명시한다. 정상 충분 자금의 기존 단원·주 난수 golden 결과는 그대로다.

시작 전 단장 계약에는 가짜 재임을 만들지 않으며, 이미 근무한 재계약의 종료 처리는 유지한다. 원래 개시일이 소실돼 실제 1년 재임과 구분할 수 없는 완료 경력은 추측 삭제하지 않는다.
