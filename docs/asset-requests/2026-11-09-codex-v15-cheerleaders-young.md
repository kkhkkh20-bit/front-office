# 에셋 v15 요청: 치어리더 단원 인물 사진 다시 만들기 (Codex)

작성: 2026-11-09. 사용자 요청: "치어리더 얼굴이 안 보임", "좀 더 젊고 예뻐야 함".

## 배경
- 11월 9일 치어리더 단원 카드가 생겼다(구단·재정 > 팬·언론 > 응원단장·치어리더). 카드마다 사진이 카드 폭(정사각, 휴대폰 약 180px·PC 약 150px)으로 크게 나온다.
- 지금 단원 사진은 v14 `assets/v14/cheer/portraits` 12명과 v12 치어리더 팀장 16명을 같이 쓴다.
  - 문제 1: 나이가 30대로 보이는 얼굴이 많다. 단원은 20대 초중반이다.
  - 문제 2: 화려한 응원단 느낌이 약하다. 사무실 증명사진처럼 보인다.
  - 문제 3: 단원이 구단당 최대 16명이라 12명으로는 얼굴이 겹친다.
