# 에셋 v6 요청: 선수 얼굴 대량 제작 (Codex)

작성: 2026-11-05. v5b 얼굴 합성 시험 합격에 따른 실제 제작 요청입니다.
규격의 바탕은 assets/v5/v6_face_spec.json 과 v5 요청서 C절입니다. 아래가 그 위에 덧붙이거나 바꾸는 내용입니다.

## 0. 먼저 해결할 것: 인물마다 붙는 파일을 없앤다
v5b는 인물마다 의상 마스크·몸판/소매/칼라 마스크·모자 마스크·모자 음영·의상 정렬 좌표(x·y) 등 6장 이상이 필요합니다. 10,000명이면 6만 장, 수 GB라 게임(웹 배포, Cloudflare 파일 2만 개·파일당 25MiB)에 넣을 수 없습니다. 그래서 v6는 아래처럼 만들어 주세요.

- **공통 상체**: 모든 인물을 기준 인물 ko_late20s_01과 **같은 어깨·목둘레·몸판 윤곽**으로 만든다(같은 카메라·자세, 상체는 사실상 같은 틀). 그러면 v5b 공통 의상 레이어를 정렬 좌표 없이(항등) 그대로 덮을 수 있다. 인물마다 다른 것은 머리·얼굴·목·모자 아래 머리카락뿐.
- **공통 의상 마스크 1장**: 위 공통 상체 기준 의상 마스크 한 장을 manifest에 둔다. 목과 칼라 경계는 인물마다 조금 달라도 칼라 레이어가 목 위로 넘어가거나 목이 칼라 밖으로 비치지 않게 생성 단계에서 맞춘다(검수: 공통 마스크 경계 ±3px 안).
- **모자**: 키 색(#FF0000) 모자는 그대로. 모자 마스크는 인물마다 다르므로 **판의 알파 채널에 모자 마스크를 넣는다**(배경은 불투명이라 알파가 비어 있음). 모자 음영은 판의 R 채널을 그대로 쓴다(게임이 계산).
- 즉 인물 한 명 = **판 1장(RGB + 알파=모자 마스크)**. 그 외 인물별 파일 없음.

## 1. 1차: 시범 100명 먼저
- 한국인 85명(18~23세 51, 24~29세 26, 30~34세 8), 외국인 15명(미국·중남미·일본·대만 등, 24~33세).
- 위 0의 구조로 만들고, 11개 구단 홈 키트를 입힌 합성 검수판(100명 × 대표 3구단, 128·256)을 같이 납품.
- 겹침 검사(ArcFace 코사인 상한 0.35, v6_face_spec.json 그대로)와 실존 인물 유사 금지 육안 검수.
- Claude가 게임에 연결해 보고 합격하면 2차부터 1,000명씩 9회 + 900명(합계 10,000).

## 2. 출력
- 판: WebP, **256과 128 두 크기**(게임은 256에서 합성하고 128은 목록용으로 축소본 사용). 512는 원본 보관용으로 따로 두고 배포 폴더에 넣지 않음.
- **시트**: 100명씩 10×10 격자 WebP(크기별 1장, 알파 포함). 낱장은 보관용.
- manifest: 인물 ID, 시트 파일·격자 위치, 나이·민족·피부톤·헤어·수염·안경 태그, 겹침 검사 최근접 상대와 유사도.
- 시트 1장 예상 크기와 1,000명당 총용량을 README에 기록(목표: 256 시트 1장 2MB 안쪽).

## 3. 생성 다양성
- 헤어(짧은 머리 위주, 장발·탈색 소수), 안경 10% 안팎, 수염 한국인 소수·외국인 다수, 체형은 얼굴 살집으로만(상체 틀은 공통).
- 같은 회차 안에서 비슷한 인상 몰림 금지. 나이 표현이 태그와 맞게(18세는 앳되게).
- 표정은 무표정~옅은 미소. 모자는 모두 착용.

## 게임 쪽(참고, Claude 담당)
- 합성: 판(256) → 공통 의상 레이어(구단 홈) → 가슴 심벌 → 모자 키 색 교체(알파=마스크, R=음영) → 모자 심벌. 결과는 구단·인물별로 캐시.
- 배정: 사라진 사람 얼굴만 재사용, 영구결번·명예의 전당·수상자급과 사용자 구단 출신은 재사용 금지, 같은 구단·같은 해 입단에 닮은 얼굴 금지, 은퇴 후 코치는 선수 때 얼굴.
