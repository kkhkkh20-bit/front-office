# 에셋 v4 요청: 실사 3D 렌더 트로피·배지 + 실사 얼굴 시험 10장 (Codex)

작성: 2026-11-05. 요청자 피드백: "좀 입체적인 그림도 좋아. 그림이 아니라 실제 같은 3D", "사람 얼굴 에셋은 더 좋은 거 없나".

## A. 트로피·상·대기록 배지 실사 렌더 (승인됨, 우선)
- 대상: assets/v3 manifest의 trophies 19종 + feats 11종, 같은 ID·같은 구성(형태·글자 자리)을 유지하고 질감만 실사로.
- 방법: 3D 모델링 후 물리 기반 렌더(PBR). Blender(Cycles/EEVEE) 또는 three.js PBR 등 무엇이든 가능. 금·은·동·크리스털·에나멜·나무 받침의 실제 재질, 스튜디오 조명(키·림 라이트), 약간의 반사와 접지 그림자.
- 각도: 정면에서 살짝 위(약 10~15도) 3/4 각도, 모든 트로피 같은 카메라·조명으로 통일.
- 출력: 투명 배경 PNG 64·128·256·512 + WebP. 글자 없는 판(타이틀 상패, 공용 숫자 틀)은 글자 자리(text_slots)를 manifest에 다시 기록.
- 금지: 실존 대회 트로피(KBO 우승 트로피·골든글러브 실물 등) 모양 복제, 실존 로고, 이모지풍.
- 폴더: assets/v4/trophies/, assets/v4/feats/ + manifest.json, checksums.json, README.md, CLAUDE_HANDOFF.md, ASSET_PREVIEW.png.
- 용량: 64px 기준 장당 15KB 이하 목표.

## B. 선수 얼굴 실사풍 시험 10장 (시험용)
- 목적: 지금의 만화풍 얼굴 대신 사진에 가까운 반실사 얼굴로 바꿀지 판단하기 위한 시험 세트.
- 구성 10장: 한국인 남성 선수 8(20대 초반 2, 20대 후반 2, 30대 2, 30대 후반 수염 1, 안경 1) + 외국인 2(히스패닉 1, 흑인 1).
- 구도(요청자 추가 지시): 머리부터 어깨·가슴 윗부분까지, 구단 유니폼 상의를 입은 모습. 유니폼은 assets/v3 uniforms의 해당 구단 홈 유니폼 디자인(단추 줄·칼라·파이핑·가슴 워드마크 일부가 보이게)과 맞출 것.
- 공통 조건: 같은 조명(스튜디오 정면 소프트박스), 같은 각도(정면, 어깨까지 나오게), 같은 배경(단색 #20262e 또는 투명), 야구 모자 착용 버전과 미착용 버전 각 1장(총 20장). 모자는 assets/v3 caps 디자인 중 서울 코메츠·광주 블레이즈 색 사용, 실존 구단 로고 금지.
- 금지: 실존 인물(선수·연예인)과 닮게 만들기, 실제 사진 사용.
- 출력: assets/v4/faces_test/ 정사각 512px PNG(+128px), manifest(나이대·피부톤·수염·안경·모자 여부 태그).
