## 표현 원칙
- 유니폼은 팀 색만 바꿔 쓸 수 있게 **중립 흰색 홈 유니폼 + 포인트 색 1개**로 만든다. 같은 장면을 빨강·파랑·검정·주황·초록·남색 6색으로 낼 수 있으면 A와 B는 색별로 낸다(그 경우 A·B 장수 ×6, 파일명에 색 키).
- 실제 구단 로고·글자·스폰서·실존 인물 닮은 얼굴 금지. 가슴 글자는 흐린 무늬로.
- 얼굴은 작거나 뒷모습·옆모습 위주. 감정은 몸짓(점프, 포옹, 두 팔 들기)으로.
- 색감: 밤 경기 조명, 금색 꽃가루, 따뜻한 하이라이트. 과한 보정 없이 사진처럼.

## 게임 연결(Claude가 한다)
- 우승 카드: 띠(F)를 카드 배경으로, 트로피(E)를 크게.
