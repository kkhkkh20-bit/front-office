## 3. 요청 목록

### A. 트로피·상(최우선)
모두 같은 화풍(금속 질감, 은은한 하이라이트, 받침대 명판), 작게(24px)도 실루엣으로 구분되게. 크기: SVG + PNG 32·64·128·256.
1. 한국시리즈 우승 트로피(기존 championship_trophy 대체, 더 크고 정교하게)
2. 한국시리즈 준우승 트로피(은)
3. 정규시즌 1위 페넌트/트로피(동 또는 깃발형)
4. MVP 트로피
5. 신인왕 트로피
6. 골든글러브(금색 글러브 조형)
7. 타이틀 상패: 타격(타율·홈런·타점·안타·도루·출루율·장타율) 공용 1종 + 투수(다승·평균자책점·탈삼진·세이브·홀드·승률) 공용 1종. 아래 띠에 부문 글자를 넣을 수 있게 글자 없는 버전도.
8. 올스타 MVP 트로피, 올스타 선정 배지(드림·나눔 2색)
9. 국가대표 메달(금·은·동) — 기존 national 배지와 어울리게
10. 우승 반지(구단 색으로 바꿀 수 있게 보석 부분을 색 변수/별도 레이어로)
11. 명예의 전당 명패
12. 감독상(선택)

### B. 대기록 배지(선수 경력 탭·연표용, 원형 또는 방패형, 32·64)
사이클링 히트, 노히트노런, 퍼펙트게임, 한 경기 4홈런, 연타석 홈런, 끝내기 홈런, 만루 홈런, 15탈삼진, 연속 경기 안타, 통산 이정표(100·200·300·400·500 숫자를 넣을 수 있는 공용 틀), 시즌 기록(30-30·40홈런 등 숫자 넣는 공용 틀).

### C. 유니폼(10개 구단 + 국가대표, 홈·원정, 총 22종) — 다시 그리기
- 야구 유니폼답게: 앞단추 줄과 단추, 칼라 라인, 소매 끝 줄무늬, 가슴 워드마크(구단 별칭 영문 또는 한글, 예: COMETS / 코메츠 — 실존 구단 워드마크 글꼴 모방 금지), 왼쪽 가슴 아래 등번호 작게, 바지 상단 일부와 벨트(선택).
- 홈은 흰 바탕 + 구단 색 파이핑, 원정은 회색 또는 구단 색 바탕.
- 정면 1장 + 등(이름·등번호 자리 비움) 1장. 등번호·이름은 게임이 글자로 덧입힐 수 있게 빈 자리와 좌표를 manifest에 기록.
- 크기: SVG + PNG 128·256·512(투명 배경).

### D. 모자(11종) — 유니폼과 같은 화풍으로 다시 그리기
정면 3/4 각도, 챙 그림자, 앞면 구단 심벌. SVG + PNG 64·128·256.

### E. 구단 로고 보강(선택, 원형 배지는 이미 승인됨 → 유지)
- 원형 배지는 그대로 두고, 추가로 (1) 배지 없는 심벌만, (2) 가로형 워드마크(심벌+별칭), (3) 단색 흰색 버전. 각 SVG + PNG.

### F. 화면 장식(선택)
- 시상식 무대 배경(어두운 무대·조명, 1920×1080, 글자 겹칠 자리 어둡게)
- 포스트시즌 대진표 배경(가을 느낌, 어둡게)
- 우승 축하 띠·리본(구단 색 변수)

## 4. 납품 형식
- 폴더: assets/v3/ 아래에 trophies/, feats/, uniforms/, caps/, logos/, stage/ 로 나누고 manifest.json(파일명·크기·구단 key·색 변수·글자 자리 좌표), checksums.json, README.md, CLAUDE_HANDOFF.md(적용 지침), ASSET_PREVIEW.png(전체 미리보기) 포함.
- 파일명: 영문 소문자_밑줄, 구단은 위 key 사용.
- 단일 HTML 배포라 용량 주의: PNG는 최적화(가능하면 WebP 동봉), 아이콘 1장 64px 기준 10KB 이하 목표.
