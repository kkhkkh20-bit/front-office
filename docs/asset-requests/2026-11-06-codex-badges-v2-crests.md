# 에셋 v2 요청: 구단 엠블럼 입체 크레스트 (Codex)

작성: 2026-11-06. 사용자 요청: 구단 로고를 입체적으로, 마스코트 일러스트가 들어간 스포츠 구단 크레스트 수준으로 새로 만든다.
사용자가 보여 준 참고 수준: 방패형 엠블럼 안에 마스코트 캐릭터가 크게 들어가고, 아래에 굵은 영문 워드마크 리본, 금속(금·은) 테두리와 경사(bevel), 조명·그림자·광택이 있는 입체 그림. 참고 그림은 다른 게임의 그림이므로 **모양·구도·글자 디자인을 베끼지 않는다**. 수준(디테일·입체감)만 맞춘다.

## 배경(지금 게임 상태)
- 지금 배지: assets/badges/v1 (원형 평면 배지, 심벌 + 단색 배경 + 테두리). 게임 전체 구단 로고가 이것을 쓴다.
- 구단 정체성(심벌·색)은 v1을 그대로 이어받는다. 새 디자인은 v1 심벌을 마스코트로 키운 것이어야 한다.

## 금지
- 실제 KBO·MLB·NPB 구단 로고, 실제 마스코트, 다른 게임(참고 그림 포함) 엠블럼과 닮게 하지 않는다. 실존 기업 표시·후원사 글자 없음.
- 같은 리그 안에서 두 구단이 비슷해 보이지 않게(모양·주색으로 구분).

## 규격
1. **크레스트(full)**: 마스코트 + 외곽 프레임 + 영문 워드마크. 정사각 캔버스, 투명 배경(RGBA), 바깥 그림자는 캔버스 안에서 짧게만(아래쪽 3% 이내). 512·256·128px.
2. **마크(mark)**: 작은 크기용. 워드마크 없이 마스코트·심벌과 외곽 프레임만, 같은 입체 스타일로 단순화. 32px에서도 구단을 알아볼 수 있어야 한다. 128·64·32px.
3. 어두운 배경(#11161D)과 밝은 배경(#F4F5F7) 양쪽에서 테두리가 묻히지 않게(외곽에 얇은 어두운 선 + 밝은 금속 테두리).
4. 조명 방향은 10개 모두 왼쪽 위로 통일. 금속 테두리 색은 구단 보조색 또는 금·은 중 하나로 통일감 있게.

## 납품
- assets/badges/v2/ 아래:
  - png/crest/{512,256,128}/{key}.png, png/mark/{128,64,32}/{key}.png
  - teams.json: v1과 같은 형식에 assets를 `{"crest":{"512":...,"256":...,"128":...},"mark":{"128":...,"64":...,"32":...}}`로, `wordmark` 필드(영문) 추가.
  - checksums.json(sha256), preview.png(10개 크레스트를 어두운·밝은 배경에 한 번씩, 마크 32·64px 실제 크기 줄), README.md, CLAUDE_HANDOFF.md(경로·크기 규칙).
- 리뷰 브랜치 `assets/v2-badges-review`로 납품하고 main에는 병합하지 않는다.
- 코드(src/, index.html, 빌드·검사)는 건드리지 않는다. 게임 연결은 Claude가 한다.

## 게임 연결 계획(Claude, 참고)
- 헤더·구단 선택·대진·우승 화면(40px 이상)은 크레스트, 목록·순위표·일정(32px 이하)은 마크를 쓴다.
- 빌드 크기 한도 때문에 512px은 저장소 원본으로만 두고 게임에는 256 이하만 넣는다.
