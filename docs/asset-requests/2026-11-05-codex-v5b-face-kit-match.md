# 에셋 v5b 요청: 얼굴 합성 판을 새 유니폼 디자인에 맞추기 (Codex)

작성: 2026-11-05. v5 검수 결과에 따른 수정 요청입니다.

## 검수 결과
- A(소개용 유니폼 44장·모자 11종): 합격. 게임 구단 소개 화면(구단 선택 자세히·구단 정보·연대기·국가대표)에 연결했습니다.
- B(얼굴 합성): 키 색 교체와 마크 자리 정렬은 11세트 모두 맞습니다. 다만 두 가지 문제로 아직 게임에 연결하지 않습니다.
  1. 얼굴 판의 유니폼이 A 개편 전 단색 홈 키트입니다. 같은 구단인데 소개 화면(예: 광주 빨간 소매·필기체 BLAZES)과 선수 얼굴(흰 상의·블록 글씨)이 달라 보입니다.
  2. 가슴 워드마크가 가운데 단추 줄에 끊겨 128~256px 얼굴에서 글자가 깨져 보입니다(COM ETS, ST ORM, RED FOX).

## 요청
1. **기준 판을 구단별 A 디자인에 맞춘 합성 레이어로**
   - 구단마다 다른 요소(핀스트라이프, 소매·어깨 배색, 가슴 띠, 칼라·파이핑 색)를 얼굴 기준 판 구도(512px, v5 faces_test와 같은 위치)에 맞춘 레이어로 만들어 주세요.
   - 방식은 v5와 같게: 기준 판은 한 벌(키 마스크)로 두고, 구단별로 `{team}_kit_overlay`(패턴·소매 배색, 전체 512 투명 캔버스, 원단 음영 포함) + `{team}_chest` + `{team}_cap`을 순서대로 얹는 구조. 이적해도 얼굴 사진은 다시 만들지 않아야 합니다.
   - 소매 배색처럼 키 마스크 밖 영역이 필요하면 기준 판 마스크를 영역별(몸판·소매·칼라)로 나눠 manifest에 기록해 주세요.
2. **가슴 글씨는 단추 줄에 끊기지 않게**
   - A의 구단 디자인이 작은 가슴 심벌형(하운즈·앵커스 등)이면 얼굴에서도 왼쪽 가슴 작은 심벌로.
   - 큰 워드마크형이면 얼굴 구도에서 글자가 단추 줄을 넘지 않도록 왼쪽 가슴 약칭(예: 첫 글자·짧은 표기)이나 심벌로 대체. 128px에서도 읽혀야 합니다.
   - 실제 유니폼처럼 단추 줄이 글자를 가르는 방식은 얼굴 합성에서는 쓰지 않습니다.
3. **원정 키트 판**: 같은 구조로 원정 오버레이도 11세트. 게임은 홈 기준으로 쓰고 원정은 경기 화면용 예비입니다.
4. 검수 미리보기: 11세트 × 기준 판 2명(홈), 128·256·512 세 크기를 나란히(작은 크기에서 글자·패턴이 뭉개지지 않는지).

## 추가: 소개용 유니폼(A) 주름 수정
- 문제: 44장 모두 주름 모양·위치·세기가 거의 같아서(어깨 아래 대칭 주름, 몸판 가운데 같은 굴곡) 생성 이미지처럼 보입니다. 구단이 달라도 같은 옷을 색만 바꾼 느낌입니다.
- 요청:
  - 장마다 주름을 다르게: 원단 무게(메시·니트), 마네킹 자세, 옷걸이 처짐에 따라 주름 위치·방향·깊이가 자연스럽게 달라지게. 좌우 대칭 주름 금지.
  - 실제 제품 사진처럼 주름은 적고 국소적으로: 겨드랑이·소매 접힘·허리 밑단·단추 줄 양옆의 작은 당김 위주. 몸판 전체에 반복되는 물결 주름 금지.
  - 앞·뒤·홈·원정이 같은 주름 틀을 공유하지 않게. 같은 구단 앞뒤도 다르게.
  - 박음질선(어깨·소매·옆선), 단추 구멍, 원단 짜임(가까이서 보이는 메시 결)을 살려 실물감을 높이기. 과한 광택·플라스틱 같은 매끈함 금지.
  - 디자인(패턴·글씨·색)과 파일 ID·크기·text_slots 좌표는 그대로. 주름 때문에 글자 자리가 휘면 quad를 다시 검증.
- 검수: 44장을 한 판에 나란히 놓은 미리보기와, 같은 위치를 잘라 겹쳐 본 비교(주름이 겹쳐 보이면 불합격).
