# 선수단 정리 모드 종료·실행 접근성

## 확인한 원인

정리 종료와 일괄 방출 버튼이 후보 카드 뒤에 있어 긴 목록을 끝까지 내려야 접근할 수 있었습니다. 로스터가 초과된 상태에서는 종료 버튼 자체를 숨겼고, 선수단 탭을 다시 눌러도 정리 상태가 남았습니다. 작은 화면의 작업 공간 재배치에서 실행 줄이 목록 본문과 함께 이동하는 문제도 있었습니다.

특히 가로 모바일에서는 페이지 버튼 줄을 첫 제목 줄에 합치는 공통 규칙이 정리 실행 줄에도 적용됐습니다. 일반 명단과 패널 높이도 나눠 쓰면서 후보를 읽을 공간이 줄었습니다.

## 수정

- 정리 화면 상단과 하단에 종료 버튼을 제공합니다. 종료하면 선택을 비우고 일반 선수 명단으로 돌아갑니다.
- 선택 인원·정산금이 적힌 일괄 방출과 선택 해제·후보 더 보기·종료를 목록 밖 실행 줄에 배치합니다.
- 정리 화면은 전용 단일 작업 패널로 표시하고, 제목과 실행 줄을 별도로 유지합니다.
- 선수단 탭을 다시 누르면 정리 모드를 종료합니다. 다시 정리하려면 정리 버튼으로 들어갈 수 있습니다.
- 로스터 초과 상태에서도 화면을 나갈 수 있습니다. 인원 제한과 경기 진행 조건은 그대로 유지합니다.
- 기존 방출 결재와 정산 처리를 유지합니다. 종료만으로 선수를 방출하지 않습니다.

## 검증 상태

PC·모바일의 진입, 실제 선택, 결재 취소·실행, 중복 정산 방지, 종료, 로스터 초과 시 제한 유지를 확인하는 `tools/check-roster-cleanup.cjs`를 추가했습니다. 최종 빌드에서 1366×768·390×664·568×320의 실제 2명 일괄 방출과 종료 검사가 통과했습니다. 원문은 docs/updates/2026-11-10-stars-trim/logs/에 보관합니다.

## 답변문

제보 감사합니다. 정리 모드의 종료 버튼과 일괄 방출 실행 줄이 목록 아래에 묻히는 구조를 수정했습니다. 상·하단의 정리 종료 버튼이나 선수단 탭을 눌러 일반 명단으로 돌아갈 수 있고, 선택 인원과 정산금을 확인한 뒤 기존 결재 절차로 방출할 수 있게 개선했습니다. 로스터가 초과돼도 화면에서는 나갈 수 있으며, 경기 진행을 위한 인원 제한은 유지됩니다.
