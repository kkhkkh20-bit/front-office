# 현재 능력 별·잠재력 별 겹침

현재 능력과 잠재력을 같은 별 등급표로 표시합니다. PC 카드·모바일/태블릿 머리말·일반 선수 요약에 현재 능력 별을 추가했습니다. 외국인 후보는 표시된 종합 추정과 같은 값을 별로 환산합니다. 미확인은 `?`이며 숨은 실제 잠재력을 공개하지 않습니다.

별은 최대 5개, 화면 능력치 최고 표시는 100점입니다. 5개는 상위 등급이라는 뜻으로 100점이나 성장 완료율을 뜻하지 않습니다. 잠재력은 스카우트 추정이므로 별 차이만큼 반드시 성장한다는 뜻도 아닙니다. 도움말에 이 기준을 명시했습니다.

‘잠재력 차이 8’은 상무 추천 문구에서 숨은 잠재력과 내부 능력치 차이를 직접 출력하던 경로였습니다. 스카우트가 추정하는 성장 여지에 따른 서술형 설명으로 바꿨습니다. 감독 귀띔의 추정 숫자도 화면 척도로 환산합니다. 성장·노화·경기 결과 수치는 변경하지 않았습니다.

신인 상세 잠재력 별 겹침은 `.kb i`의 설명문 글꼴·위 여백이 금색 채움 층에 적용된 것이 원인이었습니다. 채움 별 전용 클래스로 바탕과 글꼴·줄 높이·원점을 일치시켰습니다.

## 답변문

> 의견 감사합니다. 현재 능력도 잠재력과 같은 별 기준으로 나란히 볼 수 있도록 추가했습니다. 별은 최대 5개이고 화면 능력치 최고 표시는 100점입니다. 다만 별은 등급이며, 잠재력은 스카우트 추정이라 정확한 숨은 상한이나 성장 보장치는 아닙니다. 내부 수치 차이가 그대로 나오던 설명과 신인 상세의 별 겹침도 함께 수정했습니다.
