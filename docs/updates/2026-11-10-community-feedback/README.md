# 커뮤니티 제보 2차 검수

기준 main `12642848`. [항목별 수정 내용·게시용 답변문](../../feedback/2026-11-10-community-batch02.md).

## 완료한 검사

- 신규 규칙: 시즌 행사 예약·실제 홈경기 연결·중복/중단/저장/다음 시즌 만료/이직 장부, FA 계약 만료와 연봉협상 분리, 자동 지명 미확인 중지·확인된 기준 미달 패스.
- UI: 1366×768, 3440×1305, 터치 768×1024, 390×664, 568×320. 세로 원본 상하 색 마커 보존, 사진 복원, 발신자별 독립 설정, 코치 그래프 환산·합류 전 현재 값·설명 겹침, 시즌 운영 버튼, 10구단 결번 표시. 업로드 이미지는 검사 전용 합성 도형입니다.
- 기존 검사: FA 옵션 1개·자동 지명 3개·마케팅 1개 시나리오, Node 테스트 34개, 관련 화면 20개 비율 사례, 저장/가져오기, 인물 연속 이동 4화면, 기존 개인활동·시설·육성·관계 규칙, 정적 점검.
- 시뮬레이션: SEED 7·21로 2036년 1월 1일까지 각 10시즌 진행. 경기·선수·계약·구단 불변식 및 숨은 예외 점검에서 문제 없음. 능력치 표본은 각 11개 시점입니다.

전체 `check.sh`는 실행하지 않았습니다. 전체 1,077개 규칙 검사는 140개 이상 통과한 지점에서 종료하고, 변경 관련 기존 5개 시나리오와 신규 회귀 검사를 완료했습니다. 실물 iOS Safari, 원본 제보 세이브, 운영 배포는 확인 범위에 포함되지 않습니다.

## 재현

```sh
bash build.sh
node tools/check-community-rules.cjs
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node tools/check-community-ui.cjs
RATINGS_FILE=/tmp/ratings.json SEED=7 node tools/check-sim.js 2036
```

장기 측정은 기존 시뮬 검사에 년도별 통계 수집만 추가한 임시 측정본으로 실행했습니다. 같은 수집 경로를 `tools/check-sim.js`의 `RATINGS_FILE` 옵션으로 정리했고, 최초 표본이 일치하는 스모크 검사도 완료했습니다. 표본은 매년 겨울 성장 직후이며, 2026년은 창단 드래프트 직후라 1군 엔트리·외국인 영입 구성이 미완입니다. 1군·외국인 비교는 2027년부터 보는 것이 적절합니다.
