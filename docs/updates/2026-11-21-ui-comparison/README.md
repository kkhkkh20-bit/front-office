# 배포 전 UI 비교

[비교 파일](comparison.html)을 내려받아 브라우저에서 엽니다. 화면·모바일/PC·전후 보기를 고를 수 있으며 `원본 크기`로 글자를 확인할 수 있습니다. 이미지와 코드는 HTML 한 파일에 포함되어 있습니다.

- 기존: main `83de5da92d9c`.
- 개선 코드: `5ca108f574e2`, 브랜치 `codex/mobile-training-medical-1121`, PR #328 초안.
- 6개 화면 × 모바일 390px/PC 1366px = **전후 12쌍**, 실제 Chromium 캡처 24장입니다.
- 홈·소식함·재정이 이번 첫 적용분입니다. 훈련·의료·시설 재원은 같은 브랜치의 앞선 개선을 포함합니다.
- 공개 배포판이나 실제 이용자 저장이 아닌, 양쪽에 동일하게 넣은 검증용 저장입니다. 인터뷰·미읽음·부상·복귀 상태는 재현용으로 구성했습니다.

## 검증

- 실제 렌더러 재현: 홈 3건, 소식함 명확성 3건, 재정 3건은 수정 전 실패를 확인했습니다. 수정 후 홈 3/3, 소식함 4/4, 재정 3/3 통과했습니다. 기존 필터·액션 인자·비용·읽은 미결 상태를 보존하는 검사입니다.
- 실제 캡처 중 홈 제어부 가림과 할 일 행의 설명 겹침을 발견했습니다. 각각 실패 재현을 추가한 뒤 수정했습니다. 홈의 버튼·행 영역·마지막 작업 접근·범위 펼침을 320/390/768/1366px에서 통과했습니다.
- 소식함 상태 배지와 재정 숫자: 320/768px에서 추가로 가로 넘침·잘림을 검사했습니다.
- 전후 비교는 현금·예산·실제 훈련·제안 대기·메일 목록이 같은지 검사합니다. 두 버전의 JavaScript 오류·404·가로 넘침도 확인합니다.
- 빌드 2종·정적 검사, 첫 시즌 단계/위임 회귀 통과. 비교 파일도 12쌍·화면/기기/버전 전환·원본 확대·외부 자원 요청 없음·가로 넘침 검사를 통과했습니다.
- 이전 QUICK 실행은 소스가 바뀌어 중단했으며 완료 통과가 아닙니다. 최종 소스 QUICK는 실행 중이며 GitHub 검사 결과도 별도로 확인해야 합니다.
- 전체 `bash tools/check.sh`, 독립 다년 시뮬레이션, 실제 휴대폰·iOS Safari는 이 변경 묶음에서 미실행입니다. 전체 검증 완료로 보고하지 않습니다.

비교 HTML은 관리형 Chromium의 `file://` 제한 때문에 로컬 HTTP로 열어 조작을 검사합니다. 외부 인터넷 자원을 요청하지 않는 한 파일 구조입니다. 실제 사용자 브라우저의 파일 열기와 터치는 미검증입니다.
