# 게임 전체 UI: 정보와 설명 정리 기준

2026-11-21 사용자 피드백: 훈련 한 화면이 아니라 게임 전체를 OOTP·Football Manager의 정보 배치와 설명 방식에 비춰 점검합니다.

## 참고와 적용 기준

- [OOTP 공식 육성 안내](https://wiki.ootpdevelopments.com/index.php?title=OOTP_Baseball:Screens_and_Menus/Player_Profile/Player_Profile/Development): 훈련 계획과 능력 변화·코치 관계·보고를 나눕니다. 일반 육성과 개발 랩도 구분합니다.
- [FM24 공식 훈련 안내](https://community.sports-interactive.com/sigames-manual/football-manager-2024/training-r4961/): 개인 집중 항목과 훈련 강도·부하를 구분합니다.
- [FM24 Console 공식 훈련 화면 소개](https://www.footballmanager.com/features/football-manager-2024-console-new-features-unveiled): 주간 목표, 훈련 유닛, 부하와 핵심 능력을 별도 영역에 배치합니다.

이 게임에 적용할 설계 기준은 아래와 같습니다. 참고 게임의 규칙이나 화면을 그대로 옮긴다는 뜻은 아닙니다.

1. 화면 첫 부분에서 **현재 상태 → 가능한 행동 → 선택 결과**를 찾을 수 있게 합니다.
2. 자주 비교하는 항목은 같은 이름·순서·단위로 표시합니다. 긴 문장으로 차이를 설명하기보다 항목 자체를 구분합니다.
3. 일반 규칙·수식·배경은 해당 설정 옆의 도움말로 옮깁니다. 선수별 코치 의견과 실제 경고는 일반 설명과 구분합니다.
4. 금액, 기한, 신청 불가 사유, 즉시 발생하는 공석, 되돌릴 수 없는 결과는 조작 가까이에 남깁니다.
5. 버튼 이름은 실제 동작을 말합니다. 창 닫기·제안 철회·계약 체결을 서로 다른 이름으로 씁니다.

## 확인 범위

- 실제 로컬 Chromium 렌더링: 홈, 소식함, 재정, 스폰서, 스카우트, 달력을 각각 390px·1366px로 열었습니다. 12개 화면에 JS 오류와 가로 넘침은 없었습니다. 사용자 저장이나 공개 배포판을 확인한 것은 아닙니다.
- 훈련 화면: 320·390·768·1366px에서 변경 대기 바가 팀 방침을 가리는 현상과 여러 선수를 고를 때 제안 바가 중복되는 현상을 수정 전에 재현했습니다.
- 계약 협상·선수 카드·코치 시장·일정의 개별 기능은 소스와 호출 관계를 점검했습니다. 아래 표 전체를 실제 조작으로 검증한 것은 아닙니다.

현재 화면 기록: [홈](audit-home-current.png) · [재정](audit-finance-current.png). 개선 후 시안이 아니라 문제를 검토할 때 실제로 연 화면입니다.

## 적용 순서와 이번 변경

이번 브랜치에서는 이미 작업 중이던 훈련 화면의 겹침을 먼저 고치고, 선택기를 눌러 펼치도록 정리했습니다. 현재 훈련·코치 추천·강도·제안 대기를 짧게 보여 주고, 일반 안내와 강도별 인원은 따로 펼칩니다. 능력·코치 의견·훈련 보고는 기존 선수 정보에서 볼 수 있습니다. 실제 훈련을 바꾸는 계산과 감독 판정은 유지합니다.

사용자의 후속 적용·배포 전 비교 요청으로 홈·소식함·재정의 첫 개선을 작업 브랜치에 반영했습니다. [같은 상태의 전후 비교](../2026-11-21-ui-comparison/README.md)를 확인할 수 있습니다. 전역 도움말 시스템과 다른 표 항목은 **후속 제안이며 미적용**입니다. 화면마다 기존 결정·필터·장부·동작을 확인한 뒤 작은 단위로 바꾸며, 문장 길이만으로 대량 삭제하거나 일괄 숨기지 않습니다. 아직 병합·배포하지 않았습니다.
