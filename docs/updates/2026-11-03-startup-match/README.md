# 첫 접속·경기 준비·상황별 해설 업데이트

패치 `2026-11-03s`. 아래 이미지는 로컬에서 실제 게임을 재생해 캡처했다.

- 첫 접속은 메뉴에 필요한 파일부터 받는다. 3D 코드와 모델은 경기 진입 때 준비하고, 다운로드 실패 시 재시도 버튼을 보여 준다.
- 우리 경기 직전 중계/결과 선택을 표시한다. 준비 중에는 양 팀 선발 9명과 선발투수의 얼굴·이름·포지션을 먼저 보여 준다.
- 홈은 PC 3열·태블릿 2열·휴대폰 1열로 채우고 페이지 버튼으로 넘긴다. 긴 전체 보고는 따로 열어 내부 스크롤로 확인한다.
- 안타 주자의 도착과 송구·결과 표시를 맞췄다. 홈런은 팔로스루→빠던→주루로 이어진다.
- 캐스터와 해설의 두 줄 자막을 추가했다. 공별 승부, 타구, 송구, 도루와 동점·역전·끝내기·2아웃 적시타에 다르게 반응한다. 공개되지 않은 결과나 임의 홈런 비거리는 말하지 않는다.
- 실제 몸쪽 볼 뒤 드물게 벤치가 나왔다 진정하고 복귀한다. 부상·퇴장 판정은 추가하지 않았다.
- [계약 금액 직접 입력](../2026-11-03-contract/README.md)도 함께 포함한다.

## 확인 결과와 한계

초기 필수 코드·스타일의 gzip 합계는 약 3.38MB에서 1.06MB로 약 69% 감소했다. 첫 HTML은 약 3.8KB이며 메뉴에서는 3D 파일 요청이 없다. 이후 받는 그림·폰트·경기 모델은 이 초기 합계에 포함하지 않는다. 실제 Cloudflare 사이트 로딩 시간이나 사용자 PC FPS 측정값은 아니다.

전체 점검에서 규칙 415개, 능력 반영 2400경기씩 두 세계, 2029년까지 장기 시뮬 세 조건과 휴대폰/전용 화면 검사를 통과했다. PC 홈의 드래프트 순번 타일 누락 한 건으로 전체 스크립트는 실패했다. 타일 복원 뒤 PC 전체 UI 240회 조작과 홈 6개 크기를 다시 통과했다. 이후 해설·표시·패키징 보완은 모듈 18개와 실제 중계 5타구/벤치/빠던/모바일, 완료 타석 기록, 사이트 로딩·실패·재시도 관련 검사를 통과했다.

main 반영과 서비스 배포 완료는 별도다. 실행 환경에서 workers.dev 접속이 제한돼 실제 서비스 배포 성공은 확인하지 못했다. 외부 게시판에는 자동으로 글을 올리지 않았다.
