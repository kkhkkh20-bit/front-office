# 연수·의료 에셋 실제 연결

리뷰 에셋 `assets/design-review/2026-11-10/`의 사진 8장을 실제 게임에 연결했습니다.

- 해외 연수: 5종 비교 목록과 선택 상세. 참가비·동행비·현재 정원·신청 기간·목표 능력은 현재 OVS와 제휴 단계를 읽습니다. 추천 선수 신청과 취소는 기존 `setOvs/ovsRefund`를 사용합니다.
- 교육리그·지원: 특수 아카데미·가을 교육리그·캠프 안내를 별도 내부 탭에서 볼 수 있습니다. 지난 연수 기록과 다른 구단 참가 내역도 유지합니다.
- 모바일: 필수 화면 탭을 검색 필터에 넣지 않습니다. 직접 높이를 나누는 화면도 탭을 한 줄로 정리합니다. 연수 목록 → 상세 → 목록에서 선택과 목록 위치를 유지합니다.
- 의료: PC의 팀 닥터 요약·현재 부상·최근 복귀 표에 사진을 연결하고, 모바일·태블릿은 작은 3단계 요약을 표시합니다. 실제 부상·실제 복귀일을 읽으며 사진으로 진단하지 않습니다.
- 선수 정보의 해외 연수에도 같은 프로그램 썸네일을 사용합니다.
- 배포: 사이트 빌드에 사진 16파일만 포함합니다. 문서·시안·검수판은 배포 목록에 넣지 않습니다. 이미지 주소에는 내용 해시를 붙입니다. 단일 HTML만 받은 경우 사진이 없어도 프로그램 선택과 금액·신청은 사용할 수 있습니다.

## 검증

`tools/check-operations-art.cjs`는 실제 배포 번들을 열어 1440px PC, 1024px 태블릿, 390px 터치 휴대폰에서 탭 노출·사진 로드·신청/환급·실제 복귀일·내부 스크롤을 검사합니다. 사진 404에서도 텍스트와 선택이 유지되는지 확인합니다.

기준 main `8b4b9026`의 순수 엔진과 현재 엔진은 끝의 개행을 제외하면 동일합니다. 전체 규칙 검사에서 ‘상무 복무 선수는 퓨처스 경기에 나간다’ 항목이 실패했고, 원래 main의 HTML에서 추출한 엔진으로 단독 실행해도 같은 실패가 재현됩니다. 이 작업에서는 병역·경기 엔진을 수정하지 않았습니다.

전체 규칙 검사 실행은 위 기준 main 실패를 확인한 뒤 중단했습니다. 전체 검사 통과를 주장하지 않습니다. 실제 에셋 연결·저장/가져오기·정적 검사·PC 높이·모바일 작업 공간·배포 파일 검사는 통과했습니다. 단위 검사 34개 중 32개가 통과했고 모듈 계약 6개도 통과했습니다. 실패한 해설·송구 검사 2개는 원래 main에서도 재현됩니다. 디자인·설정·화면 공간·뷰포트·경험 검사에도 원래 main의 화면 문제와 오래된 선택자 실패가 재현돼 전체 통과로 표시하지 않았습니다.

최종 결과는 [검증 요약](checks/runtime-summary.json)에, 기준 main과 비교한 로그는 `checks/baseline-*.txt`에 있습니다. `relevant.txt`의 초기 저장 검사 실행 오류는 HTTP 서버와 브라우저 경로를 사용하도록 검사 실행기를 보완한 뒤 `save-import-final.txt`에서 통과했습니다. 게임의 저장 처리는 바꾸지 않았습니다.
