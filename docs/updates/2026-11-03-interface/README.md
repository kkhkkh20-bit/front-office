# 화면 구성·진행 방식 수정

## 변경

- PC는 사이드바와 현재 위치·하위 탭으로 구성하고 중복된 상단 주 메뉴를 제거했다. 홈 카드는 화면 크기에 맞춰 묶음별로 표시한다.
- 목록·표·상세 정보는 패널 내부에서 스크롤한다. 표 머리글과 필터를 고정하고 선수 상세를 닫으면 목록의 이전 스크롤 위치를 복원한다.
- 본문·보조 글·패널 제목·화면 제목·큰 수치를 13·12·16·20·24px로 통일하고 표·직원 카드의 행과 여백을 맞췄다.
- 기본 진행은 최대 7일 동안 일반 경기를 자동 계산하고 예약한 경기만 관전한다. 중요한 결정에서는 계속 멈춘다.
- 실제 스카우트 인원·계절·팀장 위임 여부에 따라 할 일을 판단한다. 완료된 업무와 단순 안내가 계속 버튼의 확인 대상으로 남지 않도록 했다.
- 모바일·태블릿에서도 날짜 진행 표시를 현재 보이는 화면 안에 배치하고 반복 진행 시 이전 타이머를 취소한다.
- 웹 배포 CSS의 이미지 경로를 CSS 파일 위치 기준으로 수정했다. 기존 `./assets/images/`는 `/assets/app/assets/images/`로 요청되어 시작 배경과 로고가 모두 404였다. 수정 후 `../images/`로 정상 요청한다.

## 검증 범위

- 모듈·빌드 단위 검사 18개, 문법·정적 검사 통과.
- 33개 메뉴와 모든 보고 묶음: 1366×768, 1920×1080, 1024×768, 390×844에서 내부 스크롤·고정 머리글·선수 상세 복귀 검사 통과.
- 대표 화면의 글꼴 크기·표·직원 카드 정렬 검사 통과.
- 실제 UI로 스카우트 채용·팀장 위임·확인 대상 이동을 검사하고, 모바일·태블릿 가로·세로 및 동작 줄이기 설정에서 계속 버튼과 날짜 표시 검사 통과.
- 주간 진행·예약 경기 관전·중요 결정 중단·이전 저장의 경기 대기 해제 검사 통과. 스카우트 관련 규칙 9개 통과.
- 실제 웹 배포 빌드에서 PC·태블릿·모바일의 시작 배경과 로고 로드, 초기 파일 분리·실패 후 재시도 검사 통과.
- 전체 순차 점검은 완료하지 않았다. 별도 실행한 `check-gameplay.cjs`는 `원본 투수의 측면 준비 자세`에서 실패한다. 수정 전 main(`d690158`)을 임시 디렉터리에 풀어 동일 검사를 실행했을 때도 같은 실패가 발생했다. 이번 변경으로 해결했다고 보고하지 않는다.
