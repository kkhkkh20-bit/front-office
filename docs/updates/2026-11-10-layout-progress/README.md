## 검사 코드 보완

실패한 검사 중 실제 게임 오류와 오래된 검사 가정을 구분했습니다. 해설 검사의 이름 함수와 송구 검사의 구르는 공·유격수·심판 모형을 보완했습니다. 송구는 포구 직후 중계와 베이스 송구가 이어지고, 최종 세이프는 주루 완료 뒤인지 검사합니다. 상무 시나리오는 같은 날을 네 번 반복하던 설정을 실제 4주로 바꾸고 1군 출전 당일 퓨처스 중복 방지도 확인합니다. 3경기 진행 검사는 현재의 시리즈 종료 규칙을 확인합니다. 시리즈가 끝나면 3경기 전에 멈추는 현행 엔진 규칙은 유지했습니다.

터치 검사는 현재 상단 날짜 표시·진행 막대와 실제 일정 카드 선택자를 사용합니다. 교육비 지급 뒤 화면을 갱신하고, 서로 다른 유료 조작을 연속 탭 방지 시간보다 여유 있게 누릅니다. 실제 접속·계속 버튼·터치 스크롤·파일 불러오기·재접속을 검사합니다.
