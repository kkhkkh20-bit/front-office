# 계약 금액 직접 입력과 중계 리뷰

패치: `2026-11-03r`

연봉 협상·FA·비FA 다년계약의 연봉, 계약금, 연간 옵션을 직접 입력한다. 외국인 영입·재계약도 보장 연봉과 인센티브를 같은 방식으로 입력한다. 단위는 억 원이고 소수 둘째 자리까지 허용한다. `1.23`은 1억 2,300만원, `0.01`은 100만원이다. 외국인 계약은 게임의 고정 환산 기준(1만 달러 = 1,400만원)으로 달러 금액을 함께 표시한다.

- 버튼·슬라이더를 유지하고, 버튼은 직접 입력한 끝자리를 보존한다. 슬라이더도 100만원 단위로 조정한다.
- 입력 중 총액·요구 충족·상한 반영을 다시 계산한다. 입력칸은 다시 만들지 않아 포커스와 Tab 이동을 유지한다.
- Enter는 입력을 마치며 제안을 제출하지 않는다. 계약은 제안 버튼으로 진행한다.
- 빈칸·잘못된 숫자·소수 세 자리·최저 연봉 미만·외국인 보장+인센티브 상한 초과는 제출을 막는다.
- 실제 연봉 합의의 기존 500만원 반올림을 제거했다. 요구액·AI 산정·협상 수용 기준은 유지한다.

## 레퍼런스 확인 범위

FM의 계약 조건을 행별로 제시하는 협상 구성을 조사 대상으로 삼았다. [Sports Interactive의 FM 2024 공식 매뉴얼](https://community.sports-interactive.com/sigames-manual/football-manager-2024/)과 Football Manager 공식 사이트에 접근을 시도했으나 이 실행 환경의 네트워크 정책에서 HTTP 403으로 제한됐다. Google 검색도 브라우저에서 자동 요청 확인 화면으로 전환돼 본문과 계약 화면을 검증하지 못했다. FM의 특정 숫자 입력 방식이나 단축키를 확인했다고 주장하지 않는다. 이번 입력 방식·단위·오류 처리는 사용자의 요구와 이 게임의 실제 금액 저장 단위를 기준으로 정했다.

## 함께 고친 경기 문제

수정 전 실제 UI와 렌더러로 재현한 항목이다.

| 문제 | 수정 및 확인 |
| --- | --- |
| 마지막 투구 뒤 일시정지 후 재개하면 스윙 없이 타구가 나감 | 같은 타석 마지막 공부터 재생해 스윙을 다시 연결 |
| 배속 변경 후 기존 타이머·동작이 옛 속도로 남음 | 기존 재생 토큰을 취소하고 같은 타석을 새 배속으로 재시작 |
| 투구 끝과 타구 시작 사이 약 0.95m 위치 차이 | 실제 홈플레이트 통과 좌표를 타격 출발점으로 사용, 차이 0m |
| 땅볼이 첫 프레임에 땅으로 순간 이동 | 타격 높이에서 바운드로 연속 보간 |
| 전광판 확대 후 탐색하면 버튼 글자가 이전 상태 | 장면 초기화 때 버튼 표시도 동기화 |
| 창 비율·화각 변경 후 새 관중석이 누락 | 투영 행렬 변경 시 즉시 시야 재판정 |
| 선수 모델 교체 때 GPU 텍스처가 계속 증가 | 복제된 스켈레톤의 bone texture와 믹서 캐시 해제 |

같은 렌더러에서 타자 유니폼을 네 번 교체했을 때 수정 전 텍스처는 424→447→470→493개로 늘었고 수정 후에는 355→355→355→355개로 유지됐다. 브라우저 소프트웨어 렌더러에서의 재현 수치이며 실제 사용자 PC FPS 측정과 구분한다.

## 검증

- 수정 전: 직접 입력칸 부재, 3D 상태 문제 5개, 시야 변경 누락의 실패 확인.
- `tools/check-contract-input.cjs`: PC/휴대폰의 입력·합계·증감/기간 유지·오류 차단, 실제 연봉/FA/다년계약/외국인 재계약 합의, 외국인 총액 상한.
- `tools/check-match3d-state.cjs`: 실제 기록으로 재개·배속·공 좌표/땅볼·전광판·모델 교체 메모리·장면 해제.
- `tools/test/visibility.test.cjs`: 카메라 이동 없이 창 비율·화각만 바꿔도 즉시 관중석 복원/제외.
- 계약 연봉 정밀도·비정상 숫자 제안 무효의 엔진 회귀 2개.
- 첫 전체 검사는 추가 요구로 중단했고, 이어진 최종 범위 검사에서 규칙 415개·능력 반영·장기 시뮬 3개·계약/중계 관련 검사를 통과했다. PC 홈의 드래프트 타일 누락으로 전체 묶음은 실패했고 수정 뒤 PC 전체 UI를 재통과했다. 최종 결과와 제한은 [후속 업데이트](../2026-11-03-startup-match/README.md)에 기록한다.

main 푸시와 Cloudflare 서비스 배포 완료는 별도다. 이 환경에서는 workers.dev 직접 접속이 정책으로 막혀 실제 서비스 배포 성공은 확인할 수 없다.
