# 경기 화면 에셋 검토 (2026-11-03)

사용자 선호: 경기 중 왼쪽 앱 탐색 메뉴는 숨기고 실제 상단바는 유지한다. 타자 뒤에서 투수를 보는 시점이 우선이지만, 컴프매·백년야구처럼 위에서 내려다보는 방식도 허용했다. 기존 게임의 그림을 가져오는 요청은 아니다.

## 권장 구현

우선 기존 에셋을 활용하는 위에서 본 2D 중계를 개선한다. 구장과 선수 움직임을 중심에 두고, 현재 타자·투수 카드와 우측 하단 3×3 투구판·B/S/O를 결합한다. 투구판에는 존 밖의 볼도 표시할 여백을 둔다. 수비·주루는 기존 경기 기록의 이동 결과에 연결한다.

앞서 생성한 사실적인 타자 뒤 시점 이미지는 구도 제안이다. 해당 이미지는 재사용 가능한 선수 모델·애니메이션·구장 세트가 아니다. 같은 수준의 3D를 구현하려면 야구 유니폼 선수 모델, 좌우 투타 동작, 포수·심판 자세, 수비·송구·주루 동작, 구장 모델과 브라우저 렌더링 작업이 별도로 필요하다. 현재 그런 일체형 패키지를 확보했다고 보고하면 안 된다.

현재 `cPitchSeq`는 타석의 최종 결과를 바탕으로 구종·구속·카운트를 재구성하는 **연출**이다. 실제 투구 위치는 기록하지 않는다. 향후 3×3 투구판을 붙일 때는 실제 기록과 연출을 구별해야 한다. 임의 좌표를 실제 관측값처럼 표시하지 않는다. 진짜 투구 기록으로 제공하려면 시뮬레이션·저장·재생 구조를 함께 변경하고 기존 저장과의 호환을 검증한다.

## 이번에 반영한 범위

경기 중 `.cast-page-open`으로 앱의 왼쪽 탐색 메뉴만 숨긴다. 실제 상단바와 휴대폰 하단 탐색은 유지한다. 헤더·사이드 영역을 측정하는 기존 `appFrameSync`를 통해 경기 본문이 왼쪽 끝까지 넓어진다. 선수 상세·일반 화면으로 이동하면 메뉴가 복원된다. 카메라·투구판·경기 계산은 이번 변경에 포함하지 않는다.
