## 2. 무엇을 보내나요

웹판(사이트, itch.io 등 브라우저에서 실행하는 판)은 게임을 다듬기 위해 다음 플레이 기록을 Google Analytics 4로 보냅니다.

| 항목 | 내용 |
| --- | --- |
| 무작위 기기 번호 | 처음 실행할 때 브라우저에 만들어 저장하는 무작위 문자열(`dsj_uid`). Google Analytics의 사용자 ID로 씁니다. 이름이나 계정과 연결하지 않습니다. |
| 화면 이동 | 어느 화면에서 어느 화면으로 갔는지, 머문 시간 |
| 기능 사용 | 트레이드 제안, FA 협상과 계약 금액, 드래프트 지명, 훈련·보직 설정, 감독 선임 등 게임 안 동작과 그 수치 |
| 진행 정보 | 게임 버전과 배포 번호(커밋·빌드), 게임 날짜와 연차, 고른 구단 번호, 시작 단계(구단 고르기, 창단 드래프트, 시즌 개막 등), 새 게임의 시작 방식(단장 취임·창단 드래프트)·난이도·쉬운 진행·첫 시즌 안내 여부 |
| 오류 | 오류 메시지 앞 200자, 오류가 난 파일과 줄, 그때 화면 |
| 로딩(사이트판) | 게임을 여는 데 걸린 시간, 여는 중에 받지 못한 파일이나 난 오류(앞 100자), 열리기 전에 창을 닫았는지 |
| 앱 안 브라우저 안내 | 카카오톡·네이버 등 앱 안 브라우저로 열었을 때 안내가 떴는지, 어느 단추(Chrome으로 열기·주소 복사·닫기)를 눌렀는지, 앱 종류(브라우저 정보로 판별)와 운영체제 종류. 주소 복사는 기기 안에서만 하고 보내지 않습니다 |
| 세션 | 플레이 시간, 읽은 소식 수, 진행 횟수, 마지막 화면 |

Google Analytics 스크립트는 이와 별도로 쿠키(`_ga` 등), 접속 IP 주소, 브라우저·기기 종류, 화면 크기, 언어, 유입 경로 같은 정보를 Google로 보냅니다.

**보내지 않는 것**: 단장 이름 등 플레이어가 입력한 글, 저장 파일 내용, 사진. 다만 플레이어가 "기기 옮기기 코드 만들기"를 누르면 그 저장(단장 이름·메모 포함)을 게임 서버에 최대 7일 보관하고, 다른 기기에서 한 번 불러오면 바로 지웁니다(아래 표, `docs/save-transfer.md`). 플레이어가 **클라우드 저장을 켠 경우에만** 저장 본문을 게임 서버에 보관합니다(6항).

## 5. 끄는 방법

- 처음 화면 > 설정, 또는 게임 안 설정의 **플레이 기록** 카드에서 '끄기'를 누르면 그 뒤로 보내지 않습니다. 설정은 그 브라우저에 저장됩니다.
- 내려받은 파일(`file://`)로 실행하거나 내 컴퓨터(localhost)에서 실행하면 보내지 않습니다.
- 유저 래더 자동 참가(구단 1군 스냅샷·구단명·닉네임)는 게임 안 **설정 › 래더**의 '자동 참가 끄기'로 끕니다(7항).
- 브라우저 설정에서 쿠키와 사이트 데이터를 지우면 무작위 기기 번호도 지워집니다. 다음 실행 때 새 번호가 만들어집니다.
- 이미 보낸 기록의 삭제 요청은 1항의 문의처로 해 주세요. 무작위 기기 번호를 알려 주시면 찾아 지울 수 있습니다. [GA4 사용자 삭제 절차 확인]

## 6. 게임 저장 데이터

게임 저장은 기본으로 플레이어 브라우저(localStorage, IndexedDB)에만 남고 운영자 서버로 보내지 않습니다.

**클라우드 저장을 켠 경우에만**(설정 › 저장의 '클라우드 저장 켜기', 기본 꺼짐) 여러 기기에서 같은 저장을 이어 하기 위해 게임 서버(Cloudflare R2·D1, 코드 `worker/v1/cloud.js`)에 다음을 둡니다. 켤 때 화면에서 무엇을 올리는지 알립니다. 가입은 없고, 유저 래더와 같은 익명 플레이어 번호·기기 토큰(7항)을 씁니다.

| 항목 | 내용 |
| --- | --- |
| 저장 본문 | 게임 저장 전체(단장 이름·슬롯 메모 등 플레이어가 입력한 글 포함). 게임 세계마다 하나, 최대 3개, 각 최근 3판 |
| 저장 정보 | 게임 날짜·구단 이름·세계 번호, 게임 버전, 크기·해시, 이 기기에서 저장한 시각, 올린 시각 |
| 기기 | 기기 이름(브라우저 정보로 만든 "Windows · Chrome" 같은 이름), 플랫폼, 마지막 사용 시각 |
| 연결 코드·복구 코드 | 서버에는 SHA-256 해시만 둡니다. 연결 코드는 10분·한 번, 복구 코드는 한 번 쓰거나 새로 만들면 무효 |
| 하루 올리기 횟수 | 남용을 막기 위한 플레이어별 하루 횟수 |

- 운영자(관리자 화면 포함)는 저장 본문을 읽지 않습니다. 관리자 화면에는 전체 슬롯 수·용량·올리기 횟수만 보입니다.
- 보관: 플레이어가 클라우드 슬롯을 지우거나 서버 기록을 지울 때까지. [장기 미접속(제안: 마지막 접속 뒤 1년) 자동 삭제는 아직 구현 전]
- 끄기: 설정 › 저장의 '이 기기에서 클라우드 저장 끄기'(그 뒤로 이 기기에서 올리지 않음, 이미 올린 저장은 남음). 클라우드 슬롯의 '지우기'는 그 슬롯의 모든 판을 지웁니다.
- **지우는 방법**: 7항의 **서버 기록 지우기**를 하면 클라우드 저장(R2 본문)·연결된 기기도 함께 지웁니다.

## 7. 유저 래더 서버 기록

유저 래더(주 메뉴 › 래더)는 다른 유저 덱과 리그를 치르기 위해 게임 서버(Cloudflare D1, 코드 `worker/v1`)에 다음을 둡니다. 경기는 플레이어 기기에서 돌고, 서버는 결과 요약만 받습니다.

**래더 자동 참가(2026-11-18부터, 기본 켜짐)**: 커리어 게임을 하는 동안 지금 구단 1군(26명) 스냅샷을 래더 덱으로 자동 등록합니다. 가입은 없고, 처음 한 번 익명 플레이어 번호·기기 토큰을 조용히 만듭니다(클라우드 저장과 같은 것). 하루 한 번(그날 처음 게임을 켜거나 날짜를 넘길 때)과 시즌이 끝날 때, 덱이 바뀐 경우에만 보냅니다. 처음 자동 참가할 때 화면에 "래더에 자동 참가합니다(구단 1군 스냅샷·구단명만 올라갑니다)"라고 알립니다. 그 밖에는 직접 덱을 등록하거나(하루 1회) 리그를 마칠 때·리그 라운드가 끝날 때(진행 상황) 보냅니다.

- **자동 참가 끄기**: 설정 › 래더의 '자동 참가 끄기'. 끄면 서버의 내 래더 덱과 진행 중 리그 기록을 지우고(`PUT /api/v1/ladder/auto`), 이 기기에서 더는 자동으로 올리지 않습니다. 시즌 기록·결과는 남습니다(전부 지우려면 아래 '서버 기록 지우기'). 끈 사람 수는 관리자 집계에 숫자로만 나옵니다.

| 항목 | 내용 |
| --- | --- |
| 익명 플레이어 번호 | 서버가 만든 무작위 번호(`p` + 16자). 이름·계정·기기 번호(`dsj_uid`)와 연결하지 않습니다. |
| 기기 토큰 | 이 기기를 알아보는 무작위 열쇠. 기기(브라우저 localStorage `fo-net-v1-token`)에만 원문이 있고, 서버에는 SHA-256 해시만 둡니다. |
| 닉네임 | 직접 정한 닉네임(설정 › 래더, 하루 1회 바꿈). 정하지 않으면 `구단명#4자리 태그`(예: 부산 자이언츠#3812, 태그는 이 기기에서 무작위로 한 번 정함). 단장 이름(실명일 수 있음)은 보내지 않습니다. 예전에 단장 이름으로 만든 닉네임은 처음 자동 참가할 때 한 번 `구단명#태그`로 바꿉니다. 순위표·소식·상대 목록에 보입니다. |
| 세계 번호 | 이 저장의 무작위 번호(`G.wid`). 예전 래더 덱을 옮기고 같은 덱이 두 번 나오지 않게 하는 데만 씁니다. |
| 덱 | 등록한 로스터(선수 이름·능력치·연봉·타순·보직, 팀명·구단명). 사진은 보내지 않습니다. 자동 등록인지 직접 등록인지, 연봉 상한 안인지, 마지막 직접 등록한 날을 함께 둡니다. |
| 기기 표식 | 이 브라우저에서 무작위로 한 번 만든 번호(localStorage `fo-net-v1-dev`). 서버에는 해시 앞 16자만 두고, '같은 기기에서 여러 덱' 같은 이상 감지(관리자 화면)에만 씁니다. 이름·IP·광고 번호와 연결하지 않습니다. |
| 진행 중 리그 | 리그 단계·라운드·포스트시즌 여부·참가 팀 이름(상대 유저 번호)·그때 순위표. 리그가 끝나면 지웁니다(관리자 '리그 상황'). |
| 리그 결과 | 순위, 승·무·패, 단계, 시즌 포인트, 상대 유저별 승패(맞대결), 승격·우승 소식, 시각, 플랫폼(web·android·steam), 리그 순위표(팀 이름·승패)와 우승·준우승 팀 이름(결과 대조) |

- IP 주소는 저장하지 않습니다(요청 횟수 제한을 위해 해시를 서버 메모리에 잠깐 둡니다).
- 보관: 플레이어·덱은 지울 때까지, 리그 결과 180일, 소식 60일, 하루 집계(사람을 알 수 없는 숫자) 400일.
- 예전 래더 서버(Workers KV, `/api/ladder`)에는 세계 번호별로 덱과 단계가 남아 있습니다. 새 서버가 덱이 모자랄 때 상대로 읽어 옵니다.
- **지우는 방법**: 유저 래더 › 순위 탭(또는 내 덱 탭)의 **서버 기록 지우기**. 새 서버의 플레이어·덱·시즌 기록·결과·맞대결·소식(다른 유저 쪽에 남은 나와의 맞대결 포함)과 이 세계의 예전 래더 덱을 지웁니다(서버 `DELETE /api/v1/player`, `DELETE /api/ladder/deck/세계번호`). 그 뒤 이 기기에서는 서버 래더를 끄고, '서버 래더 다시 켜기'를 누르기 전에는 다시 보내지 않습니다. 이 기기의 리그 기록은 남습니다.
- 서버로 보내지 않으려면: 설정 › 래더에서 자동 참가를 끄고 서버 기록 지우기를 하거나, 내려받은 파일로 실행합니다(래더 서버에 연결하지 않습니다).
