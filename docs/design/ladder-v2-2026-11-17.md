# 래더 v2 기획서 — 2026-11-17

구단주 요청: "래더를 제대로 컴프매처럼 좀 기획해서 이쁘게 구성해줘 화면 페이지 등. 디테일한 데이터 뽑아보게해 계속적으로 우리선수나 래더 선수구성이나 등", "하나의 메인화면 탭으로 뺄수도 있으니까".

모바일 야구 매니저 게임의 래더(단계 문장·시즌 진행·승강 리그·순위표·결과 하이라이트·기록 화면)를 참고했지만, 이름·그림·화면은 우리 게임 것으로 새로 만들었습니다. 어두운 화면, 팀 색, 기존 카드·표 부품을 그대로 씁니다.

## 1. 자리와 화면 지도

래더는 **주 메뉴 '래더'**(방패 아이콘)입니다. PC는 왼쪽 메뉴 '리그' 아래, 휴대폰은 '메뉴' 시트에 있습니다. 예전 자리(구단 › 유저 래더)를 누르면 로비로 갑니다.

| 하위 탭 | 목적 | 보여 주는 것 |
|---|---|---|
| **로비** | 들어오자마자 "지금 무엇을 할지" | 단계 문장(단계마다 다른 방패 그림), 덱 이름·OVR, 시즌 남은 시간, 시즌 포인트·단계 순위(서버) 또는 시즌 리그·최고 점수(이 기기), 큰 버튼 하나(덱 등록 / 리그 시작 / 이어 하기), 진행 막대, 승강 사다리(내 자리·승격·강등 자리), 시즌 목표 5개, 최근 리그 띠(순위·승강), 이번 시즌 우리 선수 상위, 배지 |
| **리그** | 리그 진행과 결과 | 진행 중: 다음 연전·끝까지·덱 고치기·다음 상대 비교·명경기, 순위표 / 일정·결과(라운드별, 우리 연전 강조, ▶로 중계·박스) / 리그 기록(진행 중 1위 기록·상대별 전적), 상대 덱. 끝난 뒤: 승강 배지·리그 점수·MVP, 최종 순위(득실 포함) / 일정·결과, 하이라이트 |
| **덱** | 등록과 내 선수 상태 | 덱 등록·갱신, 덱 성향(거포형·교타형·기동력형·수비형·선발 왕국·불펜 야구·균형형)과 단계 평균 비교, 타순·벤치·선발·불펜 카드(얼굴·OVR·**선수마다 래더 기록**: 통산/이번 시즌), 도전 덱 |
| **기록·데이터** | 계속 쌓이는 데이터 | ① 우리 선수: 타자 G/PA/AVG/OBP/SLG/OPS/HR/RBI/SB, 투수 G/GS/IP/ERA/WHIP/K9/W-L/SV, 머리글 정렬, 시즌·단계·포지션 거르기, 줄을 누르면 시즌별 ② 팀 기록: 시즌별 승패·승률·평균 순위·최고 단계·승강·우승·점수·득실 + 리그 흐름 그림 + 단계별 통산 ③ 선수 구성(메타): 내 단계/전체, 포지션별 OVR 평균·분포·우리 덱, 단계별 평균 덱 OVR, 외국인 비율, 나이 분포, 많이 쓰는 덱 성향, 우리 덱 vs 평균 ④ 상대 분석: 만난 덱별 전적·득실·OVR·성향, 고르면 강점·약점 막대와 서버 맞대결 ⑤ CSV 내보내기(타자·투수·리그·시즌·상대) |
| **순위** | 경쟁 | 내 시즌 카드(포인트·순위·칭호·라이벌), 순위표(단계별 / 전체 / 지난 시즌, 내 줄 강조), 최근 소식, 내 시즌 최고 기록 |

관리자 '래더 현황'에 **덱 구성(메타)** 칸과 **CSV 내보내기**(등록 덱·리그 결과)를 더했습니다.

## 2. 데이터

| 어디 | 무엇 | 한도 |
|---|---|---|
| 저장 `G.uld.ps` | 우리 선수 리그 기록. 선수 → (시즌·단계) 칸 → 타격 14칸·투구 12칸 합계 | 선수 120명(오래 안 나온 선수부터 뺌), 선수마다 칸 24개 |
| 저장 `G.uld.opp` | 상대 덱별 리그 수·승패·득실·OVR·성향·덱 구성 요약 | 60팀(오래된 상대부터) |
| 저장 `G.uld.seas/seasons`, `hist` | 시즌 칸에 승·패·무·득점·실점·강등·순위 합, 리그 줄에 승패·득실·점수 | 시즌 26, 리그 200(예전 그대로) |
| 저장 `G.uld.last` | 끝난 리그 팀·연전(일정·결과 다시 보기) | 1개 |
| 서버 D1 `deck_meta` | 덱마다 구성 요약(약 300바이트) | 플레이어당 1줄 |

- 예전 저장(v1)은 래더를 처음 열 때 옮깁니다(빈 칸 만들기 + 마지막 리그 승패 채우기). 난수를 쓰지 않고, 여러 번 해도 같습니다.
- 래더 리그는 본게임 난수·세계를 건드리지 않습니다(점검이 G에서 `uld`를 뺀 나머지가 그대로인지 봅니다).
- 계산은 공용 모듈(`src/core/uladder.mjs`: `ulPsAdd`, `ulPsRows`, `ulDeckMeta`, `ulMetaAgg`, `ulMissions`, `ulCsv`, `ulMigrate`)에 있어 화면과 서버가 같은 식을 씁니다.

### 서버(무료 플랜 기준)

- `GET /api/v1/ladder/meta?tier=N|all`: 최근 45일 덱 요약을 최대 400줄 읽어 집계합니다. Cache API 10분. 요약이 없는 예전 덱은 요청 한 번에 20개까지만 본문에서 만들어 채웁니다. 표가 없으면 처음 쓸 때 `CREATE TABLE IF NOT EXISTS`로 만듭니다(`migrations/0002_deck_meta.sql`과 같은 문장).
- `GET /api/v1/ladder/leaderboard?tier=all`: 전체 순위(높은 단계 먼저). 60초 캐시.
- 관리자 `GET /api/v1/admin/export?kind=decks|results`: CSV용 줄 최대 2000개.
- 서버가 없으면(KV 길) 메타는 이 기기에서 만난 덱으로, 순위는 이 기기 시즌 기록으로 보여 줍니다.

## 4. 미룬 것

- 매일 미션·보상(재화가 없는 게임이라 보상 설계부터 필요합니다).
- 서버에 선수 기록 올리기(지금은 이 기기 기록. 기기 옮기기로 함께 옮겨집니다).

- 리그 다시 보기(모든 경기 중계 저장)는 저장 크기 때문에 명경기 3경기만 둡니다.
