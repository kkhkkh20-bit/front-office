# 프런트컵 주최 안내 (관리자 페이지)

프런트컵은 **한 번 여는 대회**입니다(정기 일정 없음). 다음에 또 열면 대회 id만 새로 정합니다(`cup2`…).
주최는 게임 안의 **관리자 페이지**에서 합니다. 터미널은 필요 없습니다.

- 형식: 10팀 리그 → KBO식 가을야구
  - 리그: 짝마다 3연전 한 번씩(홈·원정·홈), 팀당 27경기. 모든 구장 같은 규격, 홈 어드밴티지 없음.
  - 순위: 승률(무승부 제외) → 동률 팀끼리 맞대결 → 득실차.
  - 와일드카드: 4위 vs 5위, 최대 2경기. 4위가 1승을 안고 시작해 한 번 이기거나 비기면 진출.
  - 준PO 3위(5전3선승) → PO 2위(5전3선승) → 한국시리즈 1위(7전4선승).
  - 10팀이 안 되면 리그 평균 AI 구단으로 채웁니다. AI는 개인 타이틀·칭호를 받지 않습니다.
- 경기는 본게임과 같은 평범한 난수로 돕니다. 같은 참가 덱이라도 다시 돌리면 결과가 달라집니다. **주최자가 돌린 그 결과가 공식 결과**입니다.

---

## 0. 처음 한 번만

1. **cup-kit을 main에 합칩니다.** main에 올라가면 Cloudflare가 사이트와 Worker를 새로 배포합니다.
   확인: `https://fronttime.kkhkkh-20.workers.dev/release.json`의 빌드가 새것인지 봅니다.
2. **관리자 키(CUP_ADMIN)를 Cloudflare에 한 번 등록합니다.** 길고 아무도 모르는 값(예: 32자 무작위).
   - 대시보드: Cloudflare › Workers & Pages › `fronttime` › Settings › Variables and Secrets › Add › 종류 **Secret**, 이름 `CUP_ADMIN`, 값 입력 › Deploy.
   - (또는 명령: `npx wrangler secret put CUP_ADMIN`)
   - KV는 기기 옮기기와 같은 `SAVE_KV`를 씁니다. `wrangler.jsonc`는 고치지 않습니다.
3. **게임에 같은 키를 넣습니다.** 웹 사이트에서 게임 › 설정 › 정보(PC는 설정 오른쪽 아래) 맨 아래 작은 글자 **관리자** → 키 입력 → 확인.
   처음 화면 › 설정 맨 아래에서도 됩니다. 키는 이 기기 브라우저에만 남습니다. 키가 틀리면 관리자 메뉴가 나오지 않습니다.
   다 쓴 기기에서는 '관리자 키 지우기'를 누릅니다.

## 1. 대회 만들기·접수 열기 (관리자 페이지 1번 칸)

- 대회 id(`cup1`), 대회 이름, 접수 마감(한국시간 `2026-12-05 21:00`), 팀 수(기본 10), 참가 자격(최소 시즌, 1군 연봉 합 상한).
- **접수 열기**를 누르면 게임의 구단 › 프런트컵에 '대회 참가 신청' 버튼이 보입니다. 마감 뒤 서버 신청은 자동으로 거절됩니다.
- **접수 닫기**로 언제든 닫습니다. 참가팀 명단(누구나): `…/api/cup/entries.html`

## 2. 접수 현황 (2번 칸)

- **신청 목록 받기**: 팀명 연도 · OVR 총|투수 타자 · 신청 시각 · 이상치(능력 85 초과, 나이·잠재력 범위 밖, 해시 불일치)·자격 미달 표시.
- 팀을 펼치면 덱(타순·선발·불펜·감독·얼굴)을 봅니다. **제외 / 다시 넣기**로 정리합니다.
- 서버 신청이 안 된 유저는 '참가 파일 저장'으로 받은 `frontcup-…json` 파일을 보냅니다. 받은 파일은 **파일로 받은 참가 덱 올리기**로 넣습니다(여러 개 한 번에).
- 10팀이 넘으면 OVR 순 상위 10팀이 나갑니다. 미리 제외로 정리하세요.

## 3. 대회 돌리기 (3번 칸)

- 접수를 닫고 **시드 확정 + 돌리기**. 이 브라우저에서 리그 27경기 + 가을야구를 몇 초 안에 돌립니다. 모자란 자리는 AI 구단이 채웁니다.
- 돌린 결과 전체(경기 기록 포함)는 서버의 관리자 전용 자리에 저장됩니다. 공개 전에는 아무도 볼 수 없고, 다른 기기에서 키를 넣으면 이어서 공개할 수 있습니다.
- **공개를 시작하기 전까지는 다시 돌리기**를 할 수 있습니다. 1일차를 공개한 뒤에는 바꾸지 않습니다.

## 4. 결과 공개(연재) (4번 칸)

| 날 | 공개되는 것 |
|---|---|
| 1일차 | 참가팀·진행 방식·전력표 |
| 2일차 | 리그 1~3라운드: 결과·순위·주간 MVP·명경기 |
| 3일차 | 리그 4~6라운드 |
| 4일차 | 리그 7~9라운드 + 최종 순위·가을야구 진출·개인 1위 |
| 5일차 | 와일드카드 + 준PO |
| 6일차 | PO |
| 7일차 | 한국시리즈 + 최종 결과 |

- **공개**를 누르면 게임의 구단 › 프런트컵 '진행' 칸에 그날까지의 글·순위·경기가 보이고, 그날 경기의 문자 중계·박스·줄 점수가 올라갑니다(유저는 경기 번호로 봅니다. 게임이 다시 돌리지 않습니다).
- **글 복사**: 그날 카페 글을 복사합니다(복사가 막힌 브라우저는 글 상자가 열립니다).
- **그림 저장**: 순위표 · 가을야구 · 우승 로스터 카드(PNG).

## 5. 명예의 전당 등록 (5번 칸)

- 7일차까지 공개한 뒤 우승·준우승이 확정됩니다. **우승 단장 이름**(비우면 팀명)·준우승 단장 이름을 넣고 **명예의 전당에 등록**. 다시 누르면 수정됩니다.
- 처음 화면 메뉴 · 설정 › 정보 · 구단 › 프런트컵의 **프런트컵 명예의 전당**에 우승 단장·우승 덱(타순·선발·불펜·감독·OVR·얼굴)·준우승이 보이고, 유저는 **이 덱 가져오기**로 우승 덱을 도전 덱으로 가져갈 수 있습니다(내 덱으로 등록은 안 됩니다).
- 지난 회차 기록은 그대로 남습니다. 우승·준우승 저장에는 칭호가 붙습니다(전력 영향 없음, AI 제외).

## 다음 회차

1번 칸에서 대회 id를 `cup2`로 바꿔 저장 → 접수 열기. 나머지는 같습니다.

## 예비 길: 주최 도구(터미널)

관리자 페이지를 쓸 수 없을 때만. `bash build.sh --engine-out dist/engine.js`, `export CUP_ADMIN=키` 뒤
`node tools/cup-host.cjs init|pull|add|list|drop|seed|run|status|publish` (사용법은 파일 머리말). `publish`는 설정·경기 기록·명예의 전당(우승 덱 포함)을 한 번에 올립니다(날짜별 연재는 없음).
