# 래더 v4 기획 — 2026-11-18 (구단주 확정)

래더 = **내 커리어 구단이 다른 유저 구단들 사이에서 어느 수준인지 실제 리그처럼 겪어 보는 상설 리그.** 공식 대회(프런트컵)는 운영자 승인 이벤트로 따로 둔다.

## 1. 자동 등록 (모든 유저 덱)

- **등록 단추 없이 자동**: 커리어 게임을 하는 모든 유저의 지금 구단 1군 26명을 래더 덱으로 자동 등록한다. 클라우드 저장과 같은 익명 플레이어 토큰을 조용히 만든다(가입 없음).
- **갱신 시점**: 하루 한 번(그날 처음 게임을 켜거나 날짜를 넘길 때), 그리고 시즌이 끝날 때. 바뀐 게 없으면 올리지 않는다.
- **이름**: 닉네임을 정하지 않은 유저는 `구단명 + 4자리 태그`(예: 부산 자이언츠#3812)로 보인다. 단장 이름(실명일 수 있음)은 쓰지 않는다. 닉네임은 래더 화면에서 언제든 바꾼다.
- **알림과 끄기**: 처음 한 번 "래더에 자동 참가합니다(구단 1군 스냅샷·구단명만 올라갑니다)" 안내. 설정 › 래더에서 '자동 참가 끄기'(끄면 서버 덱 숨김·삭제). 개인정보 처리방침에 항목 추가.
- **연봉 상한 없음**(구단주 11-18 "래더는 일단 상한을 두지 말고 자유롭게"): 자동·직접 등록·서버 검사 모두 연봉 상한(over_cap·no_pay·cap_ok·pay_x)을 보지 않는다. PR #237의 덱 제한 bad_ovr(정상급 과다)·bad_pay(연봉 합 불일치)도 래더에서는 뺐다(프런트컵 신청에는 그대로, 같은 cupAnomaly 경로라 strict 깃발로 나눔). 남은 거절: 편집된 저장(edited), 능력치 20~80 밖(bad_rating), 덱 형식(cupValidate). `ladder_reg.cap_ok`·`pay_x` 열은 남기고 1·null로만 적는다.
- **직접 등록**: 자동 등록과 별개로, 원하면 '지금 덱으로 다시 등록'을 하루 1회.

## 2. 리그 한 번 (지금 개편분)

1. 같은 단계 덱 10개(유저 덱 우선, 모자라면 AI 덱).
2. 정규시즌 9라운드 × 3연전(덱당 27경기), '다음 3연전'으로 공개.
3. 포스트시즌 상위 4팀: 준결승 3전2선승, 결승 5전3선승. 정규 1위·우승·준우승 기록.
4. 결산: 리그 시상, 승강, 시즌 포인트, 리그 리포트 한 장.

## 3. 단계·승강

- 5단계(루키·마이너·1부·챔피언스·레전드).
- 정규 1·2위 승격, 9·10위 강등. **우승팀은 순위와 무관하게 승격**(이미 승격권이면 추가 효과 없음).
- 14일 시즌 종료: 단계별 최종 순위·칭호, 다음 시즌은 한 단계 낮춰 시작(지금 규칙).

## 4. 숫자로 체감

- 리그 안: 순위표(게임차·연승·득실·기대 승률), 팀 기록(리그 순위·평균 대비), 개인 순위, 팀별 선수 기록, 박스스코어, 라운드 소식.
- 덱 리포트: 단계 안 전력 백분위(타선·선발·불펜·수비), 예상 순위 ↔ 실제 순위.
- 서버 기록실: 시즌별·단계별 개인 기록 순위, 최다 우승, 우승 벽, 첫 화면 공지띠.

## 5. 보상 (능력치·돈 없음)

| 조건 | 보상 |
|---|---|
| 리그 우승·준우승·정규 1위 | 앨범 기념 카드, 래더 전적 표시 |
| 시즌 단계별 1~3위 | 칭호(닉네임 옆), 래더 명예의 전당 |
| 서버 개인 기록 1위 | 기록실 영구 등재, 해당 선수 카드 배지(커리어 선수 화면에도 표시) |
| 첫 승격·첫 우승·레전드 도달 | 업적 |
| 시즌 레전드 1위 | 커리어 구단 구장 장식 1종(꾸미기) |

## 6. 반복할 이유

- 자동 갱신 덱 → 커리어가 진행되면 래더 덱도 따라 강해진다.
- **라이벌**: 같은 상대와 3번 이상 만나면 맞대결 전적과 '라이벌' 표시, 다음 맞대결 소식에 강조.
- **시즌 마감 소식**: 종료 2일 전 단계별 1위 경쟁 소식(카페 공지 문구로도 씀).

## 7. 프런트컵 연결

- 래더는 상설 랭킹, 프런트컵은 운영자 승인 대회.
- 관리자 설정 '래더 단계 시드': 챔피언스 이상(직전 시즌 기준)은 본선 직행, 그 아래는 예선. 끄면 지금처럼 승인만.

## 8. 서버·비용

- 자동 등록으로 덱 수가 크게 는다(활성 유저 수만큼). 덱 본문 약 8KB, 하루 1회 갱신 → 1,000명이면 하루 쓰기 약 1,000줄·8MB. D1 무료 한도 안.
- 리그 결과·기록 업로드는 리그당 수 KB.

## 9. 순서

1. (진행 중) 3연전·포스트시즌·10팀 기록·서버 기록실·예상 순위.
2. 자동 등록·닉네임 태그·끄기·처리방침, 우승팀 승격, 하루 1회 재등록.
3. 보상(카드·칭호·업적·배지·구장 장식), 라이벌, 시즌 마감 소식, 프런트컵 시드.

## 10. 관리자 한눈 보기 (구단주 요청 11-18)

관리자 화면 '래더 현황'을 한 페이지 대시보드로 키운다. 지금 있는 집계(활성·새 덱·완료 리그·단계 분포·사용량)에 더해:

- **등록 현황**: 단계별 등록 덱 수(자동/직접 구분), 오늘·7일 새 등록, 자동 참가를 끈 유저 수. (11-18: 관리자 대시보드로 확장 — docs/design/ladder-admin-dashboard-2026-11-18.md)
- **덱 목록**: 닉네임·구단·단계·덱 OVR·마지막 갱신·진행 중 리그 수. 검색·단계 필터, 숨기기·삭제(지금 기능).
- **리그 상황**: 지금 진행 중인 리그 목록(단계·참가 덱·몇 라운드째·포스트시즌 여부), 최근 끝난 리그(우승·준우승·정규 1위), 클릭하면 그 리그 순위표·기록.
- **시즌 판**: 단계별 시즌 순위 상위 10, 서버 기록 1위들, 이번 시즌 남은 날.
- **이상 감지**: 결과 대조 불일치, 비정상 승률(예: 27전 27승 연속), 같은 기기에서 여러 덱.
- 30초마다 새로고침, 한 화면(PC 스크롤 없이 칸 안 스크롤), 휴대폰에서도 볼 수 있게.

## 11. 래더 기록 세분화 (구단주 11-18 "통계랑 이런 것들 좀 더 세밀하게")

- 리그 팀 기록: 타격 AVG/OBP/SLG/OPS/HR/SB/R/BB%/K%, 투구 ERA/WHIP/K9/BB9/HR9/FIP(리그 ERA에 맞춘 상수)/K/BB/실책. 칸마다 리그 순위, 우리 덱 vs 리그 평균 14개.
- 팀 페이지 선수 시즌 전체 줄: 타자 G PA AB H 2B 3B HR RBI R SB BB K AVG OBP SLG OPS · 투수 G GS W L SV HLD IP H ER BB K ERA WHIP K/9, 머리글을 누르면 정렬. 홀드(HLD)는 경기 결정 기록에서 새로 센다(예전 기록은 0).
- 개인 순위 19부문(타율·홈런·타점·OPS·안타·득점·출루율·장타율·도루·볼넷·2루타 / 평균자책점·승리·세이브·홀드·탈삼진·이닝·WHIP·K/9).
- 기록·데이터: 우리 선수 통산 표에 AB·H·2B·3B·R·BB·K, 투수 HLD·H·ER·BB·K·BB/9. 팀 기록 탭 '내 덱 래더 통산'(리그·승패무·승률·득실·우승·준우승·정규 1위·승강·최고 단계·최고 성적·단계별 표·서버 통산·라이벌 = 같은 상대 3번 이상).
- 서버: 기록실 줄(ladder_lines)에 칸 d2·d3·r·l·gs·ha·bb·hra·hld를 더한다(ALTER는 서버가 없는 칸만, 줄 수는 그대로). 기록실 scope = 시즌 합계 · 한 리그 최고 · 통산(1시간 캐시), 부문: 홈런·타율·OPS·출루율·장타율·타점·안타·득점·2루타·3루타·루타·볼넷·도루 / 평균자책점·WHIP·K9·탈삼진·승리·세이브·홀드·이닝 / 팀 한 리그 최다승·최다 득점·최소 실점·팀 홈런·득실·최다 우승. `/ladder/me`에 career(모든 시즌 합).
- D1 쓰기: 리그 결과 하나에 쓰는 줄 수는 그대로(같은 줄에 칸만 더함).
