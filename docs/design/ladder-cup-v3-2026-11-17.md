## 4. 구단주가 정할 것

1. **휴대폰 자리**: 래더는 주 기능이 아니므로 하단 탭에 넣지 않고 메뉴 시트·PC 왼쪽 메뉴에 둡니다(구단주 결정 반영).
2. **기기 하나 = 서버 래더 플레이어 하나**: 서버 v1 토큰이 기기에 하나라, 한 기기에서 저장 칸을 바꿔도 같은 서버 플레이어로 올라갑니다. 칸마다 따로 순위에 오르게 할지 정해 주세요(바꾸면 토큰을 세계 id마다 둡니다).
3. **꾸미기 보상 기준**: 테두리 동 3점·은 10점·금 25점(매일 도장 1점·주간 3점), 칭호 5개. 더 길게(예: 금 50점) 할지 정해 주세요.
4. **'한 경기씩' 진행**: 연전(3경기)을 한 번에 돌리고 결과 칸을 차례로 보여 줍니다. 진짜 한 경기씩 끊으려면 연전 엔진을 나눠야 해서 이번에는 넣지 않았습니다.
