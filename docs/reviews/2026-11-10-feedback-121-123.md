## 현재 복무와 과거 복무의 경계

`milPeriod(p)`는 예약/복무 중의 `{from, until, unit}`과 정상 전역·병역 특례 조기 전역 뒤의 `{pf, pu, unit}`을 같은 `{from, until, unit}` 형태로 읽는다. 저장 필드를 덮어쓰거나 전역일을 늘리지 않는다.

`milOn(p, d)`는 `from <= d < until`인 실제 날짜만 복무일로 판정한다. 입대 전은 제외하고 전역일 당일부터 복무가 아니다. `milServing(p)`는 같은 판정을 현재 날짜에 적용한다. `milDaily`의 정상 전역과 `ntResult`의 실제 금메달 조기 전역 뒤에도 이전 복무일 판정이 유지된다. 이 도우미와 `futUse`의 기관 옵션은 퓨처스 담당자와 합의해 #118/#120의 출전일 판정에 연결했다.

기존 저장에서 기관별 경기 구분이 없는 미정산 경험은 현재 복무 중이면 구단 코치 보정을 적용하지 않는다. 새로 적립하는 경기는 기관별 누적을 명시하므로 전역 전후가 섞인 주간 정산에서도 구분된다.

협업 요청으로 같은 `20_military.js`의 월간 선발 수업 리포트(#119) 한 곳을 `seasonTotalT(p, y, '퓨처스', G.user)`로 맞췄다. 해당 월간 메일 경로의 회귀검사는 퓨처스 담당자가 맡았다.
