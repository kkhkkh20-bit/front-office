# 코치 구단 지원 연수 UI 검수

2026-11-10. 코치진의 각 코치에서 국내·일본·미국 교육을 신청하고, 현재 파견·귀국 성과·지원 인연을 같은 인물 카드에서 확인하도록 연결했다.

- 코치 보직 카드/명단에 `구단 지원 연수` 진입을 추가했다. PC 개요에는 이름을 눌러 확인하는 안내와 코치별 상태를 표시한다. 보조 코치도 같은 인물 카드로 연다.
- 프로그램과 집중할 세부 분야를 고르면 실제 엔진 비용·기간·선택 분야의 예상 전후 수치를 보여 준다. 예상치는 기존 화면 척도의 소수 1자리로 환산한다. 상승 예상이 없거나 파견 조건을 충족하지 않으면 이유를 표시하고 결제를 막는다.
- 비시즌 신청 기간, 연간/동시 한도, 부재 중 빈자리 처리, 계약/합류 제한을 명시한다. 생애 성장 한도는 원시 수치와 화면 능력치를 섞지 않고 설명한다.
- 최종 확인은 한 번이며, 확인 전에 차감하지 않는다. 진행 후 같은 요청을 다시 실행해도 다시 결제되지 않는다. GUARD의 기존 확인창을 사용하며 공용 actions 파일은 변경하지 않았다.
- 귀국 결과는 선택 분야의 실제 전후 수치와 지원 구단·비용을 표시한다. 기본 잔류 성향과 해당 구단의 지원 인연을 구분하고, 인물 카드·다른 구단 코치 영입 카드 모두 실제 `coachSupportView`와 같은 값을 표시한다. 지원은 잔류를 보장하는 것으로 설명하지 않는다.
- 자매구단 화면의 기존 전용 파견 버튼도 새 분야 선택 화면으로 연결한다. 기존 목적지와 다른 목적지 안내는 유지했다.

## 실제 브라우저 확인

`node tools/check-coach-training-ui.cjs` — 390×844, 768×1024, 1366×900 모두 통과.

각 크기에서 실제 코치 채용 → 코치진 진입 → 프로그램/분야 선택 → 단일 확인 → 1회 결제 → 일별 `sisDaily` 호출로 귀국 → JSON 저장 복원 → 실제 성과와 지원 인연 표시까지 실행했다. 보조 코치의 `ax:id` 진입, 프로그램 선택 시 내부 스크롤 유지, 가로 넘침, 잘못된 `undefined/NaN/Infinity` 문구, 자바스크립트 오류도 검사했다. 빌드는 `write:false`로 현재 소스를 메모리에서 읽었고 출력 파일을 쓰지 않았다.

실제 검수에서 두 문제를 수정했다.

1. 보조 코치 `c:id` 인물 카드에서 `personSheet`가 보직 키만 조회하던 오류를 발견하여 해당 코치 분기만 현재 재직자 id 조회로 보완했다.
2. 768px에서 기존 6열 코치 행의 세부 능력이 새 연수 버튼을 덮어 클릭을 막았다. 새 연수 버튼을 포함한 행만 761–1099px에서 기존 모바일 형태의 행 배치를 사용하게 했다. 수정 후 세 크기 모두 다시 통과했다.

학교/선수 육성·경제 엔진·원본 에셋은 이 UI 작업에서 수정하지 않았다. 엔진 담당의 API를 사용했으며 커밋·푸시는 하지 않았다.

## 기존 직원 카드 회귀 검사 보강

기존 `tools/check-staff.cjs`는 코치가 없는 시작 상태에서 상세 카드를 요구하고, 기본 접힌 재직/후보 행을 열지 않았다. `5e6745c3` 원본 `index.html`에 기존 검사를 실행해 현재 빌드와 동일한 4건 실패를 재현했다. 제품 회귀는 아니었다.

검사는 실제 후보 채용 후 재직 코치 이름과 채용 후보 이름을 클릭하여 상세 카드를 열도록 보강했다. 기존 보직·멘탈·관계망·면담 효과·가로 넘침 검증은 유지했다. `STAFF_HTML`로 비교 대상 HTML을 지정할 수 있으며, 보강한 검사는 기준 커밋과 최신 빌드 모두 1366/390에서 통과했다. 이 마지막 검사 보완에는 생산 소스를 변경하지 않았다.
