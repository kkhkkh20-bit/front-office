# 캘린더·실제 진행 중단·시즌 말 선수 보충·AI 영구결번

기준 main `b593e026`. 캘린더 요청 도중 전달된 두 피드백도 같은 작업 범위에 포함했다. 국내 선수 등록과 AI 결번은 별도 담당자가 구현했고, 진행 엔진과 화면은 통합 담당자가 구현·검증했다.

## 캘린더와 진행

- 스프링캠프·시범경기·마무리캠프·올스타 휴식기·연봉/FA 협상 기간을 기간 안의 날짜에 표시한다. 시작·종료·마감 일정은 기존 표시를 유지한다.
- 계속 진행 시 PC는 7일, 태블릿은 5일, 모바일은 3일 일정판을 표시한다. 그날의 경기·행사·마감을 확인할 수 있다.
- 엔진의 `advanceSteps`는 하루 처리가 끝나면 제어권을 돌려준다. 화면은 다음 날 처리 전에 사용자 입력을 받는다. 진행 버튼을 다시 누르거나 일정판의 멈춤 버튼, Space, Esc로 현재 처리한 날짜에서 중단한다. 이미 처리한 날짜를 되돌리지는 않는다.
- 달력의 ‘이 날까지 진행’도 같은 방식으로 중단한다. 진행 중 다른 업무 버튼과 게임 단축키가 날짜 처리에 끼어들지 않게 하고, Ctrl/Cmd+S 저장은 허용한다.
- 기존 엔진 `advance`는 같은 generator를 끝까지 동기 실행하므로 시뮬레이션·관전 호출 규약을 유지한다. 기본 한 시리즈/최대 3경기, 비시즌 최대 7일, 예약 관전·중요 결정 중단을 보존한다.
- 일정 기간을 표시하면서 ‘다가오는 일정’에 같은 기간이 매일 중복 나열되지 않게 했다. 대표팀 소집 기간도 시작과 복귀 일정을 중심으로 안내한다.
- 중단 후 통계·경기 요약을 정리하고 저장한다. 다시 불러와도 멈춘 날짜에서 이어지며 자동 진행이 재시작되지 않는다.

## AI 구단 영구결번

[조건·기록·검사 상세](../2026-11-10-ai-retired-numbers.md).

은퇴 시 실제 구단별 1군 WAR 60 이상, 실제 출장 8시즌 이상, 재임 연도의 한국시리즈 우승, 해당 구단의 명시적 등번호를 모두 확인한다. 현재 사용자 구단은 기존 수동 지정을 유지하고 AI 구단은 자동 지정한다. 기록은 그 구단에 남으며 리그 소식·연대기·전체 결번 목록에 반영한다. 결번과 같은 번호의 현역은 번호를 변경하고, 다른 결번과 충돌하면 중복 지정하지 않는다.

이전 구단 7번이 결번이고 마지막 현역 번호가 55번인 경우도 구분한다. OB 배지와 인물 카드에는 실제 지정 구단과 7번을 표시한다. 두 구단이 각각 지정한 결번도 따로 표시한다. 옛 은퇴자 소급 지정과 귀속 불명 기록 추정은 하지 않는다.
