# 코치 능력 표시 척도 통일

## 재현과 의미

영입 제안 메일 `cmRaid()`는 내부 종합 능력 `c.sk/c.dv`를 그대로 표시했으며, 인물 카드와 코치진 화면은 `dv()`의 비선형 100점 환산을 사용했다. 같은 내부 63은 화면에서 81이다.

제보의 63/63 대 97/78은 종합과 세부 항목의 차이도 포함한다. 실제로 투수코치의 구위74·제구60·체력61(담당 평균65), 데이터55, 유망주61이면 `coachSync()`의 종합 지도·육성은 각각 63이다. 인물 카드의 세부 구위는 97, 체력·유망주 육성은 78로 표시된다. 따라서 메일을 임의로 97/78에 맞추지 않고, 기본 종합 **81/81**과 세부 기본 **97/78**을 구분해야 한다.

현재 근무 지도·육성은 `effC()`로 감독 사단·궁합과 연수·합류 전 부재를 반영한 뒤 환산한다. 위 코치가 고집 센 감독의 사단 밖이면 현재 78/78, 사단이면 90/90이다. 직원 멘탈·관계 배율인 `staffQuality()`는 이 요약 수치 자체에 더하지 않으며, 실제 훈련 계산에서 별도로 사용한다.

## 변경

- `src/engine/staff/89_coach_market.js`: 메일을 `기본 지도 81 · 기본 육성 81`로 표시하고 현재 근무값의 사단·궁합 보정을 구분했다.
- `src/ui/staff/34_staff.js`: 인물 카드에서 사용할 기본 종합 요약과 세부 기본 능력 라벨을 추가했다. 기본/실효 차이는 환산 후 점수 차이로 표시한다(예: 내부 +6은 화면 +9). 타구단 후보 비교도 지도·육성의 화면 점수 차이를 각각 표시한다. 사단의 짧은 안내는 보정임을 설명한다.
- `src/ui/career/49_person_cards.js`: 코치 카드에 기본 종합 지도·육성 요약을 추가해 메일과 직접 비교할 수 있게 했다.
- `src/ui/staff/34c_train_coach.js`: 별 툴팁의 숫자를 100점 척도로 통일했다. 별 단계는 유지했다.
- `src/ui/components/30_card_common.js`, `src/ui/finance/35_club.js`: 타구단 코치 요약·구단 프로필 직원 상세의 내부값 직접 출력을 기본 지도·육성의 100점 표시로 바꿨다.

`24_coaches`의 능력·등급 계산과 `38_poach_fagrade`의 영입 확률·조건에는 표시 누락이 없었다. `34b_staff_fm`의 보직별 평균은 이미 내부 능력을 평균한 뒤 환산하며, 화면 숫자의 단순 평균이 아니라는 설명도 있어 유지했다. 상세 도움말에서 명시적으로 **내부 값**이라고 설명한 +6/-2는 유지했다. 스카우트·분석원의 1~5 별 척도는 코치 능력 변환 대상이 아니다.

## 검증

`node tools/check-coach-display-scale.cjs`: **8개 통과**.

- 실제 일관된 63/63 종합 코치에서 세부 97/78과 기본 종합81/81을 구분.
- 실제 `cmRaid()` 메일에서 기본81/81, 연봉1.2억·제안7일 및 원래 내부63/63 유지.
- 감독 사단·궁합 보정, 직원 멘탈/관계와 기본값의 분리.
- 파견·합류 전 빈자리58 및 이후 계획값.
- 구단 등급의 내부 보직평균 후 환산과 화면 숫자 단순평균의 구분.
- 별 툴팁 환산 및 별 단계 유지.
- 타구단 요약·구단 프로필·타팀 후보 비교의 표시 척도.

`node tools/check-coach-display-scale.cjs --browser`: **390/768/1366px 모두 통과**. 실제 `cmRaid()`를 발생시켜 메일을 열고 같은 코치의 인물 카드 기본81/81·세부97/78을 확인했다. 구분 설명의 실제 가시성, 가로 넘침 없음, 페이지 오류 없음, 내부63/63 유지를 검사했다. 캡처와 로그는 `/tmp/coach-display-review/`에 있다.

같은 초기 난수원으로 변경 전·후 실제 엔진을 별도 실행했다. 난수 호출 **1,571,674회가 동일**했고 메일 본문을 제외한 전체 `G` 및 영입 제안 데이터가 같았다. `/tmp/coach-display-review/state-comparison.json`에 결과를 남겼다. 엔진 변화는 표시 문구 한 곳이며 확률·연봉·능력 저장값은 변경하지 않았다. 메모리 빌드만 사용했고 배포 출력과 git은 루트 담당 범위다.

## 사용자 답변 초안

제보 감사합니다. 코치 영입 메일에 내부 능력값이 그대로 나오는 문제를 수정했습니다. 이제 메일과 인물 카드 모두 같은 100점 척도를 쓰며, 기본 종합 지도·육성과 분야별 세부 능력을 구분합니다. 예를 들어 종합63/63은 기본81/81로 표시되고, 세부 분야의97/78은 해당 항목의 능력입니다. 감독 사단·궁합이 반영된 현재 근무값도 별도로 구분했습니다.
