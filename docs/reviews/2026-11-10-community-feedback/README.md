## 남은 확인과 의도된 제한

- 제보 화면 크기 1024×5085, 긴 메일 300줄, 지연 사진, 아래쪽 메일 선택과 같은 메일 재렌더를 검사했으나 전체 페이지가 아래로 튀는 현상은 재현되지 않았다. 이를 해결됐다고 발표하지 않는다. 모바일 본문에서 이전/다음 메일이 막히던 DOM 의존 오류는 실제로 재현해 수정했다.
- 젊은 선수의 기존 겨울 퇴보·성장 기대 재평가 자체는 유지한다. 수정은 훈련 기회비용이 이미 하락 중인 값에 더해지는 오류에 한정한다. 별은 스카우트 추정이며 확정 성장을 보장하지 않는다.
- 급매의 신규 웃돈 면제는 날짜/소속/현재 매물 상태가 확인되는 6주 이내 급매에 적용한다. 날짜 없는 옛 매물은 기존 할인 규칙을 유지한다. 월 협상 제한과 일반 자산 보호를 우회하지 않는다.
