# 감독의 약속·요청 조건 점검

담당 범위는 `79_mgr_pledge.js`, `44_mgr_dialogue.js`, `60_mgr_visit.js` 및 추가 허가된 `30_manager.js`의 유망주 기회 합의, `29_mood.js`의 감독 외국인 상담, `02_work_tabs.js`의 합의 후보와 `32_transfer.js`의 감독 선호 표시다. `90_mgr_scenes.js`의 보강 요청과 `36_relations.js`의 정식 요청·외국인 교체 완료 판정은 각각 총괄과 별도 담당자가 수정한다. 해당 파일은 수정하지 않았다.

| 경로 | 확인한 문제 | 처리 |
| --- | --- | --- |
| 유망주 기회 합의 | 45일 부상 선수에게 실제 `pactPropose`가 “꾸준히 기회를 주겠습니다”를 반환하고 합의를 저장했다. UI와 달리 실행은 나이·주전 여부도 검사하지 않았고, 중복 ID는 두 대상으로 기록했다. | 공통 `mgrReinforceReady`와 등록 가능 여부를 사용해 UI와 실행을 같은 25세 이하 비주전 기준으로 맞춘다. 부상·차출·군 복무·육성·미계약·다음 시즌 입단·2군 선발 수업·재등록 대기·PS 자격 제한은 신규 합의 대상으로 삼지 않는다. 중복 ID는 한 명으로 처리한다. |
| 합의 기간·귀속 | 시즌이 끝난 뒤에도 당해 연도 합의를 새로 만들 수 있었다. 오래된 합의에 감독 ID가 없으면 숨은 기용 가산이 현 감독에게 적용됐다. | 비시즌 종료 후 신규 합의는 다음 시즌 준비 때 논의하도록 안내한다. 새 합의는 구단·감독 ID를 저장하고, 가산·보고·UI가 같은 대상을 확인한다. 감독 귀속 없는 예전 합의의 가산은 적용하지 않는다. 기존 30일 재제안 제한은 유지한다. |
| 합의 점검 기록 | `seasonTotal`을 읽어 같은 해 다른 구단에서 뛴 기록도 합의 뒤 기회로 셀 수 있었다. 대표 차출 중인 선수를 엔트리 경쟁에서 밀렸다고 보고할 수 있었다. | 새 합의는 `seasonTotalT`로 이 구단에서 쌓은 출전만 점검한다. 차출·계약·등록 제한은 실제 출전 불가 이유로 설명한다. 기존 저장의 구단 범위 없는 기준값은 기존 누계 방식으로 이어 읽어 음수 출전량이 생기지 않게 한다. 자동 관계 보상·감점은 도입하지 않는다. |
| 감독의 유망주 기회 보장 | `wishW=4`인 2군 선발 수업 투수가 `canUp=false`인데도 실제 `mplMonth`가 감독 약속 위반을 기록했다. | 콜업 요구와 약속 위반 양쪽에 `canUp`을 사용한다. 현재 콜업할 수 있는 4주 누적 대상은 그대로 위반 대상으로 남기며, 같은 달 중복 위반은 기존 규칙대로 막는다. |
| 콜업 요구 | PS 등록 자격 없는 선수가 2군 콜업 요구 UI 후보가 될 수 있었다. | 요구 함수도 실제 등록 자격을 확인한다. 차출 선수는 평소 `playersOf`가 제외하므로 이 누락을 주간 자동 기분 하락의 재현 증거로 사용하지 않았다. 직접 호출의 가용성 경계도 함께 확인했다. |
| 외국인 상담 | 일반 외국인 교체 횟수를 모두 사용했는데도 감독이 새 선발을 요구했다. 겨울에 결별하기로 한 기존 외국인 3명을 빈자리가 없는 것으로 세어 실제 방문 상담을 막았다. | 등록 기간·교체 횟수를 확인하고 현재 계약 유지 선수(`fStayOf`)를 기준으로 빈자리를 센다. 시장이 닫혔으면 다음 시장에서 논의한다고 설명한다. |
| 정원이 찬 외국인 영입 | 총 선수단 정원과 즉시 등록 가능 여부를 구분하지 않았다. | 필요한 유형이라는 목표는 유지하면서 “먼저 자리를 비워야 한다”는 선행 조건을 표시한다. 즉시 후보를 보자는 방문 초대와 등록 불가능한 후보 추천은 하지 않는다. 선수 정리·신규 계약의 경제 규칙은 바꾸지 않는다. |
| 같은 날 외국인 상담 | 보류권·교체 횟수·정원 상태가 바뀌어도 같은 대답이 캐시될 수 있었다. 다른 구단 보류권이 있는 선수를 영입 후보로 언급했다. | 대화 캐시 키에 실제 계약 제약을 넣고 후보에도 계약 검사를 적용한다. 시즌 중 요구액은 실제 계약 경로와 같은 신규 상한으로 검사한다. |
| 외국인 감독 선호 태그 | `G.mgrWant`에 구단·감독 귀속이 없어 이직·감독 교체 뒤 전임의 요구를 후임 선호로 표시할 수 있었다. | 저장과 태그에 명시 구단·감독 ID를 사용한다. 귀속이 없는 예전 저장은 후임 선호로 추정 표시하지 않는다. |
| 영입 면담 약속 키 | 같은 키를 중복 전달하면 같은 약속에 연봉 가산을 두 번 계산했다. | 약속 키를 중복 제거한다. 정상 UI의 선택과 연봉 가산 규칙은 유지한다. |

단순 의견 대화나 감독의 성향에 따른 판단은 유지했다. 현재 즉시 이행 불가능한 일, 선수단을 먼저 정리하면 추진할 수 있는 일, 이미 충족한 일을 구분한다. 예산이나 선수단 사정을 무시하고 요청을 성공 처리하거나 관계 감점을 일괄 면제하지 않았다.

검증 명령: `node tools/check-manager-promises-conditions.cjs`

메모리 `build({write:false})`로 **16개 통과**. 실제 합의 생성·월간 보고·감독 약속 위반·겨울 방문·같은 날 외국인 상담과 UI 합의 후보 렌더·감독 선호 태그를 실행했다. 시즌 엔트리를 실제 `setEntry`로 구성해, 등록 초기화 누락을 재현 결과로 오인하지 않는다. 불가능한 대상의 거절뿐 아니라 가능한 유망주의 정상 합의·쿨다운·실제 위반과 외국인 영입 목표 유지도 확인한다.

기존 `tools/check-logic.js:469`의 합의 쿨다운 검사는 임의의 첫 젊은 타자를 골라 합의가 항상 생성된다고 가정한다. 그 선수가 이미 주전이면 이번에 UI와 일치시킨 조건에 맞지 않으므로, 해당 검사 fixture는 실제 비주전 선수를 선택해야 한다. 공유 검사 파일은 이 작업에서 수정하지 않았다. 배포 빌드·커밋·푸시는 하지 않았다.
