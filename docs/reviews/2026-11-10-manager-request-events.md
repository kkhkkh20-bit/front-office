# 감독 요청의 실제 실행 조건

2026-11-10. `staff/36_relations.js` 감독 요청 영역만 수정했다. 구단주 지원금 부분은 변경하지 않았다.

## 확인한 규칙

- `league/01_rules.js`: 정식 정원은 68명. `rosterN`은 군 복무·다음 시즌 입단·육성 등의 실제 규칙을 반영하므로 단순 선수 객체 수로 판단하지 않는다.
- `market/16_trade.js:tradeOpen`: 정규시즌 7월 31일까지. 포스트시즌과 결산 직전은 불가.
- `players/44_free_agents.js:freeOpen`: 국내 무적 영입은 정규시즌 마지막 날까지 가능하다. 8월 15일로 일괄 제한하면 안 된다.
- `contracts/12_foreign.js:foreignOpen/foreignCheck`: 정규시즌 8월 15일까지. 일반/아시아 쿼터와 교체 횟수·외국인 연봉 상한은 별도다. 교체는 기존 선수가 자리를 비우므로 정원이 찼다는 이유만으로 모든 외국인 교체를 금지하지 않는다.
- `players/03_depth.js:psOk`: 8월 15일 뒤 새로 취득한 선수는 해당 포스트시즌에 출전할 수 없다.
- `players/20_military.js:isAway`, `league/01_rules.js:playersOf`: 군복무·대표팀 차출로 빠진 기존 선수는 `playersOf`에서 제외된다. 이 명단만 요청 시점에 저장하면 복귀를 신규 영입으로 오인한다.

기존 `90_mgr_scenes` 경로에 명시적 메모리 fixture를 넣어 부상·육성·미계약·PS 부적격·기존 선수 군복귀가 모두 보강 성공(+6)으로 처리되는 것을 확인했다. 이 경로의 수정은 통합 담당이 진행하며, 공통 `mgrReinforceReady`를 아래 검증에서도 사용한다.

## 적용

1. 주간 후보 생성, 직접 `mreqMake`, `EVH.mreq` 응답에 같은 `mreqGate`를 적용했다. 현재 감독·구단, 기한, 시장 기간, 정원, 실제 역할/자리 부족, 대상 선수 및 FA 자격을 다시 확인한다. 이미 처리한 이벤트는 재실행하지 않는다.
2. `90`의 단순 요청과 `36`의 fit/slot/fa/frep 요청은 중복 발행하지 않는다. out/draft는 별도다.
3. slot은 실제 하위권 자리이며 45일 안에 돌아올 더 좋은 주전이 없는 경우, fit은 역할 부족이 남은 경우에 요청한다. FA는 실제 하위권 자리 후보만 제시한다. 이미 2군인 선수에게 1군 자리 정리 요청을 하지 않는다. 정리 요청의 트레이드 선택지가 실행될 수 있는 기간에만 생성하고, 매물 등록 약속 기한도 마감일까지로 잡는다.
4. 요청에 당시 전체 소속 선수 id와 취득 순번을 남긴다. 완료는 실제 취득 기록의 구단·요청 후 순번·일자·기한과 현재 출전 가능 상태를 확인한다. 기존 선수의 군/대표팀 복귀, 부상·육성·미계약·다음 시즌 선수·PS 부적격 선수는 즉시 보강으로 인정하지 않는다. fit의 내부 역할 충족은 기한 안에만 인정한다.
5. 겨울 FA의 다음 시즌 보강 약속은 실제 FA 계약 결과와 계약 대상 시즌으로 확인한다. 다음 시즌 입단이라는 이유로 정상적인 겨울 계약을 거부하지 않는다.
6. 외국인 교체 판정에 `until`을 전달하고, 기존 외국인 객체가 삭제돼도 생성 당시 일반/아시아 쿼터를 보존한다. 기한 뒤 영입이나 다른 쿼터 영입은 교체 성공이 아니다.

수락 전 규칙상 불가능해진 요청은 관계 변화 없이 닫는다. 수락 후 정원·자금·외국인 교체 횟수를 다른 곳에 소비한 경우에는 약속을 자동 취소하지 않는다. 자금 부족과 스스로 만든 만석은 시장의 규정상 폐쇄와 구분한다. 현재 영입 함수가 허용하는 자금 조달·트레이드 인원 교환 경로를 가상의 금지 규정으로 추가하지 않는다.
