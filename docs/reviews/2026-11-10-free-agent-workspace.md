# 국내 무적 선수 전용 화면·선수 목록 행 구분

## 변경

- 영입·계약에 `무적 선수` 탭(`transfer:free`)을 추가했다. 국내 무적 선수 전체를 검색·타자/투수·수비 포지션으로 좁히고, 스카우트 평가·잠재력·나이·요구 연봉·이름으로 정렬한다. 페이지당 25/50/100명과 처음/이전/다음/마지막 이동을 제공한다.
- 기존 FA 화면의 국내 무적 선수 상자는 네 명의 미리보기와 전체 화면 링크로 정리했다. 전용 화면에는 기존 30/40명 절단을 적용하지 않는다.
- 전체 화면은 남는 화면 높이에 표를 배치하고 내부에서 스크롤한다. 선수 정보와 계약 열, 표 머리글을 고정했다. 좁은 화면에서도 가로 스크롤로 각 열을 확인할 수 있다.
- 웨이버 신청·2차 드래프트 보호/지명 행에 테두리·행 간격·선수 정보 열과 행동 열 사이 구분선을 추가했다. 이름과 버튼 글자 크기를 확보하고 버튼 열을 맞췄다. 기존 `.fl > .flr` 목록도 행 구분선을 표시한다.

## 계약·복귀 경계

계약은 기존 `A.signFree` 확인창과 엔진 `signFree`를 그대로 호출한다. 방출 구단의 365일 재계약 금지, 정식 선수 정원, 포스트시즌/결산 전 등록 제한을 화면에도 표시한다. 엔진의 FA 협상·보상 규칙은 변경하지 않았다. 보호선수 제출 또는 보상선수 지명이 필수인 상태에서는 기존 FA 화면처럼 해당 보상 절차만 표시한다.

새 화면 조작은 이미 `A` 초기화 뒤 로드되는 `44_moves.js`에서 등록한다. 선수 상세는 기존 사람 탐색/뒤로 가기를 사용하며 검색·정렬·페이지 및 실제 선택 위치가 유지되는지 검사했다. 기존 선수 부족 복구 버튼의 `transfer:free` 연결은 총괄 수정이다.

## 검증

명령: `node tools/check-free-agent-workspace.cjs`

메모리 빌드(`write:false`)한 전체 HTML을 로컬 서버와 Chromium/Playwright에서 실행했다. 1366×900, 768×900, 390×900 세 폭에서 아래 실제 경로를 각각 검증했다.

- 실제 방출로 82명 이상 후보를 준비하고 100명 페이지에서 전원 표시, 마지막 페이지 이동, 기존 평가순 60위 이후 선수 검색.
- 타자/투수·선발 포지션 필터, 나이 오름차순 정렬, 검색 시 첫 페이지 복귀.
- 선수 상세 열기→뒤로 이동 후 선택 페이지·검색/정렬 상태·스크롤 유지.
- 표의 내부 스크롤, 휴대폰 가로 스크롤, 문서 전체 가로/세로 넘침 없음.
- 방출 구단 재계약 제한의 버튼 비활성·사유 및 실제 `signFree` 거절/선수 불변.
- 실제 계약 버튼→기존 결재 확인창→1년 계약, 요구 연봉 일치, 중복 계약 거절.
- 실제 포스트시즌 계약 거절과 필수 FA 보호/보상 지명 화면 우회 불가.
- 실제 `toFree` 웨이버 공시와 `sdOpen`→`sdStart` 2027년 2차 드래프트 지명 단계. 좁은 화면에서는 실제 패널 전환을 사용한다. 행 테두리·행동 열 구분선 1px, 정보/행동 열의 좌표상 분리, 버튼이 화면 밖으로 나가지 않음, 이름 글자 14px 이상.
- 세 폭 모두 브라우저 `pageerror` 없음.

결과: **3개 화면 폭 모두 통과**. 각 폭에서 무적/웨이버/2차 드래프트 스크린샷을 저장하고 PC 2차 드래프트와 휴대폰 무적/웨이버 화면을 시각 확인했다. 산출물은 기본 `/tmp/free-agent-workspace/`의 PNG 9장과 `results.json`이다. 실행 환경 런타임 지침에 따라 자동 브라우저 검사를 사용했고, 샌드박스의 localhost/Chromium 제약 때문에 승인된 실행 환경에서 검사했다. 배포 산출물 및 git 작업은 수행하지 않았다.
