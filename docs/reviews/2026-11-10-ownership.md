# 구단 소유권·매각·인수 구현 검증

기업 부도로 구단을 없애는 방식 대신, 기존 모기업의 매각 추진과 새 기업의 인수를 중심으로 구현했다. 같은 엔진을 내 구단·AI·야인 시절 옛 구단에 적용한다.

## 핵심 변경

- AI 전용 즉시 매각·재창단과 인수 시 단장 자동 교체를 제거했다.
- 구단주 승계, 정상 인수, 지원 재검토→매각 추진→협상→인수/지원 회복을 분리했다. 매각 협상 장기화 시 임시 운영자금으로 구단을 유지하며 인수 협상을 계속한다.
- 구단 ID·이름·색·유니폼·연고, 선수·단장·지도자 유효 계약, 구단 기록·영구결번·트로피, 승인된 지원금·시설 공사·분담금은 보존한다.
- 후임에게 전임 개인의 친분·초대·면담·미완료 개인 주문을 상속하지 않는다. 옛 인물을 별도 ID로 기록한다. 사장의 통상 정년 교체는 소유권 변경과 분리한다.
- 시즌 평가를 마친 뒤 소유권 사건을 판정하며, 합의한 시즌 목표·평가 성향은 유지한다. 옛 구단에 보관한 구버전 목표도 AI 인수 후 복귀 시 보존한다.
- 기업 지원 정책은 적용 회계연도를 표시한다. 관련 구단·연도의 예산만 재확정하고, 일회성 운영자금은 실제 현금·당해 장부·영구 출자 이력에 한 번만 반영한다. 과거 결산표는 덮어쓰지 않는다.
- 소유권 화면과 타 구단 공개 프로필은 모기업/투자사와 개인 구단주를 구분한다. 당시 인물·회사·지원 정책·날짜·출자금 전후를 보관하며 조회는 저장 데이터·RNG·담당 구단을 변경하지 않는다.

## 검증

- `tools/check-ownership.cjs`: 18개 엔진 검사. 실제 `processDay` 35일 인수, 저장→`migrateDraft`→협상 재개, 실제 결산에서 출자금 한 번 계상, 사용자/AI 경제 결과 동등성 포함.
- `tools/check-ownership-people.cjs`: 16개 개인 관계·실제 면담·이직·복귀·저장 검사.
- `tools/check-ownership-ui.cjs`: 실제 엔진 전이 10개 흐름과 1366/390/768 화면. 미래 지원 정책·과거 스냅숏·내부 스크롤·공개 프로필 순수 조회.
- 단위검사 34개, 정적 검사, 기존 구단 운영진 이력 10개와 영구 연대기 7개, 기존 개인 인맥·면담 규칙 검사 통과.
- 기존 매각 회귀검사는 즉시 매각을 기대하던 fixture를 실제 협상→인수 경로로 갱신했다. 다른 구단 기사가 우리 여론을 바꾸지 않는 검사와 야인 시절 옛 구단 대상 검사도 통과했다.
- 운영진 이력 검사 1개가 만료 사유의 '재계약하지 않음'을 재계약으로 오인하던 문제는 실제 실행에서 새로 생긴 재계약 행만 판정하도록 검사만 수정했다.

## 빈도 실험의 범위

`tools/check-ownership-frequency.cjs`의 결과는 [JSON](2026-11-10-ownership-frequency.json)에 있다. 정상 조건 100시드×100년과 전 구단 상시 재정난 100시드×100년, 합계 **합성 기업 수명주기 20,000리그년**이다. 야구 경기·실제 연간 수입지출·선수 성장·단장 교체를 모두 진행한 20,000년 플레이를 뜻하지 않는다. 실제 경기 통합은 별도의 `STRICT=1 SEED=7 node tools/check-sim.js 2028` 두 시즌 검사로 확인한다.

정상 조건 합계 10,000리그년에서 정상 인수 169건, 지원 재검토·매각 추진 35건(각 100년에 1.69회·0.35회)이었다. 전 구단을 매년 재정난으로 설정한 스트레스 조건에서는 정상 인수 0건, 지원 재검토 107건(100년에 1.07회)이었다. 구단주 승계는 기업 사건과 달리 나이·재임 기간을 따르며 정상 조건에서 100리그년당 34.10회다(10구단 합계). 사장 정년 교체도 별도다.

이 수치는 실제 KBO 역사에서 추산한 확률이 아니라 게임 설정의 동작 확인이다. 리그 동시 협상 최대 1건, 회사/구단/리그 발생 간격, 중복 출자 방지와 유한한 현금 불변식을 함께 검사했다. 초기 확률 계산에서 정규분포 기반 함수를 확률처럼 사용한 편향을 발견해, 협상 결과와 경영 성향은 저장된 시드를 쓰는 균등분포로 수정한 뒤 결과를 다시 측정했다.
