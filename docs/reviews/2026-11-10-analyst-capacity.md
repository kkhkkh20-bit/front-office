# 분석원 정원과 감독의 보강 요청

예산 여유가 있어도 분석원 정원 6명에서 추가 채용이 막혔다. 감독 대화는 정원을 확인하지 않고 “한 명 추가” 요청을 만들었으며, 완료 조건이 요청 당시보다 인원 증가라 만석 요청을 달성할 수 없었다.

- 정원을 **6명에서 9명**으로 늘렸다. 상대 분석·트래킹·영상의 세 역할에 각각 3명씩 배치할 수 있다. 같은 역할에 3명을 넘게 배치하는 기존 기능도 유지한다.
- 사용자 채용·타 구단 영입은 기존 `ANA_MAX`를 참조한다. AI 영입 상한과 월간 인원 기준도 공통 정원에 맞췄다. AI의 재정에 따른 목표 인원·연봉 예산은 유지하며, 만석 교체로도 9명을 넘지 않는다.
- 역할별 상위 3명의 **100%·60%·30%** 가중치와 기존 효과 상한은 그대로다. 네 번째부터 단순 인원 수로 효과를 더하지 않는다. 추가 분석원의 연봉은 기존 비용 계산에 전액 포함된다.
- 만석에서는 추가 채용을 약속하는 대화를 내지 않는다. 이미 저장된 요청 중 기준 인원이 정원 이상이라 달성할 수 없는 요청은 감독 관계 차감 없이 종료한다. 6명에서 수락한 기존 요청은 7명 채용으로 정상 완료된다.

검증: `node tools/check-analyst-capacity.cjs` — 6개 검사 묶음 통과. 실제 `anaHire` UI 동작과 엔진 제안을 함께 실행해 6→7→9명 채용·10번째 거절, 감독 요청 완료, 급여·일일 비용, AI 정원·예산, 효과 계산·상한, 만석 대화·옛 불가능 요청 종료를 확인했다. 소스는 메모리에서 조합했으며 빌드 산출물을 쓰지 않았다.

수정 파일: `40_analysts.js`, `51_staff_league.js`, `90_mgr_scenes.js`. UI 표시는 공통 정원을 읽으므로 화면 코드는 변경하지 않았다.

사용자 답변문:

> 분석원을 최대 9명까지 채용할 수 있도록 늘렸습니다. 세 역할에 3명씩 배치할 수 있으며 추가 연봉은 예산에 반영됩니다. 정원을 채웠는데 감독이 또 증원을 요구하던 부분도 함께 수정했고, 달성할 수 없던 기존 만석 요청은 관계 하락 없이 정리하도록 했습니다.
