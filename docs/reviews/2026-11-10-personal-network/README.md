# 선수 시절부터 이어지는 단장 개인 인맥

기준: `d3260465` (코치 구단 지원 연수·성장 기능 반영 후).

개인 활동으로 실제로 쌓은 선수 친분을 원선수 ID로 연결한다. 은퇴 OB의 `fid`와 지도자의 `ob`를 거쳐 같은 사람의 코치·감독 경력에서도 단장과의 관계를 이어 간다. 동명이인을 합치거나 선수 기분·구단 유대를 개인 친분으로 바꾸지 않는다.

관계도의 내 인맥 화면은 현재 역할·소속과 계약, 개인 관계, 함께한 실제 이력을 보여 준다. 친밀한 현직 우리 구단 지도자는 단장 인맥 결속으로 표시한다. 감독이 데리고 다니는 사단과 구단 자체에 대한 잔류 성향은 별도로 유지한다.

과거 친분은 실제 저장된 개인 교류와 직원 관계만 근거로 삼는다. 알 수 없는 옛 대화나 선임 경력을 만들지 않는다. 감독이 되려면 기존 지도자 경력·자격이 필요하며 영입은 정원·연봉·계약·본인 의사 조건을 따른다.

## 확인할 경계

- 선수 → 은퇴자 → 코치 → 감독의 같은 인물 식별, 낮은 친밀도도 보존.
- 코치 후보 재생성, 단장 이직, 구단 지원 충성도와 개인 친분 분리.
- 조회·후보 생성으로 난수·영속 인사 기록을 추가하지 않음.
- 실제 은퇴·영입·이적·면담 기록의 보존과 중복 방지.
- 모바일·태블릿·PC에서 내 인맥과 기존 관계 화면, 인물 카드 연결 확인.

## 검증 결과

- 엔진 14건·독립 경계 17건 통과. 낮은 친분 10, 동명이인, 미교류 인물, 후보 재생성, 실제 은퇴/선임, 이직·야인, 오래된 이력·조회 순수성을 검사했다.
- Chromium 1366/390/768px에서 실제 식사·대화 → 이적 → 은퇴 → 코치 정상 계약 → 감독 정상 계약 → 저장 복원을 확인했다. 개인 친밀도와 업무 관계, 현재 계약과 내 인맥 연결을 함께 확인했다.
- 연수 완료 후 해임·후보 재생성 시 능력이 떨어지는 문제를 발견해 수정했다. 실제 연수 능력·지원 이력·면담 정보가 보존되고, 이후 OB 경력이 갱신돼도 같은 교육 효과를 중복 적용하지 않는다.
- 기존 코치 교육 14건·협상 14건·독립 경계 20건과 구단 인사 기록 17건, 개인 활동/커리어 규칙을 통과했다. 직원 카드·면담과 인물 연속 탐색(1366/768/390/568px)도 통과했다.
- 단위검사 34개, 정적 검사, 메모리 재빌드 일치, `git diff --check`를 통과했다. `STRICT=1 SEED=7 node tools/check-sim.js 2027`로 한 시즌을 진행했다. 전체 `tools/check.sh`를 실행한 것은 아니다.
