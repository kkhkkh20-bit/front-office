# 코치 연수 지원과 잔류 선호 연결

2026-11-10. 기준 main `5e6745c3`, 이후 진행 중인 코치 연수 기능과 통합했다.

구단이 비용을 댄 교육의 **수료 이력**을 실제 잔류·빼오기 판단에 반영했다. 코치의 기본 `loy`나 단장 개인과의 관계를 영구 변경하지 않는다. 단장 개인 관계(`staff.rels.me`)는 이직해도 따라가는 기존 구조이므로 구단 지원 효과와 분리했다.

공통 원장/API는 교육 담당자의 `24_coaches.js`가 제공한다.

- `c.studyHist`: 코치에게 남는 교육 이력. `tid`는 원지원 구단, `status:'completed'`와 `to`는 수료 상태·일자다.
- `coachSupportView(c,tid) → {base,bonus,loyalty,history}`, `coachLoyalty(c,tid)`: 현재 고용주가 지원 구단과 같은 경우만 효과를 적용하는 순수 조회.
- 국내 수료 +6, 해외 수료 +10. 완료 후 365일까지 전액, 730일까지 절반, 1095일까지 1/4, 이후 0. 가산 최대 +18, 총 충성도 최대 100. 구단 ID 0도 정상 처리한다.

이번 담당 수정은 다음 세 파일이다.

| 파일 | 연결한 실제 판단 |
|---|---|
| `staff/51_staff_league.js` | 공통 `stScore`에 선택적 다섯 번째 실효 충성도 인자 추가. 일반 스카우트·분석원은 기존 기본 충성도 사용. 손상된 후보·급여는 유효 점수로 채택하지 않음 |
| `staff/89_coach_market.js` | `cmScore`의 현직 잔류 점수, `cmRaid`의 외부 제안 유혹, `cmCounter`의 원구단 역제안 의향을 같은 실효 충성도로 계산. 영입 제안 메일도 지원 가산을 포함한 실제 충성도 표시 |
| `contracts/38_poach_fagrade.js` | 초기 빼오기 성공률에 같은 실효 충성도 적용. `poachTerms`가 UI 근거용 `loyalty`, `loyaltyBonus`를 반환 |

해외 수료 가산 10이면, 상한에 걸리지 않는 경우 현직 잔류 점수 +4.5, 초기 빼오기 성공률 -2%p, 역제안 발생률 +5%p로 기존 판단식에 연결된다. 임의의 이적 금지나 계약 강제 연장은 추가하지 않았다. 이미 제시한 역제안 금액을 충족한 경우의 기존 97%(감독 사단 50%) 조건은 존중한다. 코치 계약 연장의 기존 연봉 인상 3%·스타 6%, 보상금, 직접 보내 주기는 유지한다.

## 검증

```sh
node tools/check-coach-training-loyalty.cjs
```

현재 소스의 `write:false` 메모리 컴파일로 **14/14 통과**했다. 실제 `poachCoach`, `cmRaid`, `cmCounter`, `cmDaily`, `cmAiMonthly`, `cmLet`, `coachExtTerms` 경로를 호출했다.

주요 확인 결과:

- 같은 난수에서 사용자 빼오기가 지원 전에는 성공하고 원구단 지원 후에는 거절된다. AI의 실제 승격 빼오기도 같은 지원 선호로 줄어든다.
- 근접한 제안은 지원받은 코치가 같은 연봉으로 잔류하지만, 훨씬 큰 제안에는 여전히 이적한다.
- 원지원 구단과 현재 고용주가 달라지거나 시장으로 나오면 이전 지원 가산이 새 소속에 적용되지 않는다. 개인 수료 이력은 JSON 저장·복원 후에도 남는다.
- 진행 중·취소·미래 수료는 가산이 없다. 반복 가산 상한·만료·구단 0·사용자/AI 동일 기준·다른 직원 종류·손상된 구 저장·조회 사본 불변을 검사했다.
- 공통 원장의 객체/문자열·null 행 방어와 조회 이력 복사 문제를 독립 확인해 원장 담당자가 보완한 뒤 재검증했다.

이 검사는 수료 원장을 통제한 협상 fixture이며 자연 발생률 실험이 아니다. 실제 교육 신청·비용 지급·성장·복귀 처리는 별도 교육 생애주기/경계 검증 범위다. 이 작업에서 교육 담당자의 `24_coaches.js`·`98_sister_club.js`나 UI를 직접 수정하지 않았으며 배포 빌드·Git·커밋·푸시는 실행하지 않았다.
