# 사용자 제공 검수 원문

아래는 제보 당시 원문이며, 현재 버전의 검증 판정은 README에 별도로 기록한다.

프런트타임 PR #4의 `13b9639`에서 추가 검수 50건을 정리했어. 엔진이나 화면 출력에서 재현한 45건과, 동작은 재현됐지만 의도한 규칙인지 확인이 필요한 5건을 구분했어. 앞서 보고한 CI 실패는 이번 집계에서 뺐어. 이전 50건의 원문은 일부만 확인할 수 있어서 과거 전체 목록과의 중복 여부에는 한계가 있어. [검수 기준 커밋](https://github.com/kkhkkh20-bit/front-office/tree/13b9639b18efef148210364e5e6dc03c997b003b)

내 판단으로는 4번, 8번, 16번, 18번부터 고치는 게 좋아. 새 구단 장부에서 전 구단 환불이 빠지고, 해외 파견 중인 선수가 국내 경기 후보로 남고, 11월 캠프 예약이 막히고, 이직 후 복귀하면 이미 낸 예약의 환불을 못 받는 문제야. 모두 단장이 내린 결정과 실제 게임 상태가 달라지는 경우야.
