# 젊고 잠재력이 높은 선수의 능력 급락 제보

## 진단

현재 코드에서도 재현된다. 높은 잠재력과 좋은 리그 성적이 모든 항목의 하락을 막는 구조는 아니다. 이전 장기 능력 인플레이션 검토와 별개의 문제다. 실제 제보 저장 파일은 없어 아래는 새 게임의 통제 재현이며, 제보 선수의 원인을 단정하지 않는다.

- `develop`은 1월 1일 성장에서 국내 33세 이하에게 전 항목 공통의 퇴보를 적용한다. 기본 확률 11%, 정체형 17%이며 프로의식이 낮으면 증가한다. 공통 변화에 내부 −1.5~4.5를 더하므로 젊은 선수도 한 번에 여러 항목이 떨어진다.
- 같은 해 잠재력 하향도 별도 추첨한다. 잠재력 별점은 스카우트 추정이며 성장 보장이 아니다. 현재 좋은 성적은 출전량 보정을 통해 성장에 간접적으로 작용하지만, 성적 자체가 퇴보 추첨을 막지는 않는다.
- 집중 훈련 기회비용을 이미 음수인 겨울 변화에도 추가 차감하는 구현을 확인했다. ‘다른 항목의 성장 기회를 줄인다’는 규칙과 달리 기존 능력의 추가 하락이 된다. 이 부분은 퇴보 확률·성장률과 분리해서 검증한다.
- 부상 후유증은 실제 기본 능력을 낮춘다. 일부는 실전 출전으로 되찾고, 일부는 영구 손실이다. 시즌 폼은 경기 보정값이며 기본 능력 자체와 별도다.
- 화면 능력은 고정된 비선형 변환이다. 다른 선수들이 성장해서 상대적으로 표시가 내려가는 척도가 아니다. 내부 58~65 구간은 내부 1점 차이가 화면 약 1.57점이다. 기존 연도별 코치진 평가 막대는 별도의 평가 오차도 섞으므로 원래 능력 변화와 구분해야 한다.

## 통제 재현

새 게임 국내 타자, 24세·정상 성장형·잠재력 내부 62(별 4개 기준, 실제 스카우트 화면도 4별 이상), 144경기/600타석/35홈런의 좋은 실전 기록. 관찰을 마친 고성능 스카우트 평가 조건을 두고 장타 집중 32주로 장타 59→60.4 상승 후 같은 난수 시드로 겨울 성장을 실행했다.

|---|---:|---:|---:|
| 컨택 | 59 | 54.1 | 54.5 |
| 장타 | 60.4 | 56.6 | 56.6 |
| 선구 | 59 | 53.4 | 53.8 |
| 주루 | 59 | 54.6 | 55.0 |
| 수비 | 59 | 53.8 | 54.2 |

퇴보와 잠재력 62→57 하향이 함께 발생했다. 주된 하락은 현재 퇴보 정책이며, 추가 종합 0.30 하락은 집중훈련 기회비용 중첩이다. 퇴보 정책을 바꿀지는 별도 밸런스 결정이며 이 제보만으로 전체 성장률을 올리지 않는다.

## 수정과 검증

성장 기회비용은 항목의 겨울 변화가 양수일 때만 차감하고, 그 차감으로 변화가 음수가 되지 않도록 했다. 이미 발생한 퇴보·노화·군 복무 하락에 기회비용을 추가로 얹지 않는다. 퇴보 확률, 잠재력 재평가, 기본 성장률은 변경하지 않는다.

`devLog`에 실제 발생한 겨울 원인과 당시 구단을 기록한다. 기존 ‘연도별 코치진 평가’에 ‘겨울 기량 퇴보’, ‘잠재력 기대 재평가’, ‘집중훈련 성장기회 조정’, 노화·현역 복무 사유를 표시한다. 감독의 이름·육성 수치는 겨울 계산 당시를 기록해 이후 감독이 바뀌어도 당시 설명이 유지된다. 감독 기록이 없는 옛 저장과 군 복무 기간에는 현재 감독을 과거 요인으로 추정하지 않는다. 현재 우리 구단에서 관찰한 원인만 표시하고 숨은 잠재력 수치는 내보내지 않는다. 기존 저장의 과거 원인은 추정해서 채우지 않는다.

```sh
node tools/check-young-development-feedback.cjs
```

메모리 컴파일 기반 8검사: 실제 주간 훈련→겨울 성장, 20·22·24·27세의 같은 난수 20쌍 비교, 양의 성장에서 비용 유지, 실제 부상 손실·실전 회복 유지, 실제 `saveCheck`와 JSON 저장 복원, 원인 구분, 타 구단 비관측 원인 표시 방지. 추가 하락 위반은 기존 44건에서 수정 후 0건으로 줄었다. 재현 선수의 종합은 기존 내부 54.61(화면 68)에서 54.91(화면 69)로 바뀐다. 퇴보 자체는 남아 있어 직전 화면 75보다 낮다.

검수용 `before-save.json`, `after-save.json`, `validation.json`은 `/tmp/young-development-before/`, `/tmp/young-development-after/`에 기록했다. 이 저장은 통제 재현 자료이며 실제 사용자 저장이 아니다. 배포 빌드·커밋·푸시는 담당하지 않았다.

## 답변문

확인해 보니 젊고 잠재력 평가가 높은 선수도 겨울에 여러 능력이 함께 떨어지는 경우가 있었습니다. 여기에 집중훈련 기회비용이 이미 하락 중인 능력을 추가로 깎는 오류가 겹칠 수 있어 이 부분을 수정했습니다. 선수 상세의 겨울 성장 평가에도 실제 퇴보·잠재력 기대 재평가·훈련 조정 원인을 구분해 표시하도록 했습니다. 퇴보 확률이나 전체 성장률은 이번에 임의로 바꾸지 않았으며, 실제 제보 선수의 정확한 원인은 해당 저장 자료로 추가 확인이 필요합니다.
