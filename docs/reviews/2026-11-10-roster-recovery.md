# 시즌 말 선수 부족으로 진행 불가 — 국내 보충 경로

## 원인과 수정

국내 무적 선수 계약(`freeOpen`)과 육성선수의 정식 등록(`fromYS`)이 외국인 등록 마감일인 8월 15일을 함께 사용하고 있었습니다. 2군 선수를 정리한 뒤 부상·출장 정지 등으로 건강한 야수가 9명 미만이 되면, 정규시즌 경기 일정이 남아 있어도 보충 경로가 닫혔습니다.

국내 무적 선수 영입은 **정규시즌 종료일까지**, 육성선수 정식 등록은 **정규시즌 중 5월 1일부터 종료일까지** 가능하도록 바꿨습니다. 비시즌의 기존 계약·정식 등록 흐름은 유지합니다. 무적 시장과 선수 정보의 안내도 같은 기준으로 맞췄습니다.

외국인 교체와 트레이드 마감, 정식 로스터 상한, 자기 구단 방출 선수와의 1년 재계약 금지, 같은 구단 말소 후 10일 재등록 제한은 유지합니다. 포스트시즌 신규 영입·정식 등록은 열지 않았으며, 8월 15일 이후 영입한 선수의 기존 포스트시즌 출전 제한(`psOk`)도 유지합니다.

`healthy`는 단순 부상 여부만 뜻하지 않습니다. 출장 정지·미계약·대체 외국인 관련 재활 명단도 제외하며, 군 복무·대표팀 차출 등은 선수 풀과 등록 조건에서 별도로 제외합니다. 인원이 부족하다고 이 기준을 무시하거나 자동으로 선수를 추가하지 않습니다.

## 검증

```bash
node tools/check-roster-recovery.cjs
```

현재 소스를 `tools/build.cjs`의 `build({write:false}).engine`으로 메모리 빌드해 검사합니다. 날짜·부상 상태를 구성한 재현용 신규 게임에서 실제 계약·등록·경기 처리 경로를 실행하며, 제보자의 원본 저장 파일을 검사한 것은 아닙니다.

- 9월 21일 경기 전 건강한 야수 8명 → 외부 구단 출신 국내 무적 선수 영입 → 감독의 엔트리 보충 → `advance('day')` → 실제 경기 결과·승패 반영.
- 9월 육성선수 정식 등록과 같은 구단 말소 후 10일 대기 유지.
- 포스트시즌 영입·신규 정식 등록 차단, 늦은 영입 선수의 PS 출전 불가 유지.
- 정원 초과 영입·승격 차단, 자기 구단 방출 선수 재계약 금지 유지.
- 외국인·트레이드 마감, 결산 전 등록 제한, 육성 정식 등록의 5월 1일 시작 조건 유지.

기존 `tools/check-logic.js`의 “8월 15일 뒤 육성 정식 등록 불가” 시나리오는 변경한 국내 등록 규칙에 맞춰 기대값을 교체했습니다. 전체 규칙 검사와 배포용 빌드는 이 작업에서 실행하지 않았습니다.

## 답변문

제보 감사합니다. 국내 선수 보충에도 외국인 등록 마감일이 적용돼, 시즌 말 부상자가 늘면 경기를 진행할 수 없던 문제를 수정했습니다. 이제 정규시즌이 끝날 때까지 국내 무적 선수를 영입하거나 육성선수를 정식 등록해 인원을 보충할 수 있습니다. 실제 9월 경기에서 야수 8명 상태를 만든 뒤 영입·1군 등록을 거쳐 경기가 진행되는 것까지 확인했습니다. 외국인 마감과 포스트시즌 등록 제한, 로스터 정원·10일 재등록 규칙은 유지됩니다.
