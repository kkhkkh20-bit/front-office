# 코치 구단 지원 연수·성장·잔류 선호

기준 커밋: `5e6745c3` (추가 검수 96–125 반영 완료).

요청: 코치도 구단 지원으로 해외 연수와 능력 향상을 경험하고, 지원해 준 구단에 더 남으려는 동기가 생겨야 한다.

기존 자매구단 연수의 파견·귀국 구조를 확장한다. 코치진과 코치 인물 화면에서 연수 과정을 선택하고 비용·복귀일·개선 분야·업무 공백을 확인한다. 자매구단이 없어도 일반 해외 연수를 사용할 수 있다.

## 운영 규칙

- 국내 지도자 교육: 14일, 1천만 원. 일본 해외 연수: 42일, 4천만 원. 미국 해외 연수: 42일, 6천만 원. 자매구단은 기존 협정 비용(일본 2천만·미국 3천만 원)을 적용한다.
- 신청은 11월 1일–12월 15일의 비시즌. 구단별 한 해 두 명, 동시에 한 명, 코치 개인은 한 해 한 번이다. 연수가 계약 기간 안에 끝나야 하며, 미합류·감독대행·이미 파견 중인 코치는 보낼 수 없다.
- 보직 전문 분야·유망주 육성·소통·데이터 분석 중 배울 분야를 정한다. 개선은 선택 항목에 한하며 고능력일수록 줄고, 내부 능력 상한 90(화면 척도는 기존 100점 환산)과 연수로 얻는 생애 누적 상승 한도(실제 세부 항목 상승 합계 12)를 함께 적용한다. 지도·육성 요약 수치의 변화는 실제 항목 개선에서 계산한다.
- 연수 중 해당 코치가 맡던 지도·육성 효과는 빈자리 기준으로 처리한다. 완료는 날짜 진행에서 한 번만 적용하며 저장·복원으로 중복 보상을 받을 수 없다.
- 수료 지원에 대한 잔류 선호는 실제 비용을 댄 구단별로 남는다. 국내 +6·해외 +10, 합산 최대 +18이며 1년 이후 절반, 2년 이후 4분의 1, 3년 이후 0으로 줄어든다. 실제 합산 충성도는 100 이하이다.
- 잔류 선호는 더 나은 제안을 무조건 거절하는 강제 잔류가 아니다. 타 구단 영입·역제안·본인 결정에 같은 값을 사용하며, 단장이 이직해도 지원 보너스가 새 구단으로 따라가지 않는다.

## 검증

- 교육 엔진 14건·실제 협상/충성도 14건·별도 독립 경계 20건을 통과했다.
- Chromium 390×844·768×1024·1366×900에서 실제 프로그램/분야 선택, 단 한 번 확인/결제, 날짜 진행·귀국, JSON 복원, 잔류 선호 표시, 보조 코치 진입과 스크롤 유지를 확인했다. 768px에서 버튼을 능력 열이 덮던 문제를 발견해 교육 버튼이 있는 행의 태블릿 배치만 수정했다.
- 기존 자매구단 엔진 13건과 390/768/1366px 화면 검사도 통과했다. 기존 시설/개인활동 규칙·스태프 시장 19건·구단 인사 기록 17건·업무/연수 경계 검사를 통과했다.
- 기존 코치 목록 배치(390/768/1366px)와 직원 면담·관계·후보 화면(390/1366px)도 통과했다. 직원 검사가 접힌 코치 상세를 열지 않고 존재를 요구하던 문제는 수정 전 기준에서도 동일하게 재현됐다. 실제 이름 행을 열어 면담과 후보 정보를 검사하도록 보강했다.
- 단위검사 34개와 `STRICT=1 SEED=7 node tools/check-sim.js 2027` 한 시즌 진행 검사를 통과했다. 정적 검사·소스 재빌드 일치·`git diff --check`도 확인했다. 전체 `tools/check.sh`를 실행한 것은 아니다.
