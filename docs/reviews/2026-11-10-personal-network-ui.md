# 단장 개인 인맥 UI

관계도의 **내 인맥** 탭에서 실제 교류 근거가 남은 사람을 모아 본다. 기존 지도와 선수단 탭은 유지한다. 선수단 탭은 기분(사기)을 보여 준다는 설명을 추가했으며, 개인 친밀도는 내 인맥에서 별도로 확인한다.

## 표시와 이동

- 엔진의 순수 `personalNetworkView()` 결과를 읽는다. 원선수 `pl:ID`를 기준으로 현역 → OB → 코치 → 감독의 이름·현재 소속·계약·교류 기록을 같은 인물 카드에서 이어 보여 준다. 이름이 같다는 이유로 다른 사람을 합치지 않는다.
- 개인 친밀도와 업무관계가 다르면 둘 다 표시한다. 선수 기분, 감독 사단, 구단 충성도와 섞지 않는다. ‘단장 인맥’ 표시는 엔진이 반환한 실제 친분·현재 재직 근거를 따른다. UI가 추가 스탯 보너스를 만들지 않는다.
- 직업/현재 소속 필터, 이름·구단 검색, 8명 단위 목록, 인연·교류 이력의 내부 스크롤을 제공한다. 날짜 없는 옛 기록은 ‘일자 기록 없음’으로 표시한다. 없는 대화나 과거 친분을 생성하지 않는다.
- 인물 카드에도 ‘나와의 인연’ 요약을 붙였다. ‘내 인맥에서 보기’를 누르면 해당 이름을 찾은 목록으로 돌아온다. 기존 코치 연수·업무 정보는 그대로 남는다.
- 현역 선수는 선수 관리·계약 화면, 우리 코치는 해당 코치 계약 화면, 타 구단 코치는 기존 시장으로 이동한다. 무료 OB가 실제 후보 자격을 갖춘 경우에만 기존 `obAct`의 **후보 생성→계약 화면**을 연다. 후보를 보는 행동만으로 채용하지 않는다. 타 구단 재직 감독의 계약을 우리 감독 계약 화면으로 잘못 연결하지 않는다.
- OB 없이 보관 기록에만 남은 인물은 인물/선수 시절 기록 링크를 유지하고 현역 계약 버튼은 제공하지 않는다. 이직 시 옛 인맥을 자동 채용하지 않는다.

## 실제 UI 회귀

```sh
node tools/check-personal-network-ui.cjs
# root 배포 빌드 확인용
NETWORK_HTML=/workspace/front-office/index.html node tools/check-personal-network-ui.cjs
```

1366×768, 390×844, 768×844에서 다음 경로를 검사한다.

1. 새 게임의 기본 기분·사단·OB 구단 유대가 개인 인맥으로 생기지 않으며, API와 본문 렌더링이 G/RNG를 변경하지 않는다.
2. 실제 선수에게 식사 11회와 차 한 잔을 적용해 개인 친밀도 75를 쌓는다. 테스트의 초기 개인 자금 100과 선수 기분 20은 fixture이며, 결과 친밀도 75와 기분 31.5는 실제 활동 계산이다. 현재 선수 계약 설명과 정상 관리 화면 링크도 확인한다.
3. 실제 `switchTeam` 후 `retireOut`으로 은퇴시켜 원선수 ID의 친분이 OB에게 이어지는지 확인한다. 진로·연령·자격 대기 단계만 fixture로 설정하고 실제 후보 생성, `hireCoach`/`hireMgr` 계약 경로를 사용한다. 5시즌 전체를 시뮬레이션한 검사는 아니다.
4. 인맥 행의 후보 버튼을 실제 클릭해 시장으로 이동하고 **그 시점에는 미채용**임을 확인한다. 정상 코치 계약과 직원 면담 뒤 개인 친밀도 75는 유지되고 업무관계만 79로 달라지는지 확인한다. 감독 사단과 단장 인맥 표시가 동시에 있어도 서로 다른 근거인지 검사한다.
5. 감독 후보 → 정상 감독 계약 → 실제 로컬 슬롯 저장 → 브라우저 새로고침 후 같은 인물/친밀도/계약을 확인한다. 인물 행 클릭과 ‘내 인맥에서 보기’, 검색 Enter, 직업 필터, 긴 이력 스크롤, 펼친 이력 뒤 계약·인물 버튼 접근성을 확인한다.
6. 다시 이직해 옛 감독이 원 구단에 남고 새 구단으로 자동 채용되지 않으며 개인 친분은 유지되는지 확인한다. 보관 인물 fixture는 계약 버튼이 없고 기록 링크만 있는지도 검사한다.

문서 가로 넘침, 카드 내부 가로 잘림, 브라우저 오류와 순수 조회를 함께 검사한다. 증거는 `/tmp/personal-network-ui.log`, `/tmp/personal-network-ui/results.json`, 같은 폴더의 폭별 PNG다.

## 변경 범위

UI 소유 파일: `src/ui/career/07_relation_map.js`, `src/ui/career/49_person_cards.js`, 신규 `src/ui/career/84_personal_network.js`, 신규 `src/css/career/84_personal_network.css`. 기존 코치 작업에서 추가한 보조 코치 ID 파싱과 코치 연수 인물 화면은 보존했다.

인맥 엔진·역할 연결은 별도 엔진 담당, manifest/patch notes/check.sh와 최종 배포 빌드·git 작업은 root 담당이다. UI 작업에서는 배포 HTML 쓰기·커밋·푸시를 하지 않았다.
