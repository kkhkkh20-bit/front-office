# 미디어데이 독립 검증 (#29–38)

검증 기준: 현재 작업 시작점 `01ffefcf`의 `80_media_day.js`. 입력 보고서가 지목한 구 버전 `8b4b902`의 결론을 그대로 채택하지 않고 현재 소스를 메모리로 빌드해 다시 실행했다. 10건 모두 현재 기준에서도 **재현**했고 수정했다. 이미 수정/설계 차이/미재현 분류는 없다.

테스트는 새 게임→실제 창단 드래프트 종료→감독 고용까지 엔진 함수로 준비한 뒤 저장 스냅샷을 복원한다. 부상·차출·영입일·기록·순위 등 각 조건은 상태를 직접 설정한다. 실제 장기 플레이나 10년 시뮬레이션 결과로 주장하지 않는다. `dist/engine.js`, `index.html`은 갱신하지 않는다.

#38에는 담당 범위 밖 `src/engine/media/52_interviews.js`의 `ivDaily()` 무직 가드 수정 1건이 필요해 주 작업자에게 요청했고 반영 후 실제 `ivDaily()` 경로로 통과했다. `mdDaily()` 내부만 수정하면 호출 자체가 차단되므로 충분하지 않다.

동일 원인으로 PS 기사 안내도 새 구단으로 밀려 전달될 수 있어 `mdPsQ`에 구단 ID를 저장하고 발행일에 이전 구단 안내를 닫도록 함께 수정했다. 기사 기록은 행사 당일 이미 발행되는 기존 PS 구조를 유지한다. `tid`가 없는 과거 저장의 미발행 행사에는 현재 구단을 기본값으로 사용한다. 과거 저장에 누락된 원구단을 확정 복원할 수 없다는 한계가 있다.

git show 01ffefcf:src/engine/media/80_media_day.js > /tmp/audit-media-day-baseline.js
node tools/check-audit-media-day.cjs --baseline /tmp/audit-media-day-baseline.js
