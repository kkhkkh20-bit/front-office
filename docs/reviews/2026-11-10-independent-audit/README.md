## 우선 수정 및 추가 발견

- 1·2번: 조회 여부에 따른 결산 차이를 없애고 부임 후 승패와 시즌 종료 당시 전임 단장을 보존했다. 결산 전 세대교체도 같은 경로로 보호한다.
- 4번: 사장·고문 제안에 인물과 구단을 묶어 전임 제안에 후임이 답하지 못하게 했다.
- 26번: 독립구단 자금 부족 시 제작 승인과 직접 실행을 모두 막았다.
- 33번: 행사 당시 구단을 저장해 이직 뒤 기사와 업무 메일이 새 구단으로 섞이지 않게 했다.
- 45번: 위임 필터의 현금·지명권 평가를 일반 거래와 맞췄다. 추가 조사에서 실제 `answerOffer` 체결도 이 조건을 누락함을 확인해, 소유권·지급 여력 검사와 실제 현금/지명권 이동까지 반영했다. 양쪽 잔액 부족 시 불변과 중복 수락 방지도 검사했다.
- 추가 자금 경계: 기념상품 제작비와 팬 간담회 비용이 같은 독립구단 현금을 재사용하지 못하게 했다. 이미 예약된 트레이드 현금을 이중 차감하지 않는 경계도 검사했다.

## 통합 검증

- 담당 엔진 회귀 검사 5종 모두 통과. 약속·위임 검사는 추가 경계를 포함해 17개 통과.
- 기존 모듈·빌드 검사 34개 통과, 정적 검사 문제 없음.
- 최종 `index.html`에서도 PC 1366×768, 모바일 390×844, 태블릿 768×844의 실제 조작 18/18 통과. 새 게임·소식함 복귀·선수 상세·정리 취소·계약 금액 입력·위임 저장/복원을 확인했다. 조사 화면의 브라우저 예외와 가로 넘침은 0이었다. 별도 UI 조사에서 확정된 추가 UI 결함은 없었다.
- 수정 번들로 `STRICT=1 SEED=7 node tools/check-sim.js 2027` 실행: 2027-01-01까지 한 시즌 진행, 문제 없음.
- 소스와 생성 HTML을 함께 빌드했다. 새 엔진 회귀 검사는 `tools/check.sh`에도 포함했다. 전체 장기 검사 묶음은 실행하지 않았다.
