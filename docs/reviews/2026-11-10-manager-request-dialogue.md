# 감독 대화 보강 요청 독립 검증

2026-11-10. 통합 담당의 `staff/90_mgr_scenes.js` 수정 후 독립 검증했다. 이 검토 작업에서는 게임 소스를 수정하지 않았고 검사 도구와 이 문서만 작성했다.

## 확인한 흐름

- `mgrReqBlock`: 현재 감독·구단, 이미 진행 중인 약속, 상세 보강 요청과의 중복, 같은 요청 30일 재발행 제한, 실제 정원·시장 기간·종료 전 남은 일수를 검사한다. 선수 보강은 실제 리그 하위권 자리, 30일 이내 주전 부상 복귀, 즉시 콜업 가능한 내부 선수까지 고려한다.
- `mgrReqTree`와 `mgrReqChoiceBlock`: 현재 불가능한 요청이 후속으로 포함된 부모 선택지까지 대사를 보여 주기 전에 제외한다. 중립 운영 선택지는 남는다. 일반 후속 질문의 응답도 같은 필터를 거친다.
- `mgrTalkPick`/`mgrScnFx`: 선택 전에 상태를 다시 검사한다. 대화 시작 후 정원이 바뀌어도 옛 선택지의 관계·선수 기분·지출 보상과 새 약속이 적용되지 않는다.
- v2 요청: 당시 전체 소속 id와 취득 순번, 구단·감독, 실제 기한, 부족한 자리·요구 능력을 보관한다. 완료는 기한 안의 실제 취득과 현재 출전 가능 상태를 모두 요구한다. 군/대표팀 복귀는 신규 영입이 아니다.
- 분석원 요청: 새 id, 요청 이후 실제 채용일, 인원 순증이 모두 필요하다. 기존 분석원 역할 변경으로 `since`만 새로 바꾼 것은 채용이 아니다.

## 독립 리뷰에서 전달한 사항

최초 수정은 `mgrReqBlock`이 전역 현 감독만 확인하여 직접 전달된 전임 감독 객체까지 확인하지 않았다. 실제 UI는 `53_meeting.js:meetWho`에서 감독 id를 확인하므로 일반 사용자 경로는 보호되어 있었다. 그래도 엔진 함수 계약을 보강하도록 통합 담당에게 전달했고, 통합 담당이 `mgrTalkStart`, `mgrTalkPick`, `mgrScnFx`의 현 감독 확인 및 대화 상태의 `mid/tid`를 추가한 뒤 해당 회귀도 검사했다.

국내 무적 영입은 정규시즌 마지막 날까지 열려 있으므로 8월 16일 이후 보강 요청 전체를 막지 않는다. 외국인 마감과 PS 자격은 별도이며, 포스트시즌 및 종료까지 7일 미만인 경우의 신규 약속은 막는다. 수락 후 임의로 정원·예산을 소비하여 기존 약속을 삭제하는 흐름은 추가하지 않았다.
