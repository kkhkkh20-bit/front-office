# 코치 교육·연수 독립 경계 검토

2026-11-10. 새 교육 API 구현과 별도로 실제 엔진 함수와 기존 이직·해고·구단 인계 경로를 호출했다. 배포 산출물을 쓰지 않는 `build({write:false})`로 검사했다.

## 발견 및 처리

- 기존 `mkInterim`은 합류일만 확인해 파견 중인 수석코치를 감독대행으로 선택했다. 실제 기존 함수에서 재현했고, 허가받은 범위의 active 조건에 `!(c.sisAway>G.day)`를 추가했다. 다른 정상 코치 선택, 전원 부재 시 외부 감독대행, 미래 합류 제외, 귀국일 재선택을 검증했다.
- 기존 자매코치 회귀의 계약 없는 임시 객체 및 구단 연 1명 가정을 새 실제 계약·동시 1명·구단 연 2명·코치 연 1회 정책에 맞췄다. 비용은 `G.spend.etc`가 아니라 현금 선납과 `코치 교육·연수` 인계 원장으로 확인한다.
- 새 엔진 담당자에게 파견 중 감독대행·보조코치 효과 제외, 이직 후 원지원 구단 귀속, JSON 중복 귀국, legacy fm 중복 육성키, 능력 요약 하락, 지원 인연의 완료일부터 경과일 계산을 공유했다. 통합 구현에서 아래 경계를 통과했다.

## 범위와 한계

이 검토의 제품 소스 수정은 `src/engine/staff/30_manager.js`의 감독대행 가용 조건 한 줄이다. 교육·성장·충성도·캘린더·화면 구현은 각 담당자의 공유 소스를 검사했다. 전체 시즌 시뮬레이션과 배포 빌드는 실행하지 않았다. 감독 승격 시 코치 교육은 코치 능력 스냅숏으로 보존하며 감독 전술 수치로 변환하지 않는다. 현재 구현의 의도된 경계다.
