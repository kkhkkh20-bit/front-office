# v6 batch01 ·100명 후보 포맷 검토본

**중복 검수 미통과: 승인된100명 패키지가 아닙니다. `release_ready=false`, `do_not_deploy=true`입니다.**

요청서의 ArcFace 코사인 상한0.35를 유지해 실제 검사했습니다. 512 원본 후보223명에서 서로 기준을 만족하는 최대 조합은45명입니다(원본 후보군 진단이며, 납품256 시트의 합격 인원 수가 아닙니다). 이 폴더는 파일 구조·합성을 검토할100명 후보이며, 실제256 시트에서 측정한 최대 코사인은0.546829입니다. 게이트를 통과한100명으로 간주하지 않습니다. 실패한 수치를 감추거나 임계값을 바꾸지 않았습니다.

## 제작 구성

- 한국인85명:18~23세51명,24~29세26명,30~34세8명.
- 외국인15명: 미국·중남미·일본·대만 등의 가상 성인.
- 판 한 장에 RGB 얼굴·배경·공통 상체 + 알파 모자 마스크를 담았습니다. 모자 음영은 RGB의 R채널입니다.
- 기준 인물 `ko_late20s_01`과 같은 상체·의상 윤곽을 판에 정규화했습니다. 인물별 의상 마스크·부위 마스크·음영 파일·UV 파일은0장입니다.
- 공통 의상 마스크는 `shared/garment_mask_256.png` 한 장입니다. 구단 레이어는 항등 정렬합니다.
- 대표3팀 ×100명 ×128/256 검수판6장이 `previews/`에 있습니다. 전체11팀×100명에서 얼굴 영역 보존도 검사했습니다. 대한민국은 v5c 새 K 키트를 썼습니다.

## 실제 용량

두 해상도 합계1,000명 추정은8.659 MiB입니다(메타데이터·공통 에셋 제외).256 시트 한 장2MB 안쪽 목표를 충족하는지 `sheets.256.bytes`로 확인할 수 있습니다. WebP RGB 품질82, 투명 픽셀 RGB 보존, 알파 무손실입니다. RGB와 알파를 독립 축소 후 결합했고 인코딩 왕복 알파 일치 및 숨은 RGB 보존을 측정했습니다.

런타임 후보는 시트2개·공통 마스크1개·manifest1개로4파일입니다. ZIP·검수 PNG·검사 임베딩을 배포하지 않습니다. 현재 전체 릴리스는 중복 게이트 때문에 차단 상태입니다.

## 원본과 낱장 보관

`assets/v6/archive/batch01/portraits_part01.zip`, `portraits_part02.zip`에100명의512 정규화 PNG와 낱장128/256 WebP200개를 보관했습니다. 각 ZIP은50명,150항목입니다.512 파일과 낱장 파일은 배포 폴더 안에 풀어놓지 않았습니다. 개별 판의 보관 경로와 시트 좌표는 manifest에 있습니다. ZIP의 실제 크기·SHA-256은 `archive_manifest.json`을 봅니다.

## 알파 데이터 주의

원본 판의 알파는 표시 불투명도가 아닙니다. 알파0인 얼굴에도 RGB가 저장되어 있습니다. 일반 이미지 뷰어에서 원본을 열면 모자 위주로 보일 수 있습니다. 검수 PNG는 RGB의 표시 불투명도를 복원해 만들었습니다.

일반 Canvas2D `drawImage`는 이 RGB를 소실시킵니다. Chromium 실측에서 이 경로는 얼굴 픽셀을0으로 만들었습니다. `createImageBitmap(..., {premultiplyAlpha:'none', colorSpaceConversion:'none'})`와 WebGL의 비결합 알파 업로드 경로에서는 얼굴 RGB가 보존됐습니다. [CLAUDE_HANDOFF.md](CLAUDE_HANDOFF.md)에 실제 합성 순서와 디코딩 경로를 적었습니다.

## 검수와 미완료 항목

`arcface_validation.json`에 고정 ArcFace 모델·SHA-256·정렬 방식,100명 각각의 최근접 상대와 실측 코사인,0.35 초과 쌍이 있습니다. `validation_embeddings.npz`는 실제256 WebP를 디코딩해 얻은 L2 정규화 임베딩입니다. 임베딩을 중심화·백색화하거나 코사인 값을 재척도화하지 않았습니다. 이전 v6 회차는 없으며, 이번에는 회차 내100명을 서로 비교했습니다.

모든 인물은 이미지 생성 도구로 만든 가상 성인이며 실제 선수·유명인 사진을 생성 입력으로 쓰지 않았습니다. 제작 지시의 나이·민족·피부·헤어·수염·안경 태그를 기록했습니다. 육안 접촉판 검수와 게이트 재생성을 마치기 전에는 대량 제작에 쓰지 않습니다.

코드·기존 v5/v5b/v5c 파일은 수정하지 않았습니다. 다음1,000명 또는10,000명 대량 제작은 하지 않았습니다. **현재 남은 것은 요청한 상한0.35를 만족하는100명 확보입니다.**

최종 접촉판 육안 검토에서 일부 인물의 과장된 얼굴 비율·표정도 교체 대상으로 확인했습니다. 따라서 중복 수치와 별개로 육안 검수도 미합격입니다. 실제2560×2560 시트의 Chromium 비결합 알파 디코딩과 ZIP300개 이미지·CRC·공통 몸판 일치 검사를 마쳤습니다. Safari는 확인하지 않았습니다.
