## 남은 중복 문제

ArcFace는 v6과 같은 모델·SHA·5점 정렬을 유지하고, 사용자 요청에 따라 기준만0.35에서0.40으로 바꿨습니다. 최종256 WebP 시트의 RGB를 실제 디코딩해 검사했습니다. 회차 내 최대값은 **0.753416**, 앞 회차와의 최대값은 **0.599966**입니다.0.40 이상인 쌍은 회차 내 **1471개**, 앞 회차 비교 **406개**입니다. 임계값을 더 올리거나, 임베딩을 중심화·백색화·재척도화하지 않았습니다.

앞 회차 비교에는 리뷰 브랜치의 불합격 v6/batch01 100장도 포함했습니다. v4/faces_test·v5/faces_test까지 모두122개 이전 얼굴 이미지와 비교했으며, 같은 인물의 이전 판 변형도 비교 대상에 남겼습니다.4,950개 회차 내 비교와12,200개 과거 판 비교 결과, 최근접 상대·수치·초과 쌍 목록은 `arcface_validation.json`과 manifest에 있습니다. 검수에 실패했으므로 **main에 반영하지 않고 `assets/v6b-natural-pilot` 리뷰 브랜치에 보존합니다. 게임 연결·대량 제작을 승인한 파일이 아닙니다.** 사진의 자연스러움은 개선됐지만 개체별 얼굴 다양성 확보는 미해결입니다.

## 연결 시 주의

판의 알파는 불투명도가 아니라 **모자 마스크 데이터**입니다. 알파0인 얼굴에도 RGB가 있으므로 일반 Canvas2D drawImage로 읽으면 얼굴 RGB를 잃습니다. `CLAUDE_HANDOFF.md`의 비결합 알파 디코딩과 선형 데이터 정렬 시트 식을 따라야 합니다. RGB와 알파를 독립 축소해 만든 파일이며, 완성 합성은256에서 만든 뒤128로 줄입니다.512는 보관용입니다. Chromium 시트 디코딩 검사 결과는 validation에 기록합니다. Safari는 시험하지 않았습니다.

src/·index.html·빌드·검사 코드는 변경하지 않았습니다. 기존 v4/v5/v5b/v5c와 batch01을 수정하지 않았고, 게임 연결은 Claude 담당입니다.

독립 형식 검사34개, ZIP300항목 CRC·해시·크기, 정렬 시트100칸 무손실 왕복과 마스크 일치 검사를 통과했습니다. 마스크 최저 IoU는0.996390입니다. 실제 Chromium에서 판256·128의 숨은 RGB/알파, 정렬 시트 RGB 좌표를 확인했습니다. 접촉판100명과 목·칼라 확대20명을 육안으로 확인했으며, 일부 비슷한 인상과 확대 시 칼라 픽셀 계단은 남아 있습니다. 각 수치와 한계는 validation에 기록했습니다. 피부톤 태그는 정규화 사진의 양 볼 RGB 중앙값으로 보정했고, 생성 지시의 톤은 skin_tone_brief에 별도 보존했습니다.
