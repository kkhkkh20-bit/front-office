## 이번 제작

**B안: 구단 유니폼·모자를 입은 자연스러운 사진 자체를 생성**했습니다. 인물마다 머리·목·어깨·옷이 이어지는 사진이며, 공통 몸판에 얼굴을 붙이지 않았습니다. 코메츠 사진에서 다른 구단의 의상으로 생성 편집하며 인물을 유지했습니다. 키 색 UV 합성·모자 평면 색 교체·모자 아래 늘리기·심벌 사후 붙이기는 사용하지 않았습니다.

- 모자는 생성 단계에서 깊게 썼습니다. 챙이 눈썹 바로 위에 오고, 드러난 이마를 최소화했습니다.
- 크라운 이음선·단추·통풍구, 여러 줄 챙 박음질, 챙 두께와 눈썹 쪽 그림자, 로고 실결을 사진에 함께 생성했습니다.
- 유니폼에는 칼라 바인딩·단추·단춧구멍·천 결·작은 어깨 주름이 있습니다. 큰 가슴 글씨는 쇄골 중심의 근접 구도 밖으로 자연스럽게 잘리므로 목 아래로 억지로 올리지 않았습니다.
- **머리 위 여백을 사진 생성 단계에서 확보했습니다.** 배경 연장·사진 이동·모자 늘리기는0회입니다.512 정규화 원본의 모자 실루엣 추정 최저 **42px**, 최종128·256 WebP의 붉은 모자40건 재측정 최저는512 환산 **40px**입니다. 남색 모자는 배경과 색이 가까워 실루엣 추정과 전원 육안 검토를 함께 사용했습니다.
- 납품256px 크기 전원 비교판과512px 사진 비교판, 모자/칼라 확대판을 검토했습니다. 얼굴·목·어깨와 쇄골/칼라까지 보이는 구도입니다.

원본 생성 셀은625×625 또는885×885 유효 픽셀입니다. 셀 경계1px만 제외하고 전체를 같은 비율로512로 축소했으며, 얼굴·모자 부분 변형이나 별도 몸통 합성은 없습니다. 실존 선수·유명인 사진이나 실존 구단 로고는 생성 입력으로 사용하지 않았습니다.

## 검수 수치와 제한

독립 파일 검증 **15개 항목 통과**: 이미지 모드·크기·해시·셀 좌표, 원본 ZIP CRC/대응, 최종 임베딩 재계산, 여백을 확인했습니다. 원본 ZIP3개는 합계99이미지 항목입니다.

같은 인물의3구단 조합30쌍 최소 코사인은 **0.906199**입니다.0.60은 이 시범의 내부 동일인 유지 검사선이며, 요청한 인물 중복 기준0.40과 별개입니다.

**얼굴 중복 기준0.40은 미통과입니다.** 최종256 WebP에서 v6과 같은 ArcFace 모델·5점 정렬·L2 정규화·원래 코사인으로 검사했습니다. 서로 다른 인물의 구단별 사진405쌍 최대 **0.618406**, 초과 **145쌍**입니다. 현재 main v6b100명과3,000쌍 최대 **0.529232**, 초과 **104쌍**입니다. 모델·기준·점수를 변경하지 않았습니다. 작은 표본 선별 결과로 대량 제작의 다양성 합격을 주장하지 않습니다. 모든 초과 쌍·최근접·모델 SHA·실제 임베딩을 validation/NPZ에 보관했습니다.

로고 자수 모양과 피부·목 조명에는 생성 편집에 따른 미세 차이가 남습니다. 게임에서의 최종 인상은 사용자가 연결해 확인할 단계입니다. 그래서 이번 결과는 **사진/질감 검토용 시범**이고 `release_ready=false`, `accepted_identity_count=0`입니다. main으로 합치거나1,000장 확대 제작을 하지 않았습니다.

런타임 후보는 WebP6장+manifest1개, 이미지 합계 **334,292bytes**입니다(128판3장 86,882 /256판3장 247,410). 이를1,000장에 단순 비례하면128 약2.76MiB /256 약7.86MiB이나, 현재 근접 구도·시트 압축 기준의 추산입니다. 생산 확대 시 인물 선검수→승인된 인물별10구단 의상 편집→동일인/큰 카드/유니폼 검수 순서가 필요합니다.
