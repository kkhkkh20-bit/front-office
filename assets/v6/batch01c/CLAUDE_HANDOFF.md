# Claude 인계 · v6c10 큰 사진 B안

사용자가 요청한10명×3구단 사진/질감 시범입니다. 게임 연결 후 진행 여부를 판단하는 단계이며 release_ready=false, accepted_identity_count=0입니다. 0.40 얼굴 중복 검수는 미통과여서 리뷰 브랜치에만 올렸습니다. 코드 변경은 없습니다.

1. manifest.identities[].variants[team].sheets[128|256]의 path와 rect(x,y,w,h)를 읽습니다.5열×2행이며 셀 둘레8px 여백이 있습니다. pitch는128→144 /256→272입니다. 이전 v6b의10열×10행 계산을 적용하지 마세요.
2. 완성 RGB 사진입니다. 키 색 제거, UV 유니폼 합성, 모자색 교체, 모자 아래쪽 늘리기, 배경 채워 내리기, 로고 사후 재부착을 모두 생략합니다. 위 여백과 깊은 착용감이 이미 생성 사진 안에 있습니다. 현재 v6b의 임시 모자 보정 함수를 이 판에 재사용하면 안 됩니다.
3. 상세 큰 사진은256판, 작은 목록은128판입니다. 근접 구도에 맞춰 카메라 눈높이가 바뀌었으므로 이전143px 눈높이를 강제로 맞추지 않습니다. 전체 정사각을 표시하고 얼굴만 다시 확대 크롭하지 않아야 상단 여백과 쇄골/칼라가 남습니다.
4. identity_id+team+home+v6c10을 캐시 키로 사용합니다. 같은인물의3구단 사진이 별도 생성된 의상 버전입니다. source_pilot_id는 이전20명 리뷰 인물과의 대응일 뿐 현재 게임100명 ID를 그대로 바꾸라는 뜻이 아닙니다.
5. 런타임 후보는 manifest.runtime_files(이미지6장+manifest)입니다. ZIP·검수 PNG·NPZ를 배포하지 않습니다. 필요하면 ZIP에서512원본/낱장을 추출해 확인할 수 있습니다.

실제256px 비교판2장,512사진판5장,모자·칼라 확대판4장을 포함했습니다. 사용자 평가 전100명×10구단 생산이나 코드 연결은 하지 않았습니다. 검수 수치·여백 측정 방법·제한은 README/validation/framing_validation을 참조합니다.
