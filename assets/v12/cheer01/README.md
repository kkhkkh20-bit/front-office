# v12 cheer01

에셋 검수 통과 / 게임 연결 검수 대기. 리뷰 브랜치 `assets/v12-cheer01-review`, 루트 `assets/v12/cheer01/`. main 병합과 코드 수정은 수행하지 않았다.

요청서: `docs/asset-requests/2026-11-08-codex-v12-cheer-front-faces.md`. 이후 사용자 지시인 **자연스러운 포즈와 얼굴·어깨 중심 확대**를 적용했다. 팔짱·비스듬한 어깨·아래쪽에 일부 보이는 태블릿을 섞었다. 사진마다 자신의 머리·목·어깨·상의가 한 장으로 생성됐으며, 공통 상체나 얼굴 붙이기는 없다. 일부 미채택 가상 인물의 기존 생성 원본은 전신 사진 편집의 인물 참고로 사용했다. 기납품된 게임 인물을 재사용한 것은 아니다.

## 검수 자료

- `manifest.json`:48명 ID·r·a·f·안경·수염·포즈·인덱스·해상도별 rect.
- `previews/overview_128.png`, `previews/clead_256.png`, `previews/ccap_256.png`, `previews/front_256.png`.
- `validation.json`: 실제 최대값·최근접 상대·규격 검사 결과.
- `validation/`: 원본 ArcFace 임베딩/점수·검출·참조 해시·원본 생성 경로/해시·육안 검수 기록. 런타임에 포함하지 않는다.

최종 WebP에서 각 해상도의 사진을 다시 읽어 독립적으로 얼굴을 검출·정렬했다. 128·256 모두 raw ArcFace cosine이0.40미만이다. 신규끼리 최대 **0.3886989653**, 기존 회차와 최대 **0.3974152803**. 참조는 v6c100명(10구단 홈1,000사진), v7 126명, v8 120명, v9 60명, v10 40명: 해상도마다1,346사진이다. 참조 아틀라스32장의 SHA-256과 기존 검증 프로토콜을 확인해 참조 임베딩을 재사용했다. 모델/참조 해시는 검수 자료에 있다. 점수 보정·반올림 임계값 판정·임계값 완화는 없다.

RGB·크기·좌표·빈칸·무손실 픽셀 일치·96개 얼굴 검출·역할/성별/나이 할당을 확인했다. 모든48컷을256크기로 육안 검수했다. 나이는 가상 설정이며, 실존 인물 데이터베이스 전수 대조나 실제 게임 연결 완료를 주장하지 않는다. 생성 캐스팅 설명은 실제 사람의 인종·국적 판정이 아니다.
