# Front Office 에셋 v5b

2026-11-05 · [요청서](../../docs/asset-requests/2026-11-05-codex-v5b-face-kit-match.md)

승인된 v5 구단 디자인을 유지한 소개용 상의 44장과, 같은 배색·패턴을 쓰는 얼굴 합성용 홈·원정 22세트입니다. 가슴 마크는 긴 워드마크 대신 **단추 줄 오른쪽(착용자 왼쪽)의 작은 원본 구단 심벌**입니다. 하운즈는 방패형, 앵커스는 작은 닻입니다.

## 구성

- `uniforms/`: 11팀 × 홈·원정 × 앞·뒤. PNG·무손실 WebP 각 256/512px. v5 파일 ID·디자인·`text_slots` 좌표 유지.
- `face_kits/`: 패널·소매 배색·핀스트라이프·띠·파이핑·원단 음영·단추를 포함하는 공통 의상 레이어 22장. 글씨와 심벌은 포함하지 않습니다.
- `face_marks/`: 홈·원정 가슴 심벌 22장, 공용 모자 심벌 11장. 모두 위치가 적용된 전체 512px 투명 캔버스이며 128/256 축소본도 있습니다.
- `faces_test/`: v5의 가상 인물 2명. 512px 원본 RGB 보존. 몸판·소매·칼라·전체 의상·모자 키 마스크와 인물별 의상 정렬 데이터 포함.
- `source/chest_embroidery.blend`: 작은 가슴 심벌 22종의 실제 도형·자수 실·조명·카메라 원본. 모자 심벌은 검수된 v5 원본을 재사용했습니다.
- `previews/`: 유니폼 44장, 동일 위치 주름 비교, 인물별 11팀 홈·원정 합성 및 128·256·512 나란히 검수.

## 주름 수정

공통으로 반복되던 어깨 아래의 대칭 주름과 몸판 물결을 제거하고, 각 장에 별도 주름 지시를 주어 겨드랑이·소매·밑단·하단 단추 주변에 작고 비대칭적인 접힘을 배치했습니다. 메시/니트 결, 봉제선과 단추 구멍을 남겼습니다. `uniforms/crease_briefs.json`은 제작 지시이며 실제 주름의 수치 측정값은 아닙니다.

`previews/uniforms_44.png`에서 전량을, `previews/wrinkle_crops.png`에서 같은 좌표의 확대를 볼 수 있습니다. `previews/wrinkle_overlaps.png`는 같은 구단 앞·뒤/홈·원정의 동일 위치를 50% 겹친 비교입니다. 패턴·글씨도 겹치므로 밝기 차이를 전부 주름으로 해석하지 않습니다. v5 대비 수정 비교도 별도로 제공합니다.

## 합성

`manifest.json`의 `kits[team_key][home|away]`에서 세 레이어를 선택합니다. **인물별 의상 정렬 → 의상 마스크 → 가슴 심벌 → 모자 키 교체 → 모자 심벌** 순서를 사용합니다. 레이어의 원단 음영은 이미 포함되어 있어 다시 명암을 곱하지 않습니다.

두 기준 인물은 목둘레와 어깨 폭이 다릅니다. 의상은 공통 기준 인물 좌표로 한 벌만 두고, `assets[identity_id].garment_registration`의 2D UV 데이터로 인물의 의상 윤곽에 맞춥니다. 얼굴·피부·배경은 마스크 밖이므로 보존됩니다. **다른 인물에 공통 레이어를 바로 덮는 것은 올바른 합성 방법이 아닙니다.** 데이터 PNG의 좌표 복원식과 적용 방법은 [CLAUDE_HANDOFF.md](CLAUDE_HANDOFF.md)에 있습니다.

가슴 심벌은 중앙 단추 줄을 넘지 않습니다. 단추 줄에 맞춰 알파를 잘라 글자를 나누던 v5 방식은 사용하지 않습니다. 크기별 검수 이미지는 검수용이며, 런타임에 팀마다 얼굴을 다시 만들 필요가 없습니다.

## 제작·검수 범위

상의와 의상 원단은 이미지 생성 도구로 승인된 가상 구단 디자인을 편집했습니다. 크기 정규화, 투명 배경 잔여물 제거, 마스크·좌표 정렬과 검수 합성은 이미지 데이터 처리입니다. 가슴 마크는 기존 오리지널 구단 심벌의 네이티브 도형을 Blender Cycles로 자수 렌더링했습니다. 실제 구단 로고·KBO 로고·실제 선수 사진을 입력하거나 포함하지 않았습니다.

`validation.json`은 파일·크기·알파·좌표·마스크·합성 보존·해시 검사 결과입니다. 시각적 품질은 미리보기와 함께 검수해야 합니다. 전체 패키지의 SHA-256은 `checksums.json`에 있습니다(자기 자신 제외).

코드나 게임 화면 연결은 포함하지 않습니다. 대량 얼굴 제작은 하지 않았으며, 기준 인물은 2명뿐입니다. 기존 `assets/v5/`는 보존했습니다.
