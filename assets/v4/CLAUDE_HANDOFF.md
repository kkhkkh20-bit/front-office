# Claude 연결 메모 — assets/v4

이 변경은 에셋만 추가합니다. 게임 코드는 연결하지 않았습니다. v3 원본도 수정하지 않았습니다.

## A 연결

1. `manifest.json`의 `collections.trophies` 19개와 `collections.feats` 11개는 v3와 같은 ID입니다.
2. `assets[ID].png["128"]` 또는 `webp["128"]`처럼 표시 크기에 맞는 경로를 선택하고 `assets/v4/`를 앞에 붙이세요. v4는 PNG/WebP 렌더이므로 v3의 SVG 경로·색 레이어 변경 코드를 그대로 적용할 수 없습니다.
3. 64px 작은 아이콘은 64/128 원본을, 카드 확대에는 256/512를 사용하세요. 불필요하게 모든 512px 파일을 동시에 로드하지 마세요.
4. 배경은 투명합니다. 접지 그림자도 알파에 들어 있습니다. 밝은/어두운 게임 패널 모두에서 확인할 수 있도록 별도 미리보기를 넣었습니다.
5. 명판 글자는 `text_slots`의 512px 기준 투영 좌표를 사용하세요. CSS로 이미지 전체를 비율에 맞게 줄일 때 좌표도 같은 비율로 줄이세요. 쿼드 순서는 TL/TR/BR/BL입니다. 사각 영역에 텍스트를 그린 뒤 `quad`에 맞춰 합성하면 명판 기울기와 맞습니다. `baseline_segment`가 글자 밑선입니다.
6. `source_v3`는 이력 데이터입니다. v3의 명판 좌표를 v4에 직접 사용하면 어긋납니다. 루트 `rect`/`quad`/`baseline_segment`가 새 렌더용입니다.
7. 부문별 제목은 `batting_title_blank` / `pitching_title_blank`에 합성하세요. 일반 버전에는 고정 BATTING/PITCHING이 새겨져 있습니다. 공용 기록 프레임에는 숫자를 합성해야 합니다.
8. `source/pbr_collectibles.blend`는 수정용입니다. ID별 컬렉션 한 개의 렌더를 켜고 `STUDIO` 컬렉션을 유지합니다. 모델이나 카메라를 바꾸면 기존 `text_slots` 투영도 다시 계산해야 합니다.

## B 평가 연결

- `face_pairs`에 10명의 `identity_id`와 `cap_off`/`cap_on` ID를 묶었습니다. 선수마다 한 identity를 선택하고 모자 상태만 바꾸어야 얼굴이 유지됩니다.
- `faces_test/manifest.json`에도 같은 구성과 나이·피부톤·수염·안경·구단·모자 태그가 있습니다. 모든 인물은 가상 성인입니다.
- 512px /128px 정사각 불투명 RGB PNG입니다. 어두운 배경 목표색은 #20262e이나 생성 결과에 미세한 색 변화가 있습니다. 배경 제거를 하지 않은 상태입니다.
- 어깨·가슴 위까지 포함했으므로 원형 얼굴 아바타에 그대로 잘라 넣으면 유니폼이 사라질 수 있습니다. 카드형 선수 패널에서 전체 정사각 이미지를 먼저 평가하는 편이 좋습니다.
- 서울·광주 홈 유니폼을 입은 시험 세트입니다. 현재 선수 전체/구단 전체를 자동 대체하는 세트가 아닙니다. 다른 구단으로 바꾸면 별도 생성/합성 검수가 필요합니다.
- 모자 착용·미착용 사이의 얼굴 연속성, 피부 표현, 유니폼 가독성을 `previews/faces_pairs.png`로 비교하세요. 생성 특성상 미세한 차이가 있습니다.

## 패키지

런타임 대상은 선택한 `png/` 또는 `webp/` 파일과 필요한 manifest 매핑입니다. `source/`, `previews/`, 전체 미리보기, README, checksums를 게임 HTML에 임베드하지 마세요. 체크섬은 파일 무결성 확인용입니다.

실제 파일 수·64px 최대 용량과 자동 검증 결과는 `manifest.json`과 `validation.json`에 기록합니다. 이 납품의 검증은 에셋 범위이며 게임 화면에 연결된 상태의 검증을 뜻하지 않습니다.
