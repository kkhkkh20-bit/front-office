# KBO·MLB 로고 조사와 적용

조사일: 2026-11-06 (한국 시간). 이전 시안이 유치하다는 사용자 피드백에 따라, 실제 구단 로고를 공개 SVG 모음에서 직접 확인한 뒤 전체 구성을 다시 만들었다. 아래 자료의 로고 판본을 비교한 것이며, 2026년 최신 공식 CI 인증 자료로 표기하지 않는다.

   - 공개 패키지의 실제 SVG 도형 데이터를 읽어 비교판으로 렌더링하고 10개 모두 육안 확인했다.

## 관찰한 특징과 적용

| 확인한 로고 | 관찰 | 이번 디자인에 적용한 원칙 |
|---|---|---|
| LG TWINS, KIA TIGERS | 큰 레터링이 구단 인상을 결정하며 심벌보다 먼저 읽힌다. | 도시명과 구단명을 분리하고 구단명 글자 크기를 크게 올렸다. 공통 검정 리본을 없앴다. |
| 두산 Bears, 한화 Eagles, 삼성 Lions | 레터링 자체가 로고이며, 배경은 이를 받쳐 준다. | 글자 위계와 여백을 중심으로 구성했다. 실제 글꼴로 조판하고 원본 외곽선을 남겼다. |
| 키움, SSG, KT | 기울기·강한 대비·한두 개의 보조 방향선으로 운동감을 만든다. | 개방형 워드마크에는 이탤릭 레터링과 짧은 궤적선을 사용했다. |
| NC, 롯데, Cubs, Mariners | 원형 문장 안에서 구단명·도시명·중앙 심벌의 역할이 나뉜다. | 시걸스·스톰·앵커스는 위 도시명 / 아래 구단명 / 중앙 심벌의 원형 문장으로 구성했다. |
| Phillies, Pirates, White Sox | 작은 마크는 적은 수의 형태와 충분한 속공간으로 인식된다. | 32px 마크는 글자를 빼고 기존 구단 심벌을 단독으로 사용했다. 이니셜 도형 자체를 옮기지는 않았다. |
| Dodgers, Mets, Cardinals, Brewers | 글자의 흐름과 보조 야구 요소가 하나의 구성으로 연결된다. | 밑줄·야구공·다이아몬드를 워드마크와 연결하고, 캐릭터 목에 붙인 작은 공 장식을 제거했다. |
| Yankees | 야구공 요소가 전체 문장의 배경과 결합된다. | 썬더스는 구름·번개 뒤에 야구공 문장을 배치했다. |
| Blue Jays, Orioles | 큰 실루엣과 소수 색만으로도 종과 방향이 읽힌다. | 새·개·여우는 얼굴 표정이나 털 묘사 대신 큰 실루엣과 빈 공간으로 정리했다. |

## 그대로 가져오지 않은 것

실제 구단의 글자 도형, 이니셜 조합, 캐릭터 얼굴, 상표 심벌, 세부 배치·장식 경로를 가져오지 않았다. 기존 게임 구단의 색상·심벌을 유지하면서 새 경로를 작성했다. 공개 조사 SVG의 긴 path 문자열이 납품 SVG에 그대로 재사용되지 않았는지도 검사했다. 이는 상표 데이터베이스 전수 대조를 뜻하지 않는다.

이번 10개 구단은 개방형 워드마크 4개, 원형 문장 3개, 다이아몬드 2개, 야구공 문장 1개로 구분한다. 한 종류의 리본·방패에 캐릭터만 바꾸어 넣던 이전 구성을 대체한다.
