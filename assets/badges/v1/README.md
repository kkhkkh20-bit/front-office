# 프런트야구 구단 원형 배지 에셋 v1

최종 승인된 KBO 연상 색상 시안에서 추출한 10개 구단 PNG입니다.
새로운 로고를 생성하지 않고 승인된 시안의 심벌·배경·테두리를 유지했습니다.
약 310px 원본을 정사각형 원형으로 정규화하고 바깥에 투명 알파를 적용했습니다.
완전한 단색 벡터가 아니며 원본의 미세한 음영이 포함되어 있습니다. SVG 파일은 없습니다.

## 파일
- png/320/: 상세 화면·구단 선택용. 원본 해상도에 가까운 기준 파일.
- png/128/: 구단 헤더·대진용.
- png/64/: 고밀도 화면에서 32 CSS px 표시용.
- png/32/: 작은 목록용.
- teams.json: 파일 경로·구단명·디자인 참고색 매핑. 실제 게임 ID를 뜻하지 않습니다.
- preview.png: 추출 결과와 32px/64px 크기 확인용.
- reference/approved_color_sheet.png: 유저가 선택한 색상 시안.
- CLAUDE_HANDOFF.md: 적용 요청서.

## 주의
기존 세이브·구단 ID·구단명·연고지·시뮬레이션 규칙은 변경하지 마세요.
고양 스톰의 키움 참고색은 연고지 일치가 아닌 사용자용 색상 매핑입니다.
참고색은 공식 구단의 인증된 색상값이 아닙니다.
리그 로고는 이 최종 배지 시안과 별도이므로 본 패키지에 포함하지 않았습니다.
