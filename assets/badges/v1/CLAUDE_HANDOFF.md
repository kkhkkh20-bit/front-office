# Claude Code 적용 요청

첨부한 ZIP의 10개 구단 원형 배지를 프런트야구의 기존 구단 로고 위치에 적용해줘.
디자인은 reference/approved_color_sheet.png 기준이며 배경색과 심벌 조합을 유지해줘.

## 연결
1. 현재 저장소에서 구단 ID, 이름, 기존 로고 함수 및 사용 위치를 먼저 확인해줘.
2. teams.json의 name과 현재 구단 데이터를 대조해서 실제 ID에 연결해줘. JSON 배열 순서를 게임 구단 ID로 사용하면 안 돼.
3. 기존 공통 로고 렌더러가 있다면 그 경로를 교체해서 모든 화면에서 일관되게 사용해줘.
4. 파일은 프로젝트의 기존 정적 에셋 규칙에 맞춰 옮겨줘. 오프라인 단일 HTML 빌드를 지원한다면 기존 빌드 정책에 따라 data URI 인라인 등으로 포함하고, 로컬 절대경로를 참조하지 마.

## 적용 범위
존재하는 구단 선택, 홈 헤더, 순위표, 일정, 경기 결과, 중계, 트레이드, 구단 비교, 포스트시즌 화면의 구단 로고에 적용해줘.
없는 화면을 새로 만들거나 포스트시즌 포스터 기능을 추가하는 작업은 이번 범위에 포함하지 않아.

## 표시 규칙
- 이미지 자체에 배경색과 테두리가 들어 있으므로 추가 동전·테두리·그림자 효과를 넣지 마.
- 가로세로 1:1, object-fit: contain. 구단 이름은 별도 텍스트로 유지.
- 작은 목록 24~32 CSS px, 헤더 40~48px, 대진 64~96px를 출발점으로 기존 레이아웃에 맞춰줘.
- 고밀도 화면은 표시 크기의 약 2배 소스를 사용해줘. 필요 이상 큰 이미지를 모든 행에서 불러오지 마.
- 이름 옆 장식용 로고는 alt="". 로고가 구단 선택 버튼의 유일한 내용이면 버튼에 구단명 접근성 이름을 제공해줘.
- 기존 색상 변수는 이번에 자동 변경하지 마. 로고 배경색과 주변 강조색이 충돌하는 위치만 확인해줘.

## 확인 후 보고
10개 구단 매핑, 기존 세이브 호환, PC와 390px 모바일, 어두운/밝은 배경, 오프라인 또는 배포 빌드 경로, 이미지 누락을 확인해줘.
변경 파일 목록과 실제 적용 스크린샷을 보여줘. 시뮬레이션 엔진은 수정하지 마.
