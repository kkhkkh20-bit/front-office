# v21 아마추어 얼굴 — 미완료 후보 검토 자료

**요청한 200명·2,600장·78시트는 아직 완성되지 않았습니다. 이 브랜치는 게임에 연결할 정식 납품본이 아닙니다.**

새 얼굴 후보 380명을 생성하고 시각 검수에서 96명을 제외했습니다. 선별 과정에서 고교 홈 유니폼 사진 230명분을 별도로 생성했습니다. 현재 자료는 이 230장의 후보 사진, 23개의 변경하지 않은 생성 원본 PNG, 그리고 128·256·384px 후보 파일 690개의 실제 픽셀 검수 결과입니다.

기존 486명의 기준 사진과 비교하면 227명이 세 크기 모두 0.40 미만입니다. 후보끼리도 비교해 단일 사진 기준으로 함께 사용할 수 있는 84명을 임시 선별했습니다. 이 84명은 13변형 검수나 사람의 연령 확인을 마친 인원이 아닙니다. 최종 고교·대학 비율과 안경 비율도 아직 확정하지 않았습니다.

서로 함께 쓸 수 없는 사진을 중복 없이 묶은 검증 자료상, 현재 고정된 후보 사진들로 동시에 기준을 만족할 수 있는 인원은 최대 117명 이하입니다. 이는 **이 사진 묶음의 상한**이며, 새 인물이나 이후 다시 촬영한 사진까지 불가능하다는 뜻은 아닙니다.

## 현재 막힌 부분

- Adobe 새 얼굴 생성 도구가 일일 한도에 도달했습니다. 반환된 안내는 “Rate limit exceeded. Your quota resets at midnight GMT.”입니다.
- 대체 도구 Higgsfield도 기존 생성 크레딧 부족으로 추가 요청이 거절됐습니다. 추가 배치에는 실제 생성 작업이 제출되지 않았습니다. 구매나 체험판 시작은 하지 않았습니다.
- 기본 이미지 도구로 묶음·개별·사진 스타일 참고·무모자 사복 사진을 시험했으나 기존 얼굴 또는 후보 사이의 중복이 많았습니다. 기준을 낮춰 인원을 채우지 않았습니다.

## 검토 파일

- [후보 목록](review_manifest.json): 최종 게임 ID가 아닌 임시 후보 ID, 가상 설계 나이, 안경, 사진 경로, 원본 SHA256 및 크롭 좌표.
- [검수 결과](validation.json): 실제 검수 범위, 실패 수, 미완료 항목.
- [임시 선별 84명](previews/provisional_single_photo_selection_256.png): **단일 사진 수치 검사만 통과한 후보**입니다.
- `previews/draft_candidates_01_256.png`부터 `08`까지: 후보 230명 전체 검토판.
- `native/hs_home/`: 23개 생성 원본 PNG의 바이트가 동일한 복사본. 전역 생성 원본도 삭제하지 않았습니다.
- [중복 상한 증명 자료](validation/disjoint_collision_certificate.json): 200명을 선택할 수 없는 현재 사진 묶음의 수치 근거.
- [Claude 인계](CLAUDE_HANDOFF.md).

## 검수 재현

`insightface`, `onnxruntime`, `opencv-python`, `numpy`, `Pillow`, `networkx`가 필요합니다. 기존 buffalo_l 모델 두 개의 해시는 `validation/protocol.json`에 고정했습니다. 수치에는 L2 정규화 후 원시 내적만 사용하며 화이트닝·스케일 변경·임계값 예외는 적용하지 않습니다.

이 폴더에서 다음 명령으로 파일과 저장된 특징값의 연결 및 원시 코사인 검사를 재현할 수 있습니다.

```bash
python validation/audit_review.py
python validation/verify_native_derivation.py
sha256sum -c checksums.sha256
```

얼굴 인식부터 다시 실행하려면 모델이 `<model-root>/models/buffalo_l/`에 있는 경로를 전달합니다.

```bash
python validation/remeasure_review.py /workspace
python validation/audit_review.py
```

기존 인물의 기준 사진 특징값은 128·256px만 있습니다. 384px 후보는 기존 256px 기준값과 비교했으며 이 범위를 검수 결과에 명시했습니다. 모든 역사적 구단별 사진을 비교했다고 주장하지 않습니다.

사람이 직접 확인해야 하는 17~22세 인상 검수는 **미실시·대기** 상태입니다. 보조 시각 검수를 사람의 승인으로 기록하지 않았습니다. 실존 인물 참고는 사용하지 않았으며, 세상 모든 실존 인물과 닮지 않는다는 보편적 검증을 했다고 주장하지 않습니다.

게임 코드는 수정하지 않았고 main에도 병합하지 않습니다.
