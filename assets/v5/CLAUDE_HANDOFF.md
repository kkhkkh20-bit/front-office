# Claude 연결 메모 — v5

범위: A(유니폼44·모자11·숫자10의 본체/테두리) + B(마크22·기준 판2) + C 규격 문서. **C의 10,000명 생성은 하지 않았습니다.** 게임 코드 연결도 하지 않았습니다.

## 경로와 표시

루트 `manifest.json`의 `assets[ID].png[크기]` / `webp[크기]`에 `assets/v5/`를 붙이세요. 구단 key는 v2.1과 같습니다. 국가대표는 `korea`입니다. `collections`별로 순회할 수 있습니다.

- 유니폼: `{team}_{home|away}_{front|back}`, PNG/WebP 256·512. 모두 상의만, 앞번호·등이름·등번호 없음.
- 모자: `{team}`, PNG/WebP 128·256, 3/4 제품 렌더.
- 번호: `{0..9}_{fill|outline}`, PNG/WebP 256·512. 같은 캔버스의 흰색 질감 레이어 두 장을 색 곱셈으로 칠해 테두리 먼저 합성. 숫자 높이를 맞추고 2자리는 조합 후 quad에 맞춤.
- 소개용 글자 자리: 각 유니폼의 `text_slots`에 512px quad와 글자 크기가 있음. 화면 크기에 비례해 축소. `previews/text_slots.png` 확인.
- 제품 이미지의 사진적 주름·자수 세부에는 생성 차이가 있음. 정확한 얼굴 합성용 심벌·워드마크는 B의 v3 외곽선 기반 자수 렌더를 사용.

## 얼굴 합성 순서

기준 판 ID는 `ko_late20s_01`, `black_01` 두 개이며 `faces_test/manifest.json`에도 매핑이 있습니다. 512px PNG, 128·256 WebP입니다. 동일 인물의 키트만 바꾼 두 시험 판입니다.

1. `faces_test/png/512/{identity}.png`를 준비합니다.
2. 해당 `masks.key_mask`와 `key_shading`을 읽고 0~1로 정규화합니다. `key_albedo`의 RGB는 정확한 FF0000, 알파는 마스크입니다. **실제 사진에서 RGB==FF0000으로 영역을 찾지 마세요.** 빨간 사진 픽셀은 원단·조명 때문에 달라집니다.
3. sRGB 기준 `plate*(1-mask) + team_rgb*(shading/255)*mask`로 키 영역만 칠합니다. 구단색은 `teams[].design_palette.background`입니다. 마스크 밖은 원본 그대로입니다. 흰 버튼·피부·흰 원단을 칠하지 않습니다.
4. `{team}_chest`와 `{team}_cap`을 순서대로 source-over 합성합니다. **둘 다 이미 위치와 휨을 적용한 전체 512px 투명 캔버스**입니다. (0,0)에 올리고 **quad로 다시 워핑하지 마세요**. 가슴 중앙 단추 줄 x=256~265는 이미 비워져 있습니다.
5. 작은 화면은 합성 결과 전체를 128/256으로 줄이거나 기준 판·마스크·전체 오버레이를 같은 비율로 함께 줄입니다. 크롭된 마크처럼 가운데로 재정렬하면 위치가 어긋납니다.

`portrait_compositing`에 좌표·수식·순서가 있습니다. `previews/composites_all_teams.png`는 11세트×같은2명=22뷰의 정렬/색 교체 시험입니다. 신규 얼굴 22명이 아닙니다. 원본 배경은 불투명 짙은 회색이며 미세한 스튜디오 색조 차이가 있습니다. 현재 기준 판은 모자 착용만 제공합니다.

## v6 이후

`README.md`의 **v6 얼굴 규격**과 `v6_face_spec.json`을 따릅니다. 이번 커밋에는 대량 얼굴·실행 스크립트·임베딩이 없습니다. 임베딩 유사도 결과를 이번 기준 판 검증으로 오해하지 마세요. 0.35는 고정 ArcFace/정렬 방식으로 보정해야 할 v6 초기 코사인 상한이며 CLIP에 재사용할 수 없습니다.

배포 파일 수 제한 때문에 미래 낱장 20,000개와 다른 게임 파일을 모두 Cloudflare에 올리지 마세요. 100명씩 10×10 시트와 manifest를 배포하고 낱장은 별도 보관하는 구조가 규격입니다. 기존 회차 전체와의 최근접 비교, 전체/회차 최댓값, 인물별 태그·시트 좌표를 기록해야 합니다.

## 원본과 검증

`source/embroidery_studio.blend`는 모자·마크·숫자 수정용입니다. ID 컬렉션은 렌더가 꺼져 있으며 `source/render_metadata.json`의 컬렉션 하나를 켠 뒤, `cap`은 제품 카메라, `face`는 픽셀 정렬 카메라를 선택합니다. STUDIO를 유지하세요. 얼굴 마크 위치를 바꾸면 quad·미리보기도 다시 맞춰야 합니다.

`validation.json` / `checksums.json`은 에셋 납품 검증입니다. 원본·미리보기·README·검증 JSON을 HTML에 임베드하지 마세요. 게임 화면 연결 후 기능/리사이즈 검증은 별도로 진행해야 합니다.
