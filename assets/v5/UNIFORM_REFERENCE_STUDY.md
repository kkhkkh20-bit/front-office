# 유니폼 디자인 레퍼런스 조사

조사일: 2026-11-05 (한국 시간). 요청: 주름을 줄이고 구단마다 더 예쁘고 다양한 디자인으로 재구성. 해외 야구 및 축구 유니폼을 함께 비교했다.

## 열람 범위

아래 공개 GitHub 아카이브의 이미지 파일을 실제로 내려받아 관찰했다. MLB·adidas·Nike 공식 사이트는 실행 환경의 목적지 접근 제한으로 CONNECT 403이 반환되어 원문을 확인하지 못했다. 아래 사진은 제3자 제품/수집 자료이며 정품·실착·특정 시즌의 공식 사양을 인증하는 자료가 아니다. 축구 아카이브의 일부 제품 설명과 사진은 연도에 불일치 가능성이 있어 확정 연도를 붙이지 않았다. 최신 시즌 조사라고 주장하지 않는다.

외부 유니폼 사진과 실존 로고 파일은 조사용 임시 폴더에서만 열람했다. 게임 에셋에는 포함하지 않는다. 새 유니폼에는 게임의 가상 구단명·자체 심벌을 사용한다.

## 이 게임의 디자인 기준

1. 원단은 매끈한 새 유니폼처럼 보이게 한다. 복부·등의 촘촘한 물결, 깊은 주름, 줄처럼 튀어나온 굴곡은 피한다. 미세한 직조감과 넓고 얕은 음영만 남긴다.
2. 기본 실루엣은 야구 상의다. 단추 여밈, 얇은 V넥 바인딩 또는 짧은 스탠드 마감, 적당한 짧은 소매를 사용한다. 축구식 스폰서 큰 글자는 넣지 않는다.
3. 구단마다 주된 요소를 하나씩 정한다: 핀스트라이프 / 소매 배색 / 어깨 요크 / 사선 패널 / 톤온톤 패턴 / 작은 가슴 심벌 / 필기체 워드마크 / 아치형 블록 글자.
4. 홈·원정은 같은 구단의 한 세트로 보이되 구성을 단순히 명암 반전하지 않는다. 홈은 여백과 상징, 원정은 대표색·패널의 비중을 바꾼다.
5. 색은 구단 대표색을 중심으로 한다. 보조색은 한두 개로 제한하고, 작은 화면에서 구단을 식별할 수 있게 대비를 관리한다.
6. 등 이름·번호 영역은 비워 두고 중앙의 복잡한 그래픽은 피한다. 앞면의 작은 번호 영역도 게임이 합성할 수 있게 남긴다.

## 구단별 적용 방향

| 구단 | 구분되는 주된 구성 | 홈 / 원정 방향 |
| --- | --- | --- |
| 서울 코메츠 | 클래식 핀스트라이프 + 별 궤적 레터링 | 밝은 바탕의 가는 와인색 줄 / 와인색 몸판과 밝은 소매 |
| 서울 하운즈 | 소매 배색 + 작은 자체 심벌 | 크림색 몸판·남색 래글런 / 남색 몸판과 절제된 붉은 패널 |
| 인천 시걸스 | 해안 테마의 수평 디테일 + 가벼운 필기체 | 흰 바탕·붉은 가슴 포인트 / 붉은 몸판·밝은 어깨 요크 |
| 수원 스파크스 | 각진 어깨 요크 + 사선 포인트 | 흰 몸판·검정 어깨·붉은 옆선 / 검정 몸판·붉은 사선 패널 |
| 고양 스톰 | 고급스러운 필기체 + 낮은 대비의 소용돌이 패턴 | 크림색·버건디 레터링 / 버건디 톤온톤 패턴 |
| 대전 레드폭스 | 대비되는 소매·옆구리 패널 | 밝은 몸판·차콜 소매·주황 옆선 / 주황 몸판·차콜 어깨 |
| 광주 블레이즈 | 붉은 소매 + 금색의 가는 테두리 | 흰 몸판·붉은 소매 / 붉은 몸판·짙은 어깨와 금색 강조 |
| 대구 썬더스 | 푸른 핀스트라이프 + 번개형 밑줄 | 흰 바탕·파란 레터링 / 파란 몸판·흰 파이핑 |
| 부산 웨이브스 | 해군색·크림 배색 + 파도형 곡선 | 크림색·남색 어깨 / 남색 몸판·절제된 수평 파도 선 |
| 창원 앵커스 | 작은 가슴 닻 심벌 + 금색의 가는 선 | 밝은 몸판·남색 심벌 중심 / 남색 몸판·비대칭의 얇은 금색 포인트 |
| 대한민국 | 국가대표 어깨 요크 + 태극 계열의 절제된 곡선 | 흰 몸판·남색/빨강 어깨 / 남색 몸판·밝은 레터링 |

이는 독자적인 새 디자인 방향이다. 아래 자료의 실제 로고·스폰서·선수명·번호를 새 에셋으로 옮기지 않는다. A 소개용 유니폼의 패널/패턴 개편과 B의 단색 키 기반 얼굴 합성은 구분해서 기록한다.
