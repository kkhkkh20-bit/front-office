# 프런트야구 전체 에셋 패키지 v2.1

## 포함
- teams/: 승인된 10개 구단 원형 배지 40개 (32/64/128/320px). v1과 동일.
- national/: 태극기 기반 대한민국 원형 배지, 작은 태극 심벌, 직사각 태극기. SVG+PNG.
- competition/: 리그·포스트시즌·한국시리즈 심벌 및 워드마크, 밝은/어두운 화면용 각 버전. 우승 트로피 SVG+PNG.
- uniforms/: 10개 구단과 국가대표 홈/원정 유니폼, 총 22종. SVG+PNG.
- caps/: 10개 구단과 국가대표 모자, 총 11종. SVG+PNG.
- stadiums/: 낮/밤/강변 석양 공용 배경 3종, JPG+WebP.
- templates/results_demo.html: 오프라인으로 열리는 경기 결과·진출팀·대진·우승 UI 템플릿. 가상 데이터만 사용.
- manifest.json: 구단명·파일·색상 연결 정보.
- ASSET_PREVIEW.png: 구성 미리보기.
- CLAUDE_HANDOFF.md: 적용 범위와 검증 지침.

## 디자인 및 데이터 구분
리그 이름 프런트리그는 가칭. 기존 리그명이 있다면 변경하지 말고 확인할 것.
국가대표는 태극기를 원형 배지에 맞게 구성한 게임용 디자인. 정식 국기 제작용 규격 도면은 아님.
작은 태극 심벌은 좁은 공간용이며 사괘를 생략한 별도 디자인임.
국가대표·대회 로고·트로피·유니폼·모자는 편집 가능한 벡터로 제작. 유니폼 SVG의 배지는 PNG를 내장함.
구단 배지는 래스터 파일. SVG로 포장해 벡터인 것처럼 제공하지 않음.
구장 배경은 특정 10개 구장의 실측 외형이 아니며, 실제 파크팩터/담장 거리와 연동하지 않음.
실존 구단 로고·공식 협회 로고·실제 선수 사진을 포함하지 않음.

## 얼굴 유지
신규 선수 얼굴·실루엣·초상 아틀라스는 포함하지 않습니다. 기존 인게임 얼굴 생성·표시·저장 로직을 그대로 유지하세요. 유니폼과 모자 그림은 독립 에셋이며 기존 얼굴 위에 임의로 합성하지 마세요.
