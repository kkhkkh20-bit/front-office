# Claude Code 적용 요청

이 패키지의 에셋을 기존 프런트야구 화면에 연결해줘. 새 시뮬레이션 규칙을 만들지 말고 기존 데이터와 기능을 유지해줘.

1. 먼저 manifest.json과 README.md를 읽고, 구단명으로 실제 저장소의 구단 ID와 대조해줘. 배열 순서를 ID로 간주하지 마.
2. 구단 배지는 기존 공통 로고 렌더러를 통해 연결. 국대 로고는 국가대표 화면이 존재할 때만 적용하고 없으면 미사용 에셋으로 보관.
3. 리그 이름 프런트리그는 가칭이므로 기존 이름을 자동 변경하지 마. 포스트시즌·한국시리즈 로고는 각 해당 화면에만 사용.
4. 홈/원정 유니폼과 모자는 구단 소개·선수 프로필 등 필요한 위치에서 사용. 유니폼 이미지를 초상 위에 덧씌우면 옷과 얼굴 경계가 맞지 않으므로 임의 합성하지 마.
5. 선수 얼굴은 이번 적용 대상이 아니다. 기존 얼굴 에셋·생성 방식·선수별 연결·저장 데이터를 모두 유지하고 신규 초상을 배정하지 마.
6. 구장 배경 3종은 공용 분위기 이미지다. 특정 구장 실측 외형처럼 표기하거나 구장 효과·시설 레벨을 바꾸지 마. 텍스트 뒤에는 어두운 오버레이로 가독성 확보.
7. templates/results_demo.html은 참고 가능한 동작 예시다. DEMO 객체는 모두 가상 데이터이므로 실제 경과 날짜와 경기 결과로 연결해야 한다. 진출팀/시드/시리즈 규칙도 기존 엔진 상태에서 읽어야 한다. 예시의 순위나 전적을 하드코딩하지 마.
8. 경기 결과를 매일 강제 팝업으로 띄우거나 자동 진행을 새로 중단시키지 마. 기존 결과·리그·소식 화면에서 열어보게 연결해줘.
9. SVG와 PNG 중 기존 빌드에 맞는 형식을 사용. 단일 HTML/오프라인 배포는 기존 인라인 정책을 따르고 로컬 절대경로를 남기지 마. 모든 경기 행에서 큰 원본을 읽지 않게 적정 크기를 선택.
10. PC/390px 모바일, 밝고 어두운 배경, 구단 ID 매핑, 선수 얼굴 유지, 기존 세이브, 배포 빌드에서 에셋 누락을 확인하고 변경 파일 목록과 적용 스크린샷을 보고해줘.

국대/포스트시즌 등 현재 없는 기능은 에셋을 넣는다는 이유만으로 구현 범위를 확대하지 마.
