# 프런트야구 v8 · people01

요청서: `docs/asset-requests/2026-11-06-codex-v8-people-faces.md`. 가상 인물 **120명**, 남 79명·여 41명. 리뷰 브랜치 `assets/v8-people01-review` 납품분이며 게임 연결은 아직 하지 않았다.

인물마다 머리·목·어깨·옷이 이어지는 한 장의 실사풍 상반신으로 생성했다. v7 civilian과 같은 정면 카메라·부드러운 스튜디오 조명·짙은 청회색 배경이다. 전체 사진을 정사각형으로 자르고 균일하게 축소했으며 얼굴 붙이기나 공통 상체 합성을 하지 않았다. 모두 모자가 없고 의상은 무지다.

## 런타임 파일

해상도별 10×10 시트 **2장씩, 총 4장**. 각 해상도의 첫 장은 100명, 둘째 장은 프런트 직원 20명이다. 둘째 장의 나머지 80칸은 검정 RGB 빈칸이며 인물로 선택하지 않는다. 칸 간격·안쪽 패딩은 0, pitch는 128 또는 256이다.

| 파일 | 크기 | 인원 | 바이트 |
|---|---|---:|---:|

| [sheets/128/people01_02.webp](sheets/128/people01_02.webp) | 1280×1280 | 20 | 331,242 |

시트 합계 **9,379,140 bytes**. RGB 무손실 WebP를 사용해 검사한 사진의 픽셀을 그대로 보존했다. 게임에서 필요한 파일은 이 4장과 [manifest.json](manifest.json)이다. 검수 PNG·임베딩·점수 자료는 게임 로딩 대상에 넣지 않는다.

## 중복 검수

**통과: raw ArcFace cosine < 0.40**, 128·256 각각 검사. 최종 WebP 시트를 디코딩하여 120명 전원을 다시 검출·정렬하고 임베딩을 재계산했다. 신규 인물끼리 7,140쌍, v6c 선수 100명의 홈 10구단 버전 1,000장과 120,000쌍, v7 126명과 15,120쌍을 각 크기에서 검사했다. 합계 **284,520회**, 기준 이상 0회다.

| 크기 | v8 내부 최대 | v8 ↔ v6c 최대 | v8 ↔ v7 최대 | 기준 이상 |
|---|---:|---:|---:|---:|
| 128 | 0.394315988 | 0.390122175 | 0.397228450 | 0 |
| 256 | 0.398505330 | 0.395405501 | 0.399598807 | 0 |

기존 v6·v7과 같은 SCRFD·ArcFace 모델, 5점 정렬, 정규화를 사용했다. 점수를 보정하거나 평균 내지 않았다. 비교 범위는 v8 내부 및 v8↔기존 인물이며, 기존 v6c·v7 인물끼리의 중복 통과를 주장하는 자료는 아니다. 최근 main의 참조 시트 24장 SHA-256을 모두 재확인했다.

[validation.json](validation.json)에 크기별 최대값·상대 ID·인물별 최근접 상대를 기록했다. [임베딩](validation/arcface_embeddings.npz), [전체 점수 행렬](validation/arcface_scores.npz), [검출·정렬 좌표](validation/runtime_detections.json), [참조 파일·모델 해시](validation/reference_provenance.json)를 함께 제공한다. NPZ는 데이터 파일이며 검사 스크립트나 모델 가중치는 포함하지 않는다.

전원 256px 육안 검수에서 얼굴·목·칼라의 연속성, 머리 잘림, 로고·글자, 명백히 알아볼 수 있는 실존 인물 닮음을 확인했다. 명백한 실존 인물 닮음은 발견하지 않았다. 실존 인물 전체 데이터베이스와의 자동 대조를 수행했다는 의미는 아니다.
