# 프런트야구 공식 카페 브랜딩

시작 화면의 남색·야간 구장 조명과 기존 워드마크를 기준으로 제작했습니다. 사진 배경·대표 심벌·메뉴 아이콘은 이미지 생성 도구로 새로 만들었습니다. 실존 구단·KBO·네이버 로고나 실존 선수 얼굴은 사용하지 않았습니다.

| 파일 | 크기 | 용도 |
|---|---:|---|
| `cafe_title_1080x220.png` | 1080×220 | PC 상단, 왼쪽 워드마크·중앙 메뉴 여백·오른쪽 구장 |
| `cafe_front_1080x600.png` | 1080×600 | 카페 대문, 슬로건·무료 플레이·빈 캡처 액자2곳 |
| `cafe_mobile_cover_1080x1080.png` | 1080×1080 | 모바일 대표, 중심60%에 워드마크와 문구 |
| `cafe_icon_512.png`, `cafe_icon_150.png` | 512 / 150 정사각 | 원형 크롭을 고려한 야구공+단장 클립보드 |
| `cafe_icon_1024.png`, `cafe_icon_300.png` | 1024 / 300 정사각 | 대표 아이콘2배 판 |
| `menu_icons/white/*.png`, `menu_icons/gold/*.png` | 64×64 RGBA | 공지·패치·가이드·버그·건의·밸런스·질문·자유·우리 구단·공략·구단 이름 공유11종씩 |
| `menu_icons/2x/{white,gold}/*.png` | 128×128 RGBA | 메뉴 아이콘2배 판 |
| `board_header_{notice,patch_notes,bug_report}.png` | 1080×160 | 공지 / 패치 노트 / 버그 제보 띠 |
| `safe/cafe_{title_1080x220,front_1080x600}_safe.png` | 원본과 같음 | 문구를 가장자리에서 더 안쪽으로 옮긴 여백 판 |
| `ASSET_PREVIEW.png` | 1360×1080 | PC·모바일 모형 한 장 |
| `previews/pc_mockup.png`, `mobile_mockup.png` | 각 이미지 참조 | 배치 모형, 실제 네이버 관리 화면 캡처가 아님 |

타이틀·대문·모바일·띠·safe의 모든 PNG에 `_blank.png`(워드마크와 문구 모두 없음), `_2x.png`, `_blank_2x.png`가 있습니다.2배 판은 각각2160×440 /2160×1200 /2160×2160 /2160×320입니다. SVG는 벡터 레이아웃 원본이며 사진 배경의 생성 해상도는1672×941입니다.2배 PNG의 사진은 리샘플한 것으로, 네이티브2160 사진이라고 표시하지 않았습니다.

`editable/*.svg`에는 배경·액자·타이포 그룹이 분리되어 있고 `text_layers/*.svg`는 투명한 별도 글자 레이어입니다. PNG는 합쳐진 업로드용 파일, SVG가 편집 원본입니다. PSD는 별도로 만들지 않았습니다. SVG와 `sources/`·`fonts/`의 상대 경로를 함께 유지하세요. Noto Sans CJK KR의 한글·라틴 서브셋 WOFF와 SIL OFL 라이선스를 포함했습니다. 생성된 한글 그림 대신 실제 글꼴로 문구를 출력해 깨짐을 검사했습니다.

대문 액자는 빈 상태가 의도된 결과입니다. `manifest.json`의 screenshot_slots 좌표(1080기준)에 실제 게임 캡처를 contain 방식으로 넣고, 필요하면 여백을 유지하세요. 무료 플레이는 이미지 속 문구이며 링크는 카페 관리 화면에서 지정합니다.

모바일 바깥20%를 잘라낸 검수판과 원형 아이콘 크롭도 `previews/`에 있습니다. 업로드 전에 네이버 카페 관리 화면의 현재 규격·메뉴 겹침을 사용자가 최종 확인합니다. 이 작업에서 실제 카페 설정이나 게임 코드는 변경하지 않았습니다.
