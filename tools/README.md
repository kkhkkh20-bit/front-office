# 정리 도구

- `find-dead-code.js`: 어디서도 부르지 않는 최상위 함수·상수를 찾습니다. `--apply`를 붙이면 지웁니다. 같은 이름이 두 번 선언된 경우도 알려 줍니다(나중 선언이 앞을 덮어쓰므로 버그 원인이 됩니다). 실행하려면 `npm i acorn acorn-walk`가 필요합니다.
- `find-dead-css.py`: 소스 어디에도 나오지 않는 클래스만 쓰는 CSS 규칙을 찾습니다. `--apply`를 붙이면 지웁니다. 클래스 이름을 문자열로 이어 붙여 만드는 경우(`net${lv}`, `t-${tab}`, `'v-'+k`)는 예외로 둡니다.

둘 다 지운 뒤에는 빌드, 회귀 검사, 같은 시드 화면 비교로 결과가 같은지 확인합니다.
